# 修仙人生 · 航图之外 v0.7.0

Vue 3 + TypeScript + Pinia + Vite 的本地单机修仙游戏。本版将炼气筑基、宗门师承、随机挑战与寻人剧情连接成一个闭环。

## 启动与验证

需要 Node.js 22.12+ 或 24.x。

```sh
npm ci
npm run dev
npm test
npm run build
```

打开终端显示的网址。dist 可部署到静态服务器；更换网址、浏览器或设备前请导出存档。

## 本版玩法

- 营救归来 → 回访药工 → 坊市结识郁青、补全航图 → 青嶂关识险 → 行营修行与准备 → 筑基越关 → 云栈旅亭记路 → 回访看见世界回应。
- 山口固定种子揭示迷雾或罡风，功法、灵器、同行三种准备方向；失败保留线索与装备，养伤、凝神、固本可提高把握至 100%。筑基自身的原有风险仍然保留。
- 统一场景表现：剧情、人物对白和最新结果叠在背景上；探索、修行、宗门、缘分、擂台、突破与轮回使用独立操作区。手机文字自然换行、功能导航完整展开。
- v6 旧档保留进度，救人完成后直接接第二卷；存档版本升至 7，首次保存备份 original-v6。仍是本地 IndexedDB，不是 MySQL 或云存档。详见 [v7-cloud-road.md](docs/v7-cloud-road.md)。

- 默认进入场景冒险：渡口查线索 → 药庐配药/邀同行/练护体 → 雾林辨路 → 山祠营救 → 看见归家结果。无需等待修行月份触发。
- 新角色直接进入；旧角色可在「当前冒险」接取新增委托，不重置存档。失败带回情报，准备后可重试。
- 手机单列场景、折叠行囊、大点击区域；开发环境可访问 /tools/mobile-preview.html 检查不同视口。尚未制作 Steam / TapTap 安装包。
- 第一卷的原始设计与验证边界见 docs/v6-scene-first.md；第二卷目前只开放云外长路与旅亭，不代表完整开放世界。

- 新增沈听澜 / 尹照川两条成年异性人物线，通过共同经历相识、相知、定情；婚礼尚未开放。
- 听松擂台三位具名 NPC：观摩招式、装配准备、三合应对、失败复盘及首胜奖励；不是在线排行榜。
- 月下谈心与擂台独立场景、正确人物立绘、氛围光色及轻过渡；刷新恢复剧情和交锋。资源与规则见 docs/v5-social-scenes.md。

- 听松门丹堂 / 剑院：亲历事务、回答执事的修行之问，晋升外门，获得功法与雾岭资格。温蘅、季衡有独立肖像和师门设定。
- 六本功法，一本主修 + 一本辅修，影响吐纳、采药、历练、凝神等具体行动。散修也可在坊市求教。
- 回春谷救人 / 追线索 → 筑基后深入雾岭 → 雾海带回父亲来信。地图各三段，后两地必须通过挑战才能推进。
- 固定种子的随机遭遇：守境妖修石角可带药交涉，夺宝邪修乌灯客需闯关；敌人不会刷新重抽。失败保留进度与装备，付出时间、灵石与伤势代价。
- 根骨、神识、心得、根基、剑意、装配功法、针对性灵器及同行援助共同影响把握，公式公开；充分准备可达到 100%。
- 归元灵瓶 / 听松灵剑可炼制、精炼和装配；陆迟或执事可护持。更高装备品阶尚未开放。
- 在线修行安排：最多八项，每项 1–12 次，可采药、炼丹、养伤等；遇剧情、资源不足或修为满暂停，不自动突破或做剧情选择。

- 三组等预算资质：根骨影响吐纳和护友，悟性影响研读、丹方与解阵，神识可凝神成长，用于控火和识阵。不是三种突破率加点。
- 陆迟新增两段中期互动、动态人物档案，以及四张统一形象立绘与两张场景插画；提示词与资源清单见 docs/character-assets.md。
- 自留孤丹获得一次护脉丹纹，并解锁孤灯丹诀传承；结算提示本世未探索的下一世可能。
- 长春医道：采药、炼丹；青锋剑道：更快吐纳、历练剑意，管理伤势。
- 第三月认识陆迟，第三十六月赴约；可选择失约，或进入遗府以草药、剑意、修为破阵。
- 唯一的遗府筑基丹可自留或赠友。赠友获得护法；信任影响护法强度。
- 积满 360 修为后主动筑基，概率来源公开。养伤、炼丹与固本均是可选准备。
- 陆迟故事结束且成功筑基，记入一次传承奖励但继续探索；主动封存后才选择轮回。旧版已完成的筑基存档可直接继续此世。金丹暂未开放。
- 下一世重新选路，只携一份已解锁传承：长春丹札允许跨路线采药炼丹，青锋残谱允许跨路线练剑，渡口旧约开启前世记忆选项。
- 每次有效行动自动存档；切后台暂停，无离线收益。支持导入、导出和上一快照恢复。

正常刷新保留 IndexedDB 存档与修行安排，但不自动恢复运行。清理网站数据、换浏览器/设备/访问端口可能导致存档丢失或不可见，请定期导出。当前没有后端或 MySQL；账号、云存档、冲突处理与服务端排行榜列入后续规划，见 docs/next-design.md。

## 旧档保护

v2 筑基篇存档自动接续，不重开、不重置修为或 RNG；默认补入明心善悟资质。已过去的中期互动不补发奖励，已结算自留分支补解锁孤灯丹诀。首次写入时保留 original-v2 原始备份。v3 保存全部资质、人物记忆与丹纹状态。

v1 存档读取时不修改原始数据。确认进入新篇后，以十六岁重新开篇，旧版人物和卷宗完整封存在新档的 archive 中，并在 IndexedDB 中保留 original-v1。可从界面导出旧版原档。旧版数值不直接套入新规则。

未知未来版本不会被自动降级覆盖；损坏且无可恢复备份时停止开局写入。请只在一个标签页游玩，尚无跨标签页并发锁。

## 代码结构

- src/core.ts：纯规则公开入口。
- src/chapter.ts：筑基篇状态、命令、事件投影、种子随机数、校验与迁移。
- src/legacy-v1.ts：旧版规则与校验器，保留回归覆盖和原档识别。
- src/save.ts：IndexedDB 双快照及旧档封存。
- src/App.vue：只读状态投影、命令调度与保存成功后更新界面。
- src/characters.ts：NPC 图像、台词、去向与已知经历的只读投影。
- src/legacy-v2.ts：冻结的 v2 状态校验与迁移依据。
- tests/：45 项测试，含原 120 组与新增 180 组资质/路线/结局的确定性完整重放。
- public/mountains.svg：原创矢量山景，无图片外链。

## 范围

这是筑基篇可玩原型，不是完整六境界正式版。尚未做大规模玩家平衡测试、移动真机验收、音效、PWA、多人、后台世界模拟或云存档。卷宗保留最近 180 条，去重保留最近 512 条命令 ID，不是永久操作日志。运行时无后端、账号或遥测。
