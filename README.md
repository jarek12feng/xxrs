# 修仙人生

基于《修仙人生 H5 游戏详细技术方案》的首版可玩闭环。Vue 3 + TypeScript + Pinia + Vite，纯 TypeScript 规则核心，IndexedDB 本地存档。

## 启动

需要 Node.js 22.12+ 或 24.x。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。检查与生产构建：

```sh
npm test
npm run build
```

`dist/` 可以部署到静态网站服务器。存档绑定浏览器和网站来源；更换网址或设备之前请导出 JSON 存档。

## 当前玩法

- 创建道号，选择长春功、青锋诀或观星经。
- 单月推进或自动闭关；每 9 个游戏月触发一个事件并暂停。
- 10 个双选项事件，可获得修为、灵石、感悟、护脉丹或寿元。
- 修为满后主动突破，显示概率来源；成功延寿，失败损失修为和寿元。
- 支持炼气至飞升；寿元耗尽结算死亡，选择遗产进入下一世。
- 每次有效操作保存当前和上一份快照；刷新恢复，可导入、导出。
- 页面进入后台自动暂停，不结算离线收益。

## 代码结构

```text
src/core.ts       状态、配置、命令、确定性随机数和规则
src/save.ts       IndexedDB 双快照持久化及恢复
src/App.vue      游戏界面、只读状态投影和命令调度
src/style.css    响应式游戏视觉
public/mountains.svg   原创矢量山景
tests/           规则回放与核心不变量测试
```

核心不依赖 Vue 或浏览器 API。Pinia 只保存运行控制、页签与忙碌状态，领域状态由 shallowRef 持有，界面通过 dispatch 执行命令。操作先成功写入存档，再展示新状态；写入失败时保留旧状态并暂停。

## 原型范围

当前是快速试玩数值，尚未完成正式数值平衡。先在单个应用内建立清晰边界，后续内容与工具阶段再拆 monorepo 包。当前只有一个自动存档位；三存档位、历史版本迁移、通用配置 DSL、NPC、离线收益、音效、PWA 和 Steam 不包含在本版。人生卷宗保存最近 180 条记录，命令去重保留最近 512 个 ID，不是完整重放日志。

原创 SVG 随项目提供，不依赖图片外链。界面使用本机中文字体。运行时没有后端、账号或遥测。
