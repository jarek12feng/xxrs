# 修仙人生 · 人物与资质版 v0.3.0

Vue 3 + TypeScript + Pinia + Vite 的本地单机修仙游戏。本版聚焦炼气到筑基、陆迟事件链与跨世传承。

## 启动与验证

需要 Node.js 22.12+ 或 24.x。

```sh
npm ci
npm run dev
npm test
npm run build
```

打开终端显示的网址。dist 可部署到静态服务器；更换网址、浏览器或设备前请导出存档。

## 本版玩法

- 三组等预算资质：根骨影响吐纳和护友，悟性影响研读、丹方与解阵，神识可凝神成长，用于控火和识阵。不是三种突破率加点。
- 陆迟新增两段中期互动、动态人物档案，以及四张统一形象立绘与两张场景插画；提示词与资源清单见 docs/character-assets.md。
- 自留孤丹获得一次护脉丹纹，并解锁孤灯丹诀传承；结算提示本世未探索的下一世可能。
- 长春医道：采药、炼丹；青锋剑道：更快吐纳、历练剑意，管理伤势。
- 第三月认识陆迟，第三十六月赴约；可选择失约，或进入遗府以草药、剑意、修为破阵。
- 唯一的遗府筑基丹可自留或赠友。赠友获得护法；信任影响护法强度。
- 积满 360 修为后主动筑基，概率来源公开。养伤、炼丹与固本均是可选准备。
- 陆迟故事结束且成功筑基，结算三种结局之一。篇章完成不等于人物死亡，后续境界暂未开放。
- 下一世重新选路，只携一份已解锁传承：长春丹札允许跨路线采药炼丹，青锋残谱允许跨路线练剑，渡口旧约开启前世记忆选项。
- 每次有效行动自动存档；切后台暂停，无离线收益。支持导入、导出和上一快照恢复。

## 旧档保护

v2 筑基篇存档自动接续，不重开、不重置修为或 RNG；默认补入明心善悟资质。已过去的中期互动不补发奖励，已结算自留分支补解锁孤灯丹诀。首次写入时保留 original-v2 原始备份。v3 保存全部资质、人物记忆与丹纹状态。

v1 存档读取时不修改原始数据。确认进入新篇后，以十六岁重新开篇，旧版人物和卷宗完整封存在新档的 archive 中，并在 IndexedDB 中保留 original-v1。可从界面导出旧版原档。旧版数值不直接套入新规则。

未知未来版本不会被自动降级覆盖；损坏且无可恢复备份时停止开局写入。请只在一个标签页游玩，尚无跨标签页并发锁。

## 代码结构

- src/core.ts：纯规则公开入口。
- src/chapter.ts：筑基篇状态、命令、事件投影、种子随机数、校验与迁移。
- src/legacy-v1.ts：旧版规则与校验器，保留回归覆盖和原档识别。
- src/save.ts：IndexedDB 双快照及旧档封存。
- src/App.vue：只读状态投影、命令调度与保存成功后更新界面。
- src/characters.ts：NPC 图像、台词、去向与已知经历的只读投影。
- src/legacy-v2.ts：冻结的 v2 状态校验与迁移依据。
- tests/：45 项测试，含原 120 组与新增 180 组资质/路线/结局的确定性完整重放。
- public/mountains.svg：原创矢量山景，无图片外链。

## 范围

这是筑基篇可玩原型，不是完整六境界正式版。尚未做大规模玩家平衡测试、移动真机验收、音效、PWA、多人、后台世界模拟或云存档。卷宗保留最近 180 条，去重保留最近 512 条命令 ID，不是永久操作日志。运行时无后端、账号或遥测。
