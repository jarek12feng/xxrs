# 筑基构筑数值修复 · 2026-10-30

本轮按用户“把发现的问题都修复下”调整筑基战斗的三种主修和补给提示。此前炼气数值审查及准备入口修复保留，见 [数值审查修复](numeric-balance-fix.md)。这次没有修改敌人属性、突破概率、修炼收益或经济公式，没有提交、推送或发布。

## 规则对照

| 项目 | 原规则 | 当前规则 |
| --- | --- | --- |
| 听松剑经 | 反击伤害 +8、承伤 +2，灵剑配装在部分后期关卡容错不足 | 保留原效果；上合守势或辨影后反击，再增加伤害 2、减少承伤 5。连续反击没有这项收益 |
| 归元息 | 阵法辨影额外伤害 +7、承伤 −2，阵法密集时优势覆盖较广 | 筑基规则 2 战斗的阵法加伤降为 +5；人族战、旧青嶂远征和规则 1 存量交锋不变 |
| 长春诀 | 回春依赖灵草，缺草时数场挑战没有找到胜路 | 首合守势或从其他招式转入守势，另减伤 4；连续守势不重复获得。原有耗草回复最多 7、受致命伤不能回复、击倒不耗草保留 |
| 行前补给 | 筑基准备区仅有修炼、疗伤及入场缺钱提示 | 长春不足 4 草时说明效果与建议量，提供既有购草命令；劳作提示同时预留 8 石购草和 4 石入场。建议量不成为入场门槛 |

连招收益在出招按钮提前展示。伤害、回复和耗草仍由同一预览/结算函数计算；界面只发命令，不修改游戏状态。没有新增持久字段或变更存档格式；已有规则 1 战斗保留其原计算，规则 2 战斗使用本次数值。相同版本的固定状态与命令序列仍确定性重放；不声称跨版本数值结果相同。

长春最初试调采用每次守势都减伤，复核发现会让长息对手的连续守势惩罚失去作用，最终改为转入守势才生效。当前中等准备下，长春连续守势不能击败江问荷；剑经连续同招不能通过争魁或最终试炼。

## 同条件实测

数据见 [前后矩阵及路线摘要](foundation-balance-data.json)，含修改前 HEAD 与修改后源码 SHA-256。两版均运行 216 个合成条件：12 场 × 3 主修 × 灵瓶/灵剑 × 普通/充分/零草准备。普通根基 12，充分根基 24；神识 8、心得 4、护身诀、一阶装备，其余条件见 `tools/foundation-combat-fixture.ts`。每关采用其配置修行值，计入对应传承与稳脉；这是控制条件，不代表各功法取得成本相等。

搜索每层保留最多 160 个不同状态，最多 12 合，先找最短胜路、再择剩余气势较高者。没有找到胜路不能推断绝对无解；路线数量不能解释为玩家胜率。

| 准备 | 修改前找到胜路 | 修改后找到胜路 |
| --- | ---: | ---: |
| 普通，8 草 | 70 / 72 | 72 / 72 |
| 充分，8 草 | 72 / 72 | 72 / 72 |
| 普通，零草 | 65 / 72 | 71 / 72 |

零草仍未找到胜路的条件是长春配一阶灵剑的离渡战。长春配灵瓶的零草 12 场全部找到胜路，配灵剑带草也全部找到；不通过抹去补给价值来保证任意配装都能空手通关。

最终试炼，普通准备，表内为“回合 / 剩余气势 / 耗草”：

| 主修 / 装备 | 修改前 | 修改后 |
| --- | --- | --- |
| 长春 / 灵瓶 | 8 / 22 / 4 | 8 / 27 / 2 |
| 剑经 / 灵瓶 | 7 / 1 / 0 | 7 / 11 / 0 |
| 归元 / 灵瓶 | 7 / 12 / 0 | 7 / 11 / 0 |
| 长春 / 灵剑 | 7 / 14 / 3 | 7 / 12 / 2 |
| 剑经 / 灵剑 | 未找到胜路 | 6 / 11 / 0 |
| 归元 / 灵剑 | 7 / 6 / 0 | 7 / 6 / 0 |

剑经配灵剑的争魁战也从未找到胜路变为 6 合、余气势 11。灵剑的抢攻收益得到兑现；长春配灵瓶仍以资源换容错，归元仍擅长辨阵但不占据所有阵法战的速度优势。上述只报告搜索结果，不把每条不同招式路线的气势变化归因于单一加减值。
