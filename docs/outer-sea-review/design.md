# 金丹外海开篇：实施范围

2026-11-02，承接凝丹双路成果。同一角色跨过云壁后，从古渡进入外海；不重置旧友、主修与往事，不默认旧友同步金丹。

## 可玩循环

金丹护体渡海 → 顾沧遥与叶问苓相识 → 约定共享潮图或独自勘路 → 备行装、退潮入外府、石卫交锋 → 首选镇潮印或澄息篇 → 温养/参悟与丹元积累 → 再探内府 → 取得另一机缘、兑现潮图约定。

- 顾沧遥是澄渊宗金丹修士，目标是修复潮堤、保障药船通航。叶问苓是衡璇院金丹阵修，目标是取回古墟观潮记录、校正阵图。不是跟随玩家的无条件奖励发放者。
- 共享潮图：行装灵石 6、灵草 2，交锋初始气势 +12；内府后两宗用公开潮图修堤。独自勘路：灵石 10、灵草 2，外府首通另得灵石 24，支路归玩家、原卷归衡璇院。永久记录约定，重进不重选刷收益。
- 初到航行六个月、灵石 12，熟路往返六个月不再收整备费。准备一月、进入两月；允许撤回。撤退不加伤，败退伤势 +2。行装仅在首胜消耗，失败与撤退保留；外府通关后不再重打。
- 外府与内府均为金丹前期石卫，战斗显示境界、气势、来势与实际动作预估。内府需修为 60，并已温养法宝或参悟功法。外府 +30 修为、内府 +45，只发一次，无稀有掉落抽奖。
- 镇潮印是下品法宝，温养六个月、灵石 8 后伤害 +4、护体 +3，原灵器仍可辅用。不是通天灵宝，也不是本轮新增的凝婴必备钥匙。
- 澄息篇首次参悟一年。续修原法：伤害 +3、保留原招式；改运澄息法：护体 +4、原主修招式暂停。两者不叠加，旧功法与研修保留，安全处三个月可切换；均提高金丹吐纳效率。
- 金丹前期修为 0–299，短修一年/常规五年/长关十年，按月结算与保存零头。中期突破尚未开放，不能打坐自动跨过瓶颈。

## 五十年之约

取宝后在古渡交接潮图，顾沧遥提到五十年后的诸宗会与照霜门，叶问苓约届时再叙。通知时间保存为对话月，举办时间 = 通知月 +600，不设新的常驻比赛导航。长关到会期时停下留信；本次只做告知，比赛尚未开放，不扣资格、不虚发奖励。

## 最新评估，尚未作为元婴规则实施

用户提出宗门间大比与秘境应成为必要经历，因为提供晋升元婴必需的宝物。评估：可以建立一条“大比争得资格或线索 → 秘境取宝 → 温养/试炼 → 凝婴”的核心路线，让两项经历都有不可替代的作用。必要的是完成代表性挑战，不是清空全部大比、秘境，更不是必须夺冠。大比达到一定成绩即可获取资格，失利后保留贡献或线索，后续挑战能够补足；秘境取宝设明确进度和失败恢复，避免纯随机掉落。五十年提前告知不能变成错过一次就永失机会，需补选或其他可追赶的入口。

替代来源方案也保留供比较：关键宝物必要，大比与秘境分别提供同用途宝物。前者更适合用户希望的金丹主线必经体验，后者提供更多路线自由。最终具体门槛与恢复周期尚待设计，不在本轮擅自改变规则。化婴丹、凝婴法门与适配的关键宝物分别承担丹药、功法、承载/护持条件；普通法宝不自动等于凝婴至宝，不把镇潮印事后改成唯一钥匙。以上是评估，元婴突破尚未实施。
