# 金丹外海开篇实施与验证

2026-11-02，本地未提交、未发布。范围与取舍见 [设计](design.md)。继承已实现的凝丹双路，不重新制作突破系统。

## 可玩内容

- 云壁之后可航行到外海古渡，相识澄渊宗顾沧遥、衡璇院叶问苓，听闻照霜门。两位新人物分别为修堤、校勘阵图而行动，旧友进度不重置。
- 共享潮图/独自勘路改变行装费用、战斗接应、首通收益和内府结局。遗迹外府与内府有两场金丹石卫实战；允许撤退和负伤恢复，已通外府不重打，无重复首通奖励。
- 外府先取下品法宝镇潮印或澄息篇，温养/参悟后真实改变伤害、护体和吐纳。内府前需积累修为、用上所得，打通后取得另一件。澄息守势与原主修招式不叠加，切换保留旧功法和研修。
- 金丹前期修为 0–299，闭关一年/五年/十年，逐月结算、保存零头，预估年龄与余寿，瓶颈不自动进入中期。
- 在取宝交接对话中提前 600 月告知诸宗会。没有专门比赛导航。会期到达会留下来信并截断本次长关；实际比赛尚未开放，不扣资格与奖励。
- 当前场景、地图地标、保存重载与成果回执承接外海进度；遗迹内禁止换装、制作或跳转其他行程。

## 工程验证

- 最终全量测试 92 个文件、684 项通过；生产构建通过；`git diff --check` 通过。构建仍提示主包超过 500 kB。

- 三主修 × 共享/独行 × 法宝/功法首选，共 **12 条**正常资源公开命令路线走通两层；[路线数据](routes.json)，工具 `tools/outer-sea-audit.ts`。每步校验存档与确定性，未直接注入资源。当前样本从凝丹后到内府约十一至十五年，只是这些脚本路线，不代表真人用时或成功率。
- 规则与组件回归覆盖两层成长、预估与实际修为、互斥与撤退、保存读回、重复命令、非法奖励、寿元不足、死亡、五十年消息截断、299 瓶颈、切换功法不叠加，UI 点击闭关与取宝。
- 浏览器通过正常导入加载公开命令生成的 [金丹起点](start.json)，实际点击渡海、相识、共享潮图、整备、进入外府、五合击败石卫、取得并温养镇潮印、交谈告知五十年会期，重载确认保留。
- 窄视口检查见 [截图](browser-narrow.png)，这是桌面内嵌浏览器，不是真实手机或 Windows 实机验收。内府的主要可达证据为公开命令路线，不冒充完整人工试玩。

## 素材与边界

古渡、退潮石道、内府三张背景从既有候选接入，见 [第一批来源](../art-candidates/golden-core-20261102/batch-one-review.md)。独立素材聊天补充的顾沧遥、叶问苓、镇潮印和澄息篇四张透明素材已接入人物/物品卡片；来源和 QA 见 [四张素材交付](../art-candidates/golden-core-20261102/sea-opening/README.md)。窄视口截图采于新增人物卡片前，不作为四张新素材最终布局的验收证据。

存档 v30，增加独立 outerSea 域，旧格式仅初始化空域，不补造人物/奖励；未知格式拒绝覆盖。美术按场景加载，不进规则状态。

未开放：诸宗会实战、金丹中后期突破、更多宗门独立地区、金丹拍卖扩展、凝婴关键宝物与元婴突破。用户关于必要宝物的建议已记入设计评估，不擅自把所有大比和秘境同时改为强制门禁，也不把镇潮印变成唯一凝婴钥匙。

自动检查不能替代陌生玩家的探险吸引力、两条路线选择倾向、长闭关节奏或设备验收。构建仍有主包体积提醒；未作性能达标声明。
