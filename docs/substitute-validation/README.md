# 筑基篇替代验证记录

2026-10-30。结论：在本次覆盖的单角色路线中，没有发现不可恢复的主线断路；但“知道怎样补强”和“理解来招与连招的权衡”仍影响体验。这里的自动角色不是真实玩家，完成比例不是玩家通关率，游戏月份也不是实际游玩时长。

## 方法与范围

从 `createGame` 新建角色开始，仅调用公开命令；不注入资源、不使用成品检查点、不搜索未来战斗路线。每步校验状态与非负资源，序列化后继续；完成路线重新从同一种子重放全套命令并比较最终状态。

矩阵为三资质 × 三主修 × 四种子 × 三行为 × 三战斗策略，共 324 条：

- 主线型：保留首枚筑基丹，不做恋爱、榜单与三个地方支线。
- 支线型：赠出首枚丹后补炼，走药庄共同契约、雪线修阵、旅亭修屋并回访。
- 失误型：首次挑战不主动补足灵草，每场第一次尝试的第二合故意选当前收益最低的招式；失败后恢复。不能将此解释为所有误操作或零草通关。
- 战斗策略分别是只比较本合伤害减承伤加治疗、正确理解当前来招、机械重复本场提示的连招。后者包含看见能击倒时直接收势。它们都是刻意简化的策略，不模拟人类认知。
- 每场最多四次：静养与补给 → 主修二级 → 根基 24 → 灵器二阶、辅修二级、神识 12，必要时额外修行至多 120。所有成本都从实际收入支付。不存在失败后免费变强。

所有路线都通过识阵修复青嶂关；未覆盖另两种过关解法、护送战线、雾海、全部榜单和恋爱支线。因此是从新角色到篇终的**选定完整路线验证**，不是全部内容穷举。主线政策含源码知识，不能证明界面发现性。

机械连招的 60 条在古道外缘用完四次尝试，涉及长春与剑经，不能记成软锁或证明无解。辨影—反击不是无条件万能解法：仍可能撞上重击；只看当前来招也会错过跨回合收益。这个压力测试保留失败结果，未为让所有脚本变绿而削弱敌人。

比较本合收益策略下，剑经全程败退中位数为 5，长春、归元均为 2。不能据此宣称剑经不平衡：主修、装备、前期路线和策略匹配会影响结果；但剑经准备教学与容错应继续重点关注。当前 120–203 次命令也不包含面板开关、阅读和演出确认，不能当成完整点击数，更不能直接换算成分钟。

初轮只补主修、根基、神识，没有精炼灵器或研修辅修时，部分剑经最终试炼在四次内失败。扩充**恢复策略**后通过；本轮没有改伤害、奖励或敌人数值。不能把前后差异写成“修改提示使脚本通关率上升”，脚本不阅读自然语言。

## 已修复的发现

1. **护身诀说明漏掉战斗价值**：实际装配有护体 +2、每级研修再 +1，但未学会时功法页仅写“历练不新增伤势”。补全说明，并将三主修的“青嶂交锋”改为“回合交锋”，避免误以为筑基不生效。
2. **连招信息出现太晚**：之前主要在执行后的结算文本里解释。现在按钮提前显示蓄势、探阵、特定下合连招收益；已有数值预览仍使用结算函数，不另造计算。详细修正折叠，减少按钮文字堆积。
3. **临死前仍容易误以为回春能救回**：当本合承伤足以耗尽气势，出招前提示改招或撤退；不禁用玩家主动承担风险的选择。
4. **最终试炼阶段提示与重复招式惩罚易混淆**：提前明确同招连用减伤害、增承伤，提醒阶段来招与换招需要一起考虑。
5. **古道目标过于笼统**：核实事故、辨认信号、外缘送补给、向程砚学稳脉、补到 420 修行的提示按真实阶段切换。外缘获胜后明确补给已经送达，不让玩家再次找材料。
6. **失败后准备建议不具体**：补充功法研修、护身诀、灵器精炼的真实成本与收益，说明修行门槛只决定准入，不能保证胜利。无新系统、无存档字段变化。

## 仍不能回答的问题

- 人是否愿意读完、能否自然找到每个入口、重复准备是否令人厌烦。
- 剑经较多败退是否合理，或应进一步降低学习成本。
- 真实首 30 分钟留存、完整篇章时长、付费意愿和金丹期待。
- 手机与 Windows 真机表现，以及长时间前台游玩的性能。

可以确认选定路线的规则恢复通路，也修复了实际看见的提示缺口；外部样本仍为 0。下一轮应优先观察首次外缘败退后的准备路径，不宜继续凭全知最优路线宣布体验完成。
