## 本次改变

- 炼气 Q1–Q5：药乡身世和自选入道心意、听松宗地位与传承边界、凝元前石涧药窟必经历练、因额外夺札引出的有限追索、凝元后家书。药窟需要准备、实战、处理药性和实际应用，原三路择一准备与晋升秘境仍保留。失败可以恢复、重试，不强迫杀人或独占奖励。[领域交付与成本](qi/README.md)。
- 筑基 F1–F6：师门身份回应、沉井旧刻度、三地取材均能进入的照玄必经历练、断碑驿止争、外宗消息和归山家书。让宝或弃争也须通过撤离险阵，胜出者另须稳定归路；400修行前检查完成事实。古道接应在完成照玄后开启，避免救援阶段与新门槛互相等待。恋爱、结契、额外争宝仍由玩家选择。[领域交付与成本](foundation/README.md)。
- 地图：全图加入药坪、石涧、青嶂支路、筑基六地、照玄与断碑节点，地域连线与当前地点一致。新增背景使用已检查的候选导出；全图底图复用原画，没有声称重新绘制地理插画。桌面地图加宽，修正窄屏地点列表在桌面误显示的问题，25个基础标记无重叠。
- 旅行：照玄/断碑进入统一陆路/御剑路网，离开以真实地点报价，抵达不赠送途经地战绩。旧直达古道线路保留。药窟/支路按原领域报价展示行程，不再叠扣时间。路线、距离、成本见[旅行设计](../world-travel-design.md)和[核算表](../wayfaring-review/travel-budget.md)。
- 保存与互斥：格式v38；v37及更早版本补空的新字段，不编造药窟/照玄经历或奖励，未知未来/损坏档仍拒绝覆盖。险阵、分宝未定和药窟现场阻止不相容活动；在特殊地点不能隔空执行父地点的普通剧情。旅行中断保存起点/终点/路径/剩余月份，读档继续不重复收费；从遗府回古道不会误判已经到达。
