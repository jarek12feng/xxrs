# 炼气剧情接入 Q1–Q5

2026-11-04。本目录记录炼气独立负责范围，未提交推送。共用 world、存档、地图、成长门槛、跨域互斥由主聊天合入；具体契约见 [integration.md](integration.md)。不能以本文单域验证代替全局验收。

## 已实施

- Q1：渡口“家中药囊”现场对象，交代药乡、长辈、同龄旧友、随队老药师调息与温蘅发现灵感；四种心意持久记录，不赠属性、不绑定主修，可先救人。
- Q2：炼气山下新增“药坪与药窟”近景入口，药坪交代听松宗丹堂/剑院同门、药路供给与守护、陆怀真及传承边界；根据实际宗籍称弟子或散修，不改变原入门/授法系统。
- Q3：淬脉后、凝元前开放石涧药窟。先说定合作/独行、选择药理诱引/护体过阵/辨阵解除、留退路，完成复用战斗引擎的90气势逆流阵，再分离或调匀药性，亲自用药液逆流调息。`phase=applied` 才完成；未完成时凝元入境与炼化均硬拒绝。原第二轮药谷/宗门/散修准备及原凝元秘境仍必需。
- Q3成果：应用耗灵草2、一月，伤势恢复至多1；凝元内府实际战斗护甲+1，`qiPower`统一预览/结算。无额外修为、灵石或稀有装备大奖，不把札记当通关。额外札记提供下一次内府的伤害加成：分抄+1，独占+2，留下无加成；交札止争会失去额外加成，核心药法仍保留。
- Q4：额外札记分抄/留下无追兵；独占才留下段厉索取风险。前往青嶂支路可交札退出、按先前守退路约定结伴正路、应战后擒送或止争。失败或主动撤离有限收束、只加可恢复伤势，不夺核心所学和晋升材料，不刷追兵。未实现杀死分支。
- Q5：凝元后药坪家书可写经历或托药队传话，回应“筑基延寿仍有尽头”和故乡生活变化；不改变青石原分丹、不强迫回乡、不锁定未来恋爱。

## 状态与流程

`qiJourney.narrative` 维护动机、药坪交代、家书、home/cave/branch位置、核心阶段、方法、同行、退路、药性、札记分配、有限截夺与战斗。所有持久变化复用 qiJourney 命令，局部观察不发命令，行动成功状态才呈现药液结果。校验器检查阶段、方法、药性、战斗位置与有限结局；缺失旧字段由主聊天版本化迁移，不补造经历。

`cave:depart`/`ambush:depart` 接父线程章节旅行，自己的目的地描述与报价使用同一领域接口。不在UI直接写位置。药坪属于山下安全区近景，无新的跨地区传送。

药窟失败退回山下，解法与退路保留，疗伤后再入。缺草时可主动退出筹草，已处理药性保留。实际应用跨月遇来信，退回安全处、保留processed、物资未扣，不会因中断默默通关。自动策略通过 `qiNarrativeNext` 提交真实命令；缺草/伤重会先退回交由既有恢复策略处理。
