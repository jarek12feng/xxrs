# 三境剧情增补：首批候选素材交接

日期：2026-11-04。用户授权其他 session 同步制作。本批仅制作设计候选，不代表剧情、人物或场景已接入。主设计见 [三境改编](narrative/10-existing-realms-revision.md)；美术遵循 [美术方向](art-direction.md) 与 [PC 场景要求](scene-and-time-contract.md)。

## 允许写入与交付

按下表分目录，只能写入所属目录；不改 src、tests、public、存档、其他设计文件和已有素材。不要提交或推送共享工作区，不覆盖另一聊天成果。新增背景均为无人物的可复用环境；已有角色以后独立叠加，避免烘焙未确认宾客与角色生死。

每批保留 originals、prompts、sources、exports、QA 和 README。记录生成工具、提示词、参考来源、实际尺寸、用途与 candidate 状态；输出 WebP 候选和原图。必须实际检查 1920×1080 及 1280×720 下构图、裁切和地面留白；生成器若无法给定尺寸，记录真实尺寸及调整方法，不能虚报原图分辨率。

使用 imagegen 技能与 image_gen 工具；不得借美术自行新增剧情事实。图内不生成文字、UI、logo、水印。背景不需透明，角色需透明，但本批不制作角色和逐帧动画。缺失工具或失败时如实记录，不能用占位图冒充完成。
