# 元婴续篇与三重天劫

2026-11-04，接续用户要求的“功法能修到元婴、丹药、战力与亲渡天劫”。本地实现，无提交推送。

## 实际流程

归潮深层凝神录与离照丹室实录互验 → 古渡核对完整续篇 → 十二月研修抱元归一诀或太素守神诀 → 圆满后到近岸试雷台亲自验法 → 化婴丹、灵地、外围护持及1200修为 → 三段凝婴行功 → 青霆洗身、紫电照神、合劫归一 → 元婴初成。

法门来自已经取得的历练资料，无额外买功法捷径。抱元续篇破雷伤害+8，太素续篇护体+6；不同主修共用剧情和规则。此处掌握完整元婴行功依据，元婴长期修炼仍未开放。

试雷与正式劫雷均读取真实修为、主辅功法、装备和法宝效果。护体、破雷、辨势有提前可见的雷势提示与同源计算预览；护体后的反击、辨势后的卸力有连续行动收益。三重雷势与伤害递增，气势和灵草消耗连续保留。每重最多十二合，禁止战中换装、研修或跨域推进。

正式行功消耗一枚化婴丹，三段结束仍为金丹；留存丹流和心神转为有限气势。天劫采用同时结算：已落劫雷不会因雷云被击散取消伤害，气势归零不能晋升。失败伤势3、丹已耗，保留修为、续篇、试雷经历与补药渠道。可静养、补丹、重新叩关；主动退劫伤势2。

神识接入共享接口：禁室初始心神18–26，识海回震按抗性抵减；凝婴心神获得0–4加成且封顶12。只有明确心神耗尽导致失败时增加识海创伤，一般天劫受伤不虚构心神损伤。

## 后续飞升场景复用

公共表现模块为 `src/scene2d/tribulation/TribulationWorld.vue` 与只读 `presentation.ts`。它不导入 State、不知道境界和三重劫数，也不派发命令。输入为当前阶段/雷兆/两条量表、人物静止与已结算动作图、落雷/冲击/护体三层资源、胜利文案与结果序号。公共组件负责短演出、跳过、减少动态效果和生命周期清理；恢复旧结果不自动重播。

`nascent-soul/ThunderWorld.vue` 仅为凝婴适配器，负责把三重天劫映射到该输入；背景仍由外层 NarrativeStage 统一切换。未来飞升灵界复用公共组件时新增领域适配器，提供自己的劫数、颜色、人物姿态、素材与胜利文案；不要复制一套演出，也不要把飞升规则塞进表现组件。规则结算继续走纯战斗引擎，公共演出没有改状态的权限。

`tests/tribulation-world.test.ts` 用自定义“第九重 · 界壁雷潮”输入验证非凝婴配置、结果变更演出、跳过、不重播旧记录与卸载后不回调。该测试仅证明接口可复用，**不代表灵界飞升玩法已经开放**。
