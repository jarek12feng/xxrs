# 离照洞天与伏潮湾：本地实现记录

2026-11-04。B所有权范围：`src/lizhao/**`、`tests/lizhao*.ts`、`tools/lizhao-*`、本目录与`public/art/world-story/lizhao/`。未提交或推送。世界/地图/存档/场景路由由父线程接入。

## 已实现

金丹后期从外海古渡按真实航程赴离照港；合作与独立勘探共用两层核心场景，准备可选护潮符或净药囊。外层分潮禁阵开通后永久保留，内层守炉傀儡与药池取材需实际多合交锋。每合预览伤害、承伤、耗草和下一合积毒；积毒到100败退，辨影排毒。大部分来势支持两种有效应对，共用现有功法/装备战斗计算，不只检测固定按钮序列。

首通发2份定性辅药；旧丹室以普通灵草试炉，验证分潮和定性顺序，不再消耗首通药份。`cleared + recipeVerified`是C的主线事实；`reagent`是C按每炉1份消耗的库存，耗至0仍是有效状态。公共补药仅首通且验证后开放，每份6月、24灵石、4灵草。

正常分享与保留自己所得无追索。主动扣下药商邵荃已预订余药可多得1份，操作前明示风险及补药加价。港口先传消息，玩家再决定结伴、设伏、绕行或暂缓；伏潮湾是具名人族韩砺舟，结局有赔偿止争、揭露雇契、击退、杀死与绕行。风险仅属于具体个人，不写成三宗全体阴谋。追索结局落盘，结束后不会随机重复追兵。

败退伤势+2、留下待排残毒，所有主药/辅药/法门与已开道路保留。港口每次3月、2灵草治疗伤势2并清除残毒；无钱无药可先回古渡筹备。主动撤退不加伤。世代进度不重置，元婴后保留历史、不可重领奖。

## 本轮数值与调整

本域为新实现，没有既有离照生产数值。首次试算中360/480气势、57/64攻势使多种正常准备路线承伤过高。按同一隔离角色与同一预览决策回归，最终外阵360气势/42攻势，内层420/44，韩砺舟450/52；未强化fixture角色来补偿失败。护潮符承伤−8；净药囊每合积毒−10；合作伤害+3、入场气势+16。结伴应对韩砺舟承伤−6；设伏前两合伤害+14。真实公共命令三主修另行验证。

扣药后的补药费用32石（原24+额外接应8）；赔偿止争或交出雇契揭露私雇后恢复24石。杀死、击退、绕行保留私人合作断裂，但公共必要补药渠道仍可达。不把强抢额外药份设为必须选择。
