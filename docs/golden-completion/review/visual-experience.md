# 金丹篇独立素材与现场体验审查

2026-11-04。结论：代表节点能经公共命令检查点进入，实际点击可推进问法、离照战斗、圆满试炼、结契见证、凝婴行功、出关正式观礼和旅行。但目前有 **1 项鼠标操作阻断**，以及人物、敌人、重要仪式与能力兑现的现场表现缺口，不能据此称金丹体验验收合格。

- [检查入口](visual-evidence/preview.html)、[检查点构造](visual-evidence/preview.ts)、[浏览器脚本](visual-evidence/browser-audit.mjs)。状态来自 goldenLateCheckpoint、finishGoldenCompletion 及公共 dispatch，未直接改境界、资源、关系或完成字段。伏潮湾分支从合法后期状态重新经离照两战、验药、强扣订药、听信、雇伴构造；不是无争议玩家被强追杀。结契状态走公共相识/定情/仪式命令。此为**代表节点隔离实测，不是正常新档全程试玩**。

## 阻断

### V1 / P1：离照和伏潮湾战斗右面板盖住敌方状态及鼠标撤退

复现：检查入口选择 `lizhao-battle` 或 `bay-fight`，1920×1080；尝试点击底部右侧“撤回港口”。[离照截图](visual-evidence/04-lizhao-battle.png)、[伏潮湾截图](visual-evidence/08-bay-fight.png)。

实际表现：右侧“交锋之中”面板只有一小段战况，却占据整个右部高度，覆盖底部 CombatBar 的右侧。敌方血量区域不可见，辨影排毒右半被遮，撤退完全被盖。刷新到最新工作区后再次以 DOM 命中检查确认：撤退按钮范围 x=1521.14、y=986.45、302.14×59.80，中心命中 `narrative-inspector battle-inspector`；普通鼠标点击 1.5 秒超时，错误明确为面板拦截。聚焦按钮后 Enter 能退到 harbor，duel=null，**不是领域命令失效，也不是全输入死锁**。证据在 followup-observations.json。

玩家影响：以 PC 鼠标为主的玩家无法使用承诺的安全撤退，不能直观看见敌方剩余气势；重要战术操作被无用空白面板挡住。应在继续增加素材前修复。

建议：战斗只保留一套不重叠的状态/招式布局；把 l.last 放进紧凑战斗栏，或让该战斗不生成通用 inspector。为敌方状态、三招与撤退统一预留安全区。核查源：`src/lizhao/LizhaoPanel.vue` 的 world slot/CombatBar 与默认 slot 战况；`src/scene2d/NarrativeStage.vue` 的 battle-inspector；不需新美术。

未验证：完整 App HUD 与其他屏幕尺寸可能进一步改变覆盖范围，需修复后复验；没有测试存盘失败或所有战斗类型。

## 重要

### V2 / P1：重要人物与敌人仍是名字框，无法形成现场交锋/问答

复现：`question` → 沈观微问法席 → “演示旧法滞涩，问接续之法”；`bay-fight`；`lizhao-battle`。[问法打开](visual-evidence/02-question-open.png)、[问法回应](visual-evidence/03-question-answer.png)、[韩砺舟交锋](visual-evidence/08-bay-fight.png)。

实际表现：问法席没有沈观微或玩家人物，只有写着姓名的菱形热点；点击后问题消失、问法数和文字更新，没有人物示范/回应。韩砺舟用写着“横刀立于回潮礁前”的矩形框代替持刀人族，守炉傀儡也用文字框。不能因有姓名而认定人物已入场。源码 `GoldenStoryScene.vue` 仅潮堤生成两个 named-person span；`LizhaoPanel.vue:115` 为文字敌人 div。

玩家影响：同道指导、竞争者威胁与敌人来势缺乏可见对象，角色身份和攻击方向无法从画面理解。顾沧遥/叶问苓已有资源，潮堤仍用名牌是接入遗漏，不应盲目重画。

建议：先接已有两宗全身资源，补沈观微与韩砺舟身份锚点和透明全身形象；守炉傀儡保持石雕古阵守卫，不能借怪物代人。最低演出应有朝向、预备、施法/格挡、受击/回应差分，由已成功命令结果驱动；名字牌保留作识别而不是主体。

### V3 / P1：圆满考验与凝婴前三段是数值面板，准备与突破缺少身体及器物变化

复现：`completion-trial` 点护体回元；`nascent-phase-0` 点循脉导出。[试炼前](visual-evidence/09-trial.png)、[试炼后](visual-evidence/10-trial-after.png)、[行功前](visual-evidence/14-nascent-phase0.png)、[行功后](visual-evidence/15-nascent-phase1.png)。

实际表现：空坐垫背景上悬挂数据框，没有打坐主角、六道封印或丹流可见形态。首轮护体动作 turn 0→1、心神22→21；循脉导出 phase0→1、丹流7→5、心神9→8，并消耗6月，说明命令有效，但画面核心只改字。准备热点“丹炉与药匣”位于没有对应器物的右侧台沿，真实炉子在背景左侧；圆满/凝婴界面中主辅药、化婴丹也只是数字。

玩家影响：诸多准备虽有规则，难以获得“我正在亲自叩关”的感受；阶段切换与风险逼近主要依赖阅读。凝婴作为大关卡，需要在准备、消耗、行功、失稳/成形四类状态上看得见结果。

建议：保留当前明确成本，把资源面板与主角打坐姿态、六印/丹流/识海的克制覆盖层连接；准备完成显示丹瓶入匣、灵地护持形成，失败显示失稳并保留可恢复状态。无需先追求全逐帧动画，可先做可靠分阶段差分与短演出。热点应按真实炉/药匣位置配置。

**雷劫例外**：本次加载的新工作区已有 [近岸渡劫台](visual-evidence/16-thunder.png)、全身主角、雷势条和三重天劫选项；`ThunderWorld` 已接新背景与雷击/护持资源，不能再列为“无雷劫素材”。此次只查看初始雷劫场面，未人工完整逐合渡完所有劫雷，不能宣称动画连贯与挑战性已验收。

### V4 / P1：结契、正式大典与首次元婴护渡均未换成事件现场

复现：`covenant-discussed` → 行前约书 → 请道友见证；`nascent` → 出关 → 正式观礼/谢绝职务；`ability`。[结契](visual-evidence/11-covenant.png)、[见证后](visual-evidence/12-covenant-witness.png)、[正式大典](visual-evidence/18-formal-celebration.png)、[护渡完成](visual-evidence/19-ability.png)。

实际表现：结契已经写出双方商议和见证，但苏婉宁、主角及见证者均未在场。正式大典文字列出苏婉宁、两宗轮值使者，仍显示空静室。护渡完成也在同一空静室上显示“测绘队已渡过”，没有古渡、测绘队或护持变化。`NascentPanel.vue:30–33` 仅雷劫分支换背景，其他事件仍引用筑基静室；world slot 除雷劫只显示 working-array 文字。

玩家影响：人物关系的重要承诺和升境后的世界回应没有可见兑现；“前往潮隙”与画面位置矛盾，地图即便已更新，也不能替代现场切换。

建议：结契使用已有苏婉宁身份资源和适当场景，主角/苏婉宁/宾客严格按当前状态独立叠加，不把见证者烘焙进背景；大典可复用问法席或宗门会场，加简礼/正式/暂缓的差异；护渡可复用古渡环境并补潮隙、队伍和护持覆盖层。先完成场景归属与角色出现，再增加精细服饰。未验证全部恋爱路线与宾客资格，本结论只针对合法结契检查点。

### V5 / P2：地点复用与固定热点错位，削弱离照/伏潮湾辨识

复现：`lizhao-verified` → 归港航路；`bay`。[丹室](visual-evidence/06-lizhao-chamber.png)、[伏潮湾](visual-evidence/07-bay.png)。

实际表现：丹室出口画在左上干廊道，归港热点却在左下潮毒渠上；“分药槽与旧丹炉”的固定坐标也不能同时贴合各背景。伏潮湾、离照港和外海古渡沿用同一 ferry.webp，韩砺舟文字虽说回潮礁，现场却是熟悉古渡。`LizhaoPanel.vue` 使用固定 points，bay/harbor 都落入 ferry 背景分支。

玩家影响：可点击入口易发现（有菱形和名称），但玩家并非在点击实际门、炉或人物；前往不同海域像只改标题。建议按 location 定义热点位置，出口锚定干廊道、炉锚定右后炉体；伏潮湾先评估复用海岸图裁切/无人物差分，离照港给出可辨地物，避免为数量重做所有图。

## 润色与文案

P2：问法面板“公开传讲承接沈观微的有限经验”“不要求夺魁、入宗或结契”，结契说明“单身同样可完成叩关”，正式观礼回执“没有人替你宣布更高境界已成”，能力收束“长期修行尚未开放”都带规则验收口吻。费用、失败代价应保留清楚，但放在报价/帮助，现场人物说具体话。

示例方向（未改产品）：问法可用“沈观微示意你近前：把行功时滞涩之处说来”；结契可用“长关在即，先把居所与信路商议妥当。是否结契，仍由你们自己决定”；护渡回执可用“最后一艘测绘舟越过乱流，船上有人向你举灯报平安”。未开放范围保留在章节结束提示，不让人物代说实现边界。

P2：背景复用并非都需重画，静室可服务行功；真正优先的是人物、器物、动作和事件切换。必要对象需名称和稳定的鼠标/键盘入口，不能只靠颜色或隐藏点击点。地图航线已明确列出 36,000 里、6月、抵达年龄与余寿，[出发预览](visual-evidence/21-travel.png)可读；不应为古风删去真实成本。
