# 问法石案：实操接入

2026-11-04。本轮将问法从一次点选即获得批注，改为提出疑处、两步试法、领悟收束。四个话题仍服务同一凝婴准备主线，不增加灵石门槛，也不以恋爱、夺魁或改投宗门换取资格。

## 实际内容

- 旧法接续：先缓旧脉，再候新流回转；两股灵流从相争到同息。
- 稳神：先守不断的本念，再分神听辨逆流；不能追亮光，也不能闭绝外界。
- 辨药：温盏辨清沉浮，再将浮毒引入空盏；真正取材、定性仍须亲赴离照。
- 布阵：先疏通回流，再以外圈护阵挡扰；供灵与护持不能挤在同一阵心。

每一步有明确可读线索与两个实际操作。错误会说明哪里不对，保留当前步骤，可重新调整；不因教学错误扣寿元、药物或灵石。问法的原核验年月仅在开启时结算。两步完成后才写入 `teachings` 与 `teachingSources`，地图发现和凝婴前置因此不会提前开放。

开场对白按长春、剑法、吐纳主修，以及退潮旧录、归潮经历变化。早期会谷问法为沈观微本人，年代久远或古渡入口为当值传讲者依公开实录讲解。没有合适人像时不假冒人物；石案采用程序化灵流、听潮环、药盏和阵盘示意，均由保存的当前阶段驱动。

## 保存与交互

`GoldenStory.practice` 保存话题、来源、步骤、错误次数与反馈，`teachingPracticeResults` 保存本次改版后完成话题的错误次数。旧档已获问法保留，不虚构做过新的试法。父任务负责 v42 迁移。离开现场后可回原来源续试；异地不能隔空完成。重挂载自动打开正在练习的石案。`teachingSolution(topic)` 为公共命令测试提供动作序列。

## 证据边界

规则与组件专项覆盖四话题完成、错误调整、序列化续试、异地拦截、重复命令、旧版字段与非法状态。主任务统一进行构建及全量回归。程序化图形是可读的试法反馈，不等同于逐帧人物演出；本说明不声称正常新档全程或 Windows/Steam 验收。
