## 实现

`wayfaring/completed-routes.ts` 根据已发布的新旧状态投影归途，复用原章节路线的地点、里程和方式：药圃 → 山居 1200 里步行、遗迹 → 古渡 1800 里行舟、归潮 → 会谷 900 里步行。里程沿用此前规划。

这是一份已结算结果的表现，不是再次安排一趟收费行程：月份、灵石、灵草均不额外扣除，奖励不重复发放，存档不新增字段。全局地图是唯一接管者；章节地图不会再复制一份。抵达后即使调用控制器的 `depart`，也不会再发送命令。关闭、暂停、跳过均仅改变表现。

只有实际地点变化且角色仍存活才展示归途。保存未发布、战斗仍在进行、只取得药圃胜利尚未取药、同地点比赛结束、寿尽等情况均不冒充返回。普通手动返回由原有旅行报价与续航负责，本批不改其费用。

## 验证方法与范围

规则回归使用自动化夹具执行真实 `dispatch`：三章各测战败与撤退，两处海境测胜利返回；药圃单测胜利留场、取药归山和不重复接管普通撤回。另测死亡、不变状态、会谷同场结束。

Vue 控制器回归同时挂载全局和章节控制器，验证保存结果发布后只出现一张归途图，关闭和再次调用动身不会派发命令或改变已结算状态。此前的普通返回、试剑归途、战后反馈回归保留。
