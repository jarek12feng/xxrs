# 大地图旅行实施记录

> 最新范围见下方“第二批顺序实施”；首批测试数量、未完成列表为历史记录。

2026-11-03，本地实现，未提交、未发布。设计与预先规划见 [世界地图、距离与旅行](../world-travel-design.md)。本轮依据最新筑基、凝丹、外海、诸宗会剧情梳理地理，不采用旧插画坐标推算距离。

## 已接入

- 筑基六处地点：听松行前居、无名渡、晴川药庄、雪线旧门、听雨旅亭、云外古道。由现场出口走近后展开路图，选择目的地和通行方式；山河见闻中的筑基地图也使用同一组件。
- 地理/里程/行速配置、路径求解、规则结算、存档、地图 UI 与路径播放分别封装。整程只取整一次，不逐条边重复收费；途中经过旅亭不自动完成支线。
- 陆路、筑基御剑、金丹回访内陆采用不同速度；遵守现有地点准入条件。学习不绑定主修：行前居研习一月→选择御剑试行→实际抵达后掌握。
- 预览显示路线、距离、行速、耗时、预计年龄和余寿；既有内比日期若会被跨过，出发前提示，行中传讯停下。
- 事件/寿尽优先；未抵达不发地点成果。剩余路程持久化，读档后只走余下月份；禁止在途中工作、换路、换方式绕过费用。可明确放弃并返回出发处，已用时间不退，本批不另收撤回费。
- `PathTraveler` 只接收路径、人物图、移动模式及播放参数。暂停、跳过、减弱动态、后台暂停与卸载清理统一实现，不触发游戏结算。只在父级回传成功保存后的抵达状态时播放。
- v32 新增 wayfaring 域。v31 只初始化空域，不补御剑、不补亲历；首次保存备份 original-v31；较新档拒绝覆盖。已有迁移链继续回归。

## 验证证据

- 全量 `npm test -- --maxWorkers=4`：126 文件、868 项通过。默认高并发首轮中，旧 balance-recovery 的五秒上限出现超时；限制并发后原断言完整通过，没有跳过测试或修改超时阈值。
- `npm run build` 通过，含 vue-tsc；仍有主包/渲染器超过 500 kB 的提示，未宣称性能验收通过。
- `git diff --check` 通过。
- 规则回归包括全部路对的对称性与整程取整、速度差异、非剑道学习、重复命令、死亡与事件互斥、不能飞越剧情资格、传讯停时、v32 合法在途存档序列化/迁移后继续、取消行程保留已耗时间、v31 备份和未来档拒绝覆盖。
- 原三主修×三条筑基成长路线、凝丹、外海、诸宗会与叙事连续性测试继续通过；这证明这些脚本路线可达，不能作为真人节奏/胜率证据。
- UI 回归确认到场景出口只开地图，明确动身才发旅行命令；地图查看不改状态；模拟保存未回传时不播放抵达；成功状态回传后移动到目标，结束/暂停/卸载无残留帧；减少动态直接显示目的地。
- 浏览器通过 `tools/wayfaring-preview.html` 的公开命令筑基检查点，实际点击研习→御剑试行→抵达无名渡→进入现场，看到 3 月陆路改为 1 月空路、首次飞行掌握及无名渡剧情。检查页不读写玩家存档；不是新角色完整人工试玩，也不是完整 App 的保存失败实测。
- 实际内嵌浏览器视口为约 320×669；[路图](browser-inland.png)、[御剑抵达](browser-arrival.png) 是窄视口补充证据。1920×1080、1280×720、Windows 与缩放检查尚未完成，不能以这两张图声称 PC 验收通过。

## PC 交互补充（2026-11-03）

本轮沿用 Steam / PC 优先：地图占主视野，右侧固定范围的信息栏；低高度桌面中信息栏自身滚动。隔离全局 header/footer 的高度和边距，御剑札记按需展开。地点扩大命中区域，支持 Tab、Enter/空格选择与焦点高亮；选址只更新预览，必须另按出发。Esc 收起地图并阻断全局系统菜单快捷键。复用 PathTraveler，未另建行走/飞行计时器，未改变路程与耗时规则。

检查工具为 `tools/wayfaring-preview.html`（公开命令生成的筑基检查点，不读写玩家存档）。浏览器视口 1280×720、1920×1080、2560×1440 下 document scrollWidth/scrollHeight 均未超过视口；实际用 Enter 选择雪线旧门、再选择无名渡并点击出发，显示陆路三月抵达。截图 pc-720.png、pc-1080.png。这是独立组件检查页，不能据此宣称主应用所有弹层、Windows 缩放、Steam 包或完整新档体验已经验收。

验证：旅行规则/界面 13 项通过；全量 `npm test -- --maxWorkers=4` 为 869 通过、1 失败（`foundation-growth-mainline.test.ts` 的三月后重逢目标：期望“还需 3 个月”，实际为“与苏婉宁同往无名渡，在入井前交流各自来意。”）。保留该问题，没有修改他处主线投影或测试来掩盖失败。`npm run build` 通过，仍提示大 chunk；`git diff --check` 通过。本轮未提交或发布。


## 第二批顺序实施（2026-11-03）

本批按“回归修复核对→实际应用旅行闭环→扩展章节路线→复用动效→节奏与 PC 验证”推进。先前三月重逢提示失败在工作区最新主线修正后通过；没有以删除断言掩盖问题。

### 已实现范围

- StoryScenes 统一接入开篇近郊、青嶂、雾海、炼气成长入境、凝丹道路、穿云壁、外海航路与诸宗会相关进退路线。地点与命令映射见 `src/wayfaring/story-routes.ts`。只接已有合法行动，不开放任意地点传送；照玄赴约等未列入映射的行动仍使用既有场景流程。
- 零月近郊行动不新增确认和年月费用；有成本的旅程显示里程、既有行动费用、年龄及余寿。航海时间继续包含候潮、接驳及探索，不能以普通御剑行速覆盖。地图预览读取原命令报价，不先试运行一次规则。
- 内陆和航海均通过实际 App 保存链路确认抵达后播放。外海/会谷逐月行动保存剩余月份，传讯后读档只续剩余时间；最后一月被打断也不会多收一月。放弃保留原地及已耗时间，不另收撤回费。
- 存档 v33 新增 `wayfaring.passage`。v32 只补空航程并保留原档备份，不给玩家补奖励；损坏和未来版本拒绝覆盖。旅行中不能穿插工作或另一条航程绕过费用。
- `RouteCanvas` 统一地图渲染，`PathTraveler` 统一路径、八帧步态、御剑起落及行舟尾迹，`useMapFocus` 统一焦点与快捷键，`useStoryTravel` 协调报价、存档回传和表现。动画不写领域状态、不扣年月，暂停/跳过/减少动态不改变结算。
- 男性炼气和筑基使用已有八帧行走素材；女性、金丹仍以静态人物标记沿路移动，不能称全角色逐帧动画。御剑和行舟为程序化动作与标识。
- 筑基抵达脚点按来向设置，药庄使用场内安全入口；同一地点的操作仍保留原脚点。
- 总览文案改用当前听松、筑基六地和金丹外海地域，删除未获当前剧情支持的昆仑/太虚/蓬莱占位地标。旧底图仍为示意插画，不按像素量距离；各章节位置仍归原领域，未建立全世界统一位置模型。

### 验证与 PC 证据

- 最终全量回归：130 文件、883 项通过（`npm test -- --maxWorkers=2`）；包含实际 App 保存失败不播放、重复点击不重复结算、退出地图不误开菜单、航程中断/序列化/继续/取消等。
- 实际 App 浏览器检查使用隔离 localhost:5281，通过界面导入公开命令生成的开发检查点。实走筑基现场出口→学习御剑→试飞无名渡→进入现场→刷新后继续，位置保留。外海检查点第一月传讯后，读档显示剩余五个月；续航回执只计五个月，抵达状态再次刷新保留。
- 1280×720 筑基地图操作位于可见底栏，右侧信息独立滚动；1920×1080 外海续航地图完整可见；2560×1440 主应用海图边界为 x24/y116/2512×1240，页面无外溢。证据：[720p 御剑](app-flight-720.png)、[1080p 续航](app-sea-resume-1080.png)。这是浏览器视口检查，不是 Windows 系统缩放验收。
- 最终核对中，清理旧占位地标后同步更新了两条地图契约断言；打包并行运行曾导致旧数值测试五秒超时。打包完成后以两工作进程独立全量通过，未提高超时或跳过测试。
- `npm run package:win` 成功产出 x64 NSIS 安装包和便携 zip（同时运行 vue-tsc 与 Vite build）。仍有大 chunk 提示；安装包未签名、使用默认 Electron 图标，属于本地测试包，未发布 Steam。文件大小及 SHA-256 见 [包校验记录](windows-package.md)。
- 全部 15 对筑基路线与常见旅程成本由公开规则生成：[旅行预算](travel-budget.md)，脚本 `tools/travel-budget.ts`。常见五程陆路 26 月，御剑 8 月加研习 1 月；固定脚本不能证明真人体验或会期压力已平衡。
