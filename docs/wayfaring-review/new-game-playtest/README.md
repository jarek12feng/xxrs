## 实际发现（尚未修改代码）

1. **读档场景回退**：在炼气历练完成护药实战后刷新，标题正确显示第15月；继续游戏却打开此前坊市行旅，提示旧伤药委托。手动选“炼气历练”后成长进度完整、目标仍为淬脉泉。是恢复视图问题，不是数值存档丢失。截图 restored.png 与 qi-completed.png。
2. **短途多一次点击**：雨夜渡口→药庐、药庐→雾林、雾林→山祠、山祠→药庐、听松→坊市共五次零月近郊旅行，演出结束仍停在地图，必须按“进入现场”。建议短途演出完成自动进入，长途保留结果/进入选择；需后续实现和回归。截图 nearby-map.png。
3. **成长目标分散**：领取功法后当前行旅指向回访/航图/坊市支线，进入洞府才看到修行安排；成长与行旅可切换，但新玩家容易持续跟支线。属于观察到的可用性风险，尚非陌生玩家研究结论。
4. **事件打断后的整备说明不足**：第11月点击一月整备，抵达第12月家书；选择后仍为0/3、灵草4，需再点整备至第13月，方扣3草并达1/3。没有重复扣草，但时间已用且行动未完成，应让玩家更清楚知道需重新安排。

## 本轮修复

1. 视图偏好独立于领域存档，绑定保存状态快照；读取后恢复已选择行旅。显式剧情入口优先于偏好，修复“重返旧阵”误入筑基行旅。
2. 免费、零月近郊旅行演出结束自动进入现场；需月数或资源的旅行仍保留进入确认。动画仍不结算年月或修改领域状态。
3. 试招结束回到修行目标；支线行旅提供可点击的修行目标，原回访仍可手动进入。
4. 行前来信打断后明确说明：已过一月，物资未动，准备未增加，需要重新安排；现场保留提示。
5. 入境按钮改为“查看行程与消耗”，成长路线完成与战斗准备分开说明；展示药理护身扣草后的剩余补给，提醒两战之间不会自动补满气势。
6. 筑基后洞府不再摆出炼气筑基丹/叩关操作；无未结行旅时的目标与筑基现场统一指向青嶂归路，避免落回可选寻亲提示。
