## 本轮修复

1. 刚筑基时现场全是锁定去向，却没有明确归路入口。行前居的人物/道路面板新增“前往青嶂旧路”，未踏勘时的对话也不再提前叙述共同勘路。
2. 洞府操作推进年月后，原行旅偏好与快照失配。成功保存命令后才延续偏好，读取其他快照仍须精确匹配；不把视图写入领域进度。
3. 首次抵渡规则将沉井阶段设为1，但人物显示只认阶段0，导致必选交谈时苏婉宁不在现场。共用“入井前待交谈”投影驱动人物、热点、肖像与对白；交流后独自入井，井内和战斗中不带入她。
4. 已学护身诀时，相识回执不再重复宣称新学功法。奖励和资源规则不变。
5. 地点快捷按钮和大地图共用默认行路方式，消除已学御剑后前者3月、后者1月的显示矛盾；路线距离与耗时仍调用统一报价。
6. 删除筑基准备提示中已过时的灵器精炼固定价格/减伤数字，引导查看丹器实时精炼报价。

以上修复沿用已有走近、行走、御剑和现场表现组件，没有另建动画结算逻辑。
