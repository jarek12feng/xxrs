## 实现约束

- `additional-story.ts` 为四类适配，仍调用统一旅行引擎；不会通过试运行命令推测随机结果。
- App 持有这批旅行的全局表现入口，使事件弹窗、人物页和师门页都可接入；原章节控制器不重复接管，原长途续航也不由全局弹窗重复恢复。
- 抵达判定分别核对保存后的遗府阶段、人物事件、同行阶段、擂台交锋或药运实际结算。药运完成即返回山居，是整段往返，不假装角色仍在交接点。
- 交锋自动结束的归途是已结算结果的表现，不再发送撤退命令；战后反馈保留，关闭地图不再次保存、扣月或发奖。
- 本批不新增存档字段。原单次事件中断语义保留，不声称这些固定任务已拆分成可被速度装备缩短的多月移动。

## 同时修复

人物出行与赴台原先借用劳作一月，再减去旧版 4 灵石收入；劳作实际已为 5 灵石，导致每次凭空赚 1 灵石。改用专用旅行月推进，消除劳作收益和误导日志。赴台实扣 4 灵石，人物相处无凭空收入，事件与寿尽优先保留。

战后结果展开时，原关闭条件会同时锁住归途地图。现允许关闭纯表现地图，再查看已经保存的战后结果；新行动仍受结果面板和保存锁限制。
