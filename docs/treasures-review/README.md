# 宝物与拍卖会接入记录

2026-11-02。本地实现，未提交、未推送、未发布。设计见 [宝物与拍卖会](../treasures-design.md)。工作区有其他进行中的成长改动，本轮保留这些改动，不将整个工作区归为本轮交付。

## 当前可玩

- 储物袋与灵器准备页均能进入宝物与拍卖会。镇岳钟、缚风索、照隙镜使用一个互斥辅器位，委托取得、装配/卸下、筑基精炼都有命令；灵剑/灵瓶继续保留主器位和原器纹。
- 钟：守势承伤 −2，反击伤害 −1；索：反击承伤 −2、伤害 −1；镜：正确辨影伤害 +2。精炼将对应主要效果从 2 提至 3。接入共用回合交锋，旧概率式关卡不增加这些招式修正。
- 钟、索委托各 28 灵石，镜 42 灵石，均耗一月；精炼 18 灵石、玄铁料 1、一月。炼气中期（修为 120）可用钟索，镜与精炼要求筑基。未持有、已精炼、交锋/事件中均拒绝非法操作。
- 坊市小拍要求炼气中期，筑基拍卖要求筑基。三席分别为未持有适用辅器、药物、未学功法；候选用尽转为仍可使用的补给，满神识不抽清心丹。高境界回坊市不会抽到筑基器物。
- 目录、NPC 最高预算、起价和拍次固定保存；查看目录免费，筹资后赴会耗一月。每口加价 2，玩家先设上限、逐口确认。对手无法越过自身预算。仅落槌扣费与交付，放弃不收费，离场保留已拍得物。
- 每场结束后至少十二个游戏月才能再领目录。现实离线不推进。入场期间其他成长行动冻结；主界面有返回竞拍/离场按钮，避免关闭面板后找不到出口。查看目录尚未入场时可正常筹资。
- 功法直接加入已学列表，仍由玩家装配；药物进入既有药物库存，沿用服用条件。拍品展示现有功法实际效果和常规来源参考价。筑基丹未进入池，保留遗府与丹方成长循环。
- 筑基中期看到镇潮印展品见闻，不可竞拍、装备或领取。完整法宝、金丹/元婴拍卖、通天灵宝、本命法宝祭炼尚未开放。

## 状态与代码

`src/treasures/` 分开配置、状态校验、报价结算、战斗投影和界面。`world.ts` 仅注册状态/命令/生命周期，`workshop/combat.ts` 合并辅器招式修正。UI 经原有保存成功后更新流程，无直接领域写入、无额外定时器或现实时间随机。

存档 v27。v26 只补空宝物域，不补物品、钱和参会经历；原始 v26 存档纳入备份。旧版原有迁移边界继续保留，未知 v28 拒绝加载和覆盖。新角色不继承器物或拍卖目录。目录已经公布后，即便玩家从其他渠道学会/取得同件拍品，也不重抽，出价时拒绝重复并允许放弃。

## 验证

规则与界面测试覆盖境界、20 种种子的候选变化、确定性重放、同命令防重、超预算/缺钱、NPC 有限预算、三类拍品到账、逐口竞价/放弃/离场、时间与寿尽抢占、装备互斥、精炼次数、错误存档及 v26 迁移。IndexedDB 保存恢复保留拍次、NPC 预算和下一口出价；恢复后命令不重复结算。共用交锋对照确认三种辅器实际影响对应招式，未装配无效。

开发浏览器使用独立端口 5267 与本目录 preview.html（仅开发夹具，不读写玩家存档）。按钮测试走实际 TreasurePanel 和公开命令；固定起点资源是开发检查点，不能算自然首玩。当前未完成 60–90 分钟陌生玩家全程、真实手机、Windows 实机或长期拍卖经济平衡验收。
