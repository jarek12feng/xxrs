## 来源与处理

使用内置 image_gen。最初两张提示词见 [prompts.md](prompts.md)，新增八张及两次修订的实际提示词见 [expansion-prompts.md](expansion-prompts.md)；工具返回路径见 [expansion-generation-records.json](expansion-generation-records.json)。未使用 CLI 回退、网络图库或其他画师素材。工具未返回模型版本、种子，不作推测。

新增图原始返回均为 1672×941。原图直接复制；压缩版统一裁切 `[4, 2, 1668, 938)`，再 LANCZOS 缩为 1600×900，WebP quality=85、method=6。原图不覆盖。所有实际图像内容修订均经 image_gen，Python 仅做授权的裁切、缩放、压缩和检查拼图。

## 逐张视觉 QA 与建议裁切

共同检查：最终十张未见可辨文字、水印、现代结构、突兀西幻结构或通天灵宝。人物均为中式衣冠的人族环境角色，未借图像确定具名身份。装饰纹理不承担文字信息。所有原图已目视检查，所有压缩版成功解码，并以 [800px/张检查拼图](qa-contact.jpg) 和 [390px/张窄屏检查拼图](qa-mobile-390.jpg) 复看；拼图底部英文编号是本地 QA 标签，不存在于候选图中。

1. **听松内比**：两名同门完整，点到为止，松林看台明确；下部石面留白可用。原图及压缩版另有逐张打开检查，详见 README。390px 仍能认出切磋场景，剑身细节变小。保持整幅 16:9，禁止竖向居中裁掉两侧人物。
2. **外海古渡**：断崖石阶、木渡船和海中岛屿完整，没有飞升仙界。390px 船与远海仍清楚。保持整幅；不能只取中心海面而丢失左侧古渡。更详细检查见 README。
3. **听松山远景**：松林山脉、石阶与朴素灰瓦石木殿堂形成从熟悉宗门向山脉展开的尺度；没有巨型皇宫。底部阴影岩石适合覆层。390px 能认出主殿及练功台，远处细小建筑只能作轮廓。保持 16:9；主殿在中右，不宜左对齐裁切。原图未出现需修订问题。
4. **外海水府宗门**：潮汐庭院、波纹石栏和铜铃可辨；深青衣冠人群互助搬运，支持协作印象。没有海底玻璃宫或巨大护盾。390px 可辨水庭、深青衣冠与人群，铜铃与手指不宜承担提示。底部石面/水雾低对比；保持全幅，若缩裁至少保留中部人物和左上铜铃。搬运只是环境活动，不代表运输玩法。
5. **雪山剑修宗门**：雪松、岩脊、灰白衣袍、窄袖与中式剑形成明显冷地辨识；两名同门练步而非残杀。底部雪影平静。390px 可辨雪山宗门，剑身与脸很细，不作对手肖像。保持全幅，或以中右院落为焦点，但不得裁断完整人物；不得用冰雪颜色暗示新增属性机制。
6. **古墟阵修宗门**：赭色平台、纸质路线图和铜阵盘明确；人物研读图册而非全息投影。首稿出现不合要求的圆拱遗构，保留为 `hengxuan-array-sect-draft-original.png`，不采用；修订版已将其改为中式横梁门构。纸上只有路径线，没有文字。390px 仍可辨桌案与观台，细小路径和盘纹不可承担真实解谜信息。左侧人物、中央桌案与右侧谷地共同构图，保持 16:9，不建议中心竖裁。
7. **海底退潮遗迹**：干石道贯穿前景至远岸，旁有潮池、海草和中国式门楼，退路可辨；左侧月洞门为中式庭院遗构。没有垂直水墙、现代海底设备或怪物。390px 主路径仍连续，水洼不能用作可点击路线标记。保持全幅，中心路径不可被 UI 完全盖住；建议 UI 仅覆盖下部约 15%–20%，而非大块遮挡中部干道。
8. **古墟内府**：修订版有明确缺失桥面、分层石台、阶梯和风化中式护法石雕；人物雕像不作机器人。首稿桥面过完整且齿轮突出，保留 `ancient-ruins-inner-court-draft-original.png`，不采用。修订去掉远景偏西式圆拱，机械齿轮改为克制嵌盘。390px 缺口仍可见，替代侧路细节不够清晰，真实路线选择必须由 UI/文字表达。保持全幅并保留中央桥口及右侧石雕；这是环境候选，不可当实际关卡通行图。
9. **宗门间大比**：辽阔山谷中小规模观战；深青、灰白、赭色衣冠和铜盘区别来客，同门对打无血伤；非西式体育场。下部石阶平静。390px 可辨两名交手者和分组观众，细小器物不能可靠识别；不借颜色把宗门写成单一性格。保留完整 16:9，窄裁会丢失两侧宗门群体。
10. **金丹拍卖会**：中式梁柱、屏风、封闭宝匣，侧桌丹瓶及线装书，陈列克制；没有现代槌、标价、巨型宝珠或西式药水。丹瓶带塞，书无文字。390px 能认出主展台与宝匣，侧桌器物偏小，不可替代 48/64px 道具图。保持全幅，避免右侧裁去丹瓶和功法；底部地面可用，但灯影存在，文字仍需衬底。

推荐窄屏统一等比横幅（390×约219px），不采用竖向 cover。静态缩略检查不等于实际手机截图、可读性对比度测试或运行时性能验收；人物脸和细小纹理尚不适合独立放大使用。未添加 UI 文本，因此也未验证最终文本对比度。
