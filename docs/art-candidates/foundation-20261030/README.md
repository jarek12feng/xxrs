# 筑基后剧情素材包

2026-10-30。独立候选资源交付，不修改游戏规则、存档或运行时资源。范围依据为制作时的主线、第一卷及 `docs/narrative/01–05`。后续剧情、候选人物背景及道侣事件是否实施，仍以开发文档与运行代码为准。

## 文件入口

- [图集](gallery.html)：按角色、场景、物件、效果筛选，切换深浅底检查透明边缘。
- [逐项台账](ledger.md)：交付状态与使用条件。
- [机器清单](manifest.json)：相对路径、尺寸、导出大小与 SHA-256。
- [需求与制作计划](plan.json)：有限范围清单，不自动随剧情无限扩张。
- `records/`：每张图的完整提示词、参考与生成来源。使用内置 imagegen；没有第三方下载图片。
- `originals/`：生成 PNG 原图；`exports/`：候选 WebP。生成目录仅用于溯源，运行或复用不得依赖工作区外的绝对路径。
- `build_catalog.py`：使用 Pillow 读取元数据、cwebp 导出，重建清单和图集；不修改 PNG 像素。环境需要 Python、Pillow、cwebp。
- [剧情覆盖与复用](coverage.md)、[声音复用清单](audio.md)。

## 本轮明确的形象要求

女性主角指玩家结识的成年女性道侣，当前为二十四岁的沈听澜，不是玩家选择的女性角色。她沿用脸型、长辫、绘图师身份与青灰主色。用户要求减少层叠衣片、绑绳、披挂与花纹，改用更简约、修身、适当露出肩臂和腿部的造型。另制作出行、绘图、庭院、月下相约四套不同剪裁和配色的场合服装；不把所有女性 NPC 改成同一风格。

`shentinglan-simple` 与七种姿态共用简约交领裙。四套 `shentinglan-outfit-*` 是独立服装候选；尚未为每套衣服再制作全部动作，也未新增换装系统。不得混用不同服装的姿态作为连续动作帧。后续接入按场景选择一套，再按需要补相同衣服的动作。

## 接入约束

1. 本目录不在 `public/` 下，不会进入当前试玩包，不代表玩家已经能见到这些画面。
2. 立绘和场景分离；按需加载当前场景与实际出场者，不能首屏预加载整个包。人物高度导出为 768，场景宽度 1280，物件宽度 384，保留透明通道与原图。
3. 关键文本、路线含义、针孔线索及工单内容由可访问 UI 表达，不能只靠小图判断。物件图不承诺奖励数值、传承能力或新境界。
4. 新人物均为候选；不将具名人族对手替换为妖兽。旧 NPC 的去向由实际剧情决定。纪念场所、旧物包不能用来推断人物死亡，未知、失联、死亡须分别处理。
5. 结契、相约、救援图只在相应事件条件满足时使用；职业工作与普通相识不自动产生恋爱。未看到炼气伏笔的玩家也可正常初识。
6. 这些是静态立绘和背景，不是骨骼动画或逐帧动作。动效层需要后续只读表现组件驱动；不参与规则状态或随机数。

## 验收边界

制作验收检查可解码文件、透明通道、构图、角色脸型/衣冠、物件识别和资源清单。候选通过不等于游戏集成通过；真实 UI 中的深浅背景边缘、移动端裁切、按钮对比度、加载峰值与 Windows 实机表现仍属于接入验收。

浏览器工具拒绝打开本地图集的 `file:` 协议，本轮没有绕过该限制；直接读取图片检查内容，图集交互尚未在浏览器中验证。透明图查看器显示的边缘有色像素需要在实际混合背景下复查，不能据文件存在宣称最终抠图效果完美。
