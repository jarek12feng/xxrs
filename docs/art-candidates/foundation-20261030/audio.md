# 声音素材复用与缺口

本轮美术交付不改声音播放代码。现有 `public/audio/original-v1/` 共 28 个原创程序合成 WAV；制作源码与来源说明见 `docs/audio-candidates/20261029/README.md` 和 `render.py`。没有使用未授权商业歌曲或第三方录音。这里提供明确复用映射，不将声音重新复制成多套同内容文件。

| 场景/事件 | 复用文件 | 触发约束 |
| --- | --- | --- |
| 渡口日常、药庄、绘图、庭院生活 | home.wav / work.wav / study.wav | 背景音乐按场景，工作音只在操作实际完成后 |
| 遗府、来信、断讯 | mystery.wav / discovery.wav / discern.wav | 发现须有新事实，重复查看不重复发声 |
| 外府挑战、归路禁制、外部接应 | trial.wav / strike.wav / guard.wav | 战斗结果真实成立，不能把纯展示当作攻击 |
| 同行、分别、远行 | journey.wav / vista.wav | 普通分别不自动用悲剧结局声 |
| 正常重逢、双方结契、双向脱险 | reunion.wav / closure.wav | 真实事件落定；未相识、失联或单方猜测不触发 |
| 医治、恢复 | medicine.wav / rest.wav | 不借画面自动推断治愈或发奖励 |
| 实际成长与突破 | upgrade.wav / breakthrough.wav | 以成功持久化后的领域结果判定 |
| 确认死亡与纪念 | death.wav / closure.wav | 只限确认事件；未知、断讯、遗物图片不触发 |

## 尚未制作的声音类型

现有包没有具体水岸、雨棚、船板、风铃环境录音，也没有人物台词配音。本轮没有生成这些录音，不把复用背景音乐称为补齐了所有环境声。无需阻塞静态候选素材交付；正式场景接入时可先复用现有氛围层，若新增专用环境声须另做来源记录、循环接缝和人耳试听。未验证新场景的 Windows 实机混音及长时间疲劳度。
