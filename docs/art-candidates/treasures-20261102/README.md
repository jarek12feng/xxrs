## 来源和导出

- `prompts.json`：五次调用的完整实际提示词，键与运行文件同名。
- `sources.json`：工具、生成日期、生成会话、原始落盘目录及文件名。工具没有返回底层模型版本，因此不推测或宣称特定模型。
- 器物调用均传 `transparent_background: true`，会场为 `false`；每件一次生成，无重绘候选。
- 先查看 `public/art/items/spirit-lantern.webp` 与 `vial.webp`，按其古铜、青玉和写实绘制质感写提示词。没有将它们作为编辑输入，生成结果并非逐像素风格复刻。
- 内置工具原始 PNG 原样复制到 `originals/`，保留工具默认输出。运行导出使用系统 `cwebp -q 90 -alpha_q 100`；器物另加 `-resize 512 512`，会场保持原尺寸。未进行背景抠图、重着色或程序补画。
- `qa-metrics.json` 保存运行资源尺寸、体积、SHA-256 和透明统计；`qa-contact-sheet.png` 是仅用于检查的深浅底拼图，包含 180、64、48px 显示尺寸。拼图由 Pillow 排版，不属于生成原图或运行素材。
