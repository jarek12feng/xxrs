## 1. 全卷目标与既有约束

主线仍是玩家突破境界、证道长生。同一角色持续成长，不轮回刷传承；“多玩几次”指同一个角色多次探险、参加不同届大比。先按男性主角承接苏婉宁，但恋爱和结契自主，散修及不恋爱角色可完整成长。功法可后天学习、兼修，各构筑共用主线框架。

依据 [主线](mainline.md)、[成长循环](progression-loop-contract.md)、[筑基设计](foundation-growth-design.md)、[女主主线](narrative/07-shen-mainline.md)、[宝物](treasures-design.md)。最新确认覆盖旧文中“金丹前后才结束女主营救”的提案：古道双向接应在筑基完成；金丹不再靠女主反复失踪推动升级。

金丹体验：结成金丹、独当一面、远行青玄界，亲历各宗传承与资源竞争。实力、地位、时间尺度必须改变可做的事情，不仅改称谓或倍率。突破后立即在后续行程兑现新能力，不强制回旧关领奖。

## 2. 全卷结构

结丹筹备 → 凝丹突破 → 首次远行与试用法宝 → 外宗共同探险 → 宗门间大比 → 竞争与合作进入深层险境 → 金丹圆满大关 → 凝婴筹备。

探险占主要篇幅，大比是中段高潮之一，不串成连续替 NPC 查案。每段写明：自身目标、能力缺口、至少两种准备/应对、资源成本、失败保留内容和下一段使用的新能力。真人体验决定现实节奏，不按“每阶段必须玩若干分钟”卡时。

| 阶段 | 难点与努力 | 进阶与兑现 |
| --- | --- | --- |
| 金丹前期 | 稳丹、温养法宝、研修原功法后篇或新法，短途试法 | 新灵力运转稳定；首次独立远行，不把每次小提升都设为强制副本 |
| 金丹中期 | 普通修炼资源不足，构筑有短板 | 新地域探险取得适配传承/材料、完善法宝；能够连续作战或应对特殊环境 |
| 金丹后期 | 单项强处不足以应对大险境 | 应对竞争者、路线、退路和连续补给，整合功法/神识/金丹运转 |
| 金丹圆满 | 明确凝婴缺口，取得关键机缘 | 完成本卷大关与人物收束；不是几次打坐直接免费元婴 |

关键瓶颈有修为积累和亲历成果，不能简单复制炼气“三路择一加秘境”到每段。金丹现实游玩时长、修为刻度、各行动年数暂不定死，先算完整路线收支并试玩。

## 3. 筑基到金丹

承接圆满、稳脉、贯流、归山成果，不重做整个筑基篇。寻找凝丹机缘，通过宗门内比两胜或秘境实战取得同用途主药，自炼/委托/合作取得丹药，选择灵地与护持，明确风险后叩关。

成功关卡必得关键主药；失败消耗当次药材、时间并产生可恢复伤势，保留路线、关系和修行成果。补取主药的来源、成本有上界，不能一次用掉就删档。不能用一次随机失败造成永久劣丹和元婴封路。

金丹寿元基准是 500 年总上限，不额外加 500 年；年龄继续累计，永久减寿单独保留。修行可选短修/常规/长关，出关目标、年龄、余寿可见；不靠现实离线惩罚。

## 4. 功法进阶与转修

两路并存：原功法寻找同源后篇；取得新法后转修。进阶不是一律淘汰原功法，转修不清空境界、不凭空遗忘旧法；主修效果不无限叠加，兼修有边界。

来源：探险传承、大比选阅/交换资格、宗门有分量的职责和实际表现、交换与拍卖补齐篇章。不得只靠重复交货刷贡献，散修有可达来源。

转修前展示资源、预计年月、已有招式如何处理、新法实际效果；明确研读、调息、试用的过程。外篇取得后先有用途，完整法门需要更深挑战；不能凑齐前所有碎片都是废物。

同角色可以多次挑战，但每次要有新区域、线索、可用外篇、人物承诺或实质进度。准备充分者可以更早成功，不强制刷次数。关键传承不依赖无保底低概率掉落；随机性主要丰富额外战利品。

## 5. 法宝、经济、拍卖

金丹元婴以法宝为主；元婴中期才开始听说通天灵宝。少量法宝先做清用途：破防、护持、干扰蓄势、续航；每件有消耗、配合和不适用情形。本命法宝仍是待评估方案，不预先承诺洗词条/升星系统。

原灵器可继续辅用、特殊用途或合理重铸，避免过去投入瞬间作废。金丹拍卖按境界入场，提供实用法宝、丹药、功法；必需晋升物不能只在随机目录出现。

法宝温养、功法研修、远行补给、突破储备统一核算。宗门合作和散修委托都有收入/恢复通路，避免金丹为主线无限刷低阶劳作。有限奖项不直接送齐下一阶段全部准备。

## 6. 元婴晋升条件

用户明确：化婴丹必备。它不是唯一条件。

| 必备条件 | 来源/准备 | 不能绕过 |
| --- | --- | --- |
| 金丹圆满及本境考验 | 自身修行与本卷大关 | 不能购买境界资格 |
| 凝婴法门 | 原功法对应篇章，或完成适配转修 | 不能只持有未研修玉简 |
| 神识准备 | 研修与亲历神识考验 | 不靠临时装备堆值代替 |
| 化婴丹 | 争取成丹，或取得主药自炼/委托 | 每次正式叩关消耗一枚 |
| 灵地、护持与身体状态 | 宗门轮用、租借或修复等可替代路径 | 伤势、灵气供应明确检查 |

大比可给成丹资格、主药、兑换凭证，不能只有冠军才能凝婴。失败损失丹药与时间，伤势可恢复，已学法门、神识成果、开通渠道保留；重新筹备有成本但不抹掉半卷努力。元婴突破本身须在失败恢复和突破后能力兑现齐全后开放；元婴整卷另列范围，不提前假开放。

## 7. 两级大比与沉浸式告知

用户最新要求：大比不是常驻专门入口。必须先在符合境界的同门交流、任务交接、归途或外宗道友相逢中得知；提前若干年，给玩家提升实力的时间。不能到场才突然开赛，也不能悄悄错过。

第一批参数：筑基中期后在一次师门交接/归山遇见同门，提前十年（120 游戏月）告知日期；通知显示举办年月、预计年龄与剩余准备时间。开场时长闭关/批量修行停下，带来同门传讯，玩家决定赴会或暂缓；不自动报名/战斗。无现实倒计时。首版会期一年，缺席无主线惩罚，后续交谈可得下一届消息；参赛后按章节完成，不用会期暗杀正在备战的玩家。

筑基宗门内大比安排在中期成长，奖励可用于后期；古道断讯/接应期间不插入新邀请，已收到消息也应先结束危机。参赛和夺魁均非晋升前置，散修不强行入宗。现有听松试剑榜保留随时练习职责，大比独立记录届次与赛果，但入口来自剧情。

首版三场点到为止的斗法，胜负均推进本届赛程；有赛前情报、可换构筑和补给、主动认输与赛后回应。三名同门有不同目标与风格，可在金丹篇再见。表现奖只按首次达到的新成绩领取，既不逼冠军也不无限刷低阶对手。三胜为本届夺魁，其他成绩有明确承认，不能失败也写冠军。

金丹宗门间大比先通过远行认识外宗人，再由他们提前五十年（600 游戏月）告知邀请。单人斗法、小队试炼优先，论法/技艺交流后补。不必全部参加；赛果改变合作条件、队友和后续探索邀请，不把主线封给冠军，不以单场比赛决定宗门存亡。续届有合理等待与其间可做之事，不空耗几十年。

## 8. 更大的世界与人物

先在青玄界选一个主要远行地域、少量据点；雪域、古墟、外海是候选，不一次全开、不急跨界。先做三四个持续交集的宗门，各自有修行方法、资源、职责和内部不同立场；其余通过可信见闻扩展。具体宗名和地域在对应切片定稿前属于候选。

探险类型分路线撤退、连续补给、遗迹机关、多方分宝与冲突。同一人物跨探险、大比和重逢出现，而非每地图十个一次性名字。竞争者可合作，也会守住自己的利益；有协商、交锋、撤出，不将所有宗门冲突写成灭门。

苏婉宁继续测绘与自己的修行，同行、分别、长关前约定与正常重逢；不自动追平、不因离线无提示寿尽。旧友有人突破、有人留乡、有人授徒，去向有消息来源，不批量死亡制造宏大。感情不替代修行，不重复筑基救援。

## 9. 实施顺序与验收

1. G0 本设计、入口同步，筑基宗门内大比完整切片：剧情消息→十年准备→赴会→三场胜负→奖励与回应。
2. G1 筑基圆满→凝丹主药→丹药/环境→突破与失败补取→首次金丹远行，形成完整可玩闭环后才正式开放。
3. G2 金丹前中期、法宝与功法进阶/转修、多宗门探险与重复探索的实质进度。
4. G3 提前告知的宗门间大比、具名对手延续、小队试炼和赛果后续。
5. G4 深层探险、后期圆满、化婴丹与凝婴条件、恢复路径；元婴正式突破单独检查新能力兑现。

模块分规则、配置、只读视图、存储和 UI。命令改状态，随机只用存档种子，所有收益幂等；事件/死亡/其他交锋有互斥，资源不负，未知存档不覆盖。保存格式变化更新版本/校验/迁移，不补造过去参赛史。

验证：三主修、宗门/散修、参赛/暂缓/错过、输赢/认输、恢复与改装、重复命令、固定种子重放、存读档、寿尽抢占、长关日期提醒。新手与熟练路线分别记年月、收支、有效决策与重复劳动。自动可达不等于挑战感、沉浸感或商业验收；桌面与窄屏视觉、真实玩家另记证据。
