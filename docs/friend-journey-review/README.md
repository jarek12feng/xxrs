苏婉宁金丹重逢同行正式告别后，在下一次实际耗月行动的首月开始一趟独立勘潮。仅使用已有可靠凝丹与联络条件；年龄超出可靠寿元范围不继续编造近况，不推定死亡。不按现实离线时间推进。
