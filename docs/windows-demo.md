# Windows 试玩版

当前冻结试玩候选为 `playtest-20261029-A`（应用 v0.14.0、存档 v14），目标 Windows 10/11 x64。本地单机，无需 Node、浏览器服务器或联网；没有 Steam SDK、账号、自动更新或付费功能。

本轮打包记录见 [冻结版 Windows 交付记录](playtest-windows-package.md)。给玩家的简短附件见 [试玩说明](playtest-kit/试玩说明.txt) 与 [反馈表](playtest-kit/反馈表.txt)；观察者使用 [完整试玩流程](first-30-min-playtest.md)。下文 0.10/0.11 等记录属于历史版本，不作为本轮 Windows 实机验收凭据。

## 构建与检查

使用 Node 22.12+：

```sh
npm ci
npm test
npm run test:desktop
npm run package:win
git diff --check
```

`release/` 输出 NSIS 每用户安装包和 zip。zip 必须完整解压后运行 `cultivation-life.exe`，不能只复制 exe。不要提交运行时和安装包到 Git。

`npm run desktop` 可在开发机器启动桌面版。`test:desktop` 在临时目录启动四个真实 Electron 进程，检查离线首页/图片、渲染进程无 Node 权限、关闭重开后完整状态及随机种子一致、当前快照损坏后回退上一快照并再次重启显示角色；不会读取或覆盖玩家目录。测试入口和测试代码不打入安装包。

仓库提供手动触发的工作流模板 `docs/windows-demo.workflow.yml`，用于在 Windows runner 构建、跑桌面存储测试、静默安装并检查安装后窗口能启动，上传安装包。当前推送凭据缺少 workflow 权限，因此模板尚未放入 `.github/workflows/`，GitHub Actions 暂未启用。有相应权限后将模板移入该目录即可启用。此工作流不创建 GitHub Release，尚未执行，也不覆盖真实玩家机器上的所有安装行为。

## 安装与存档

双击 `XiuXianRenSheng-Demo-0.11.0-Windows-x64-Setup.exe` 安装到当前用户并创建桌面快捷方式。安装完成后从快捷方式启动。

- 桌面档案目录固定为 `%APPDATA%\cultivation-life`；IndexedDB 位于其中的 `IndexedDB`。安装目录与存档目录分离。
- 不改变 `com.xxrs.cultivationlife` 应用 ID、`cultivation-life` 数据目录或 `xxrs://game/` 来源，否则可能读不到已有档案。
- 每次操作沿用现有写入事务：保存成功后更新画面。正常退出前请等待保存完成；默认保留 current 和 previous 快照。
- 卸载配置为保留用户数据；更新、覆盖安装和解压目录变更都使用同一档案目录。实际 Windows 卸载重装后读档仍需要验收。
- 网页版与桌面版的存储空间独立。旧网页进度在“菜单 → 备份与迁移”点“导出备份”，桌面版从同一入口点“导入备份”选择 JSON；确认导入前可先导出当前桌面进度。
- 额外设备备份使用“备份与迁移 → 导出备份”；如复制整个目录，先关闭游戏。不要只复制单个 LevelDB 文件。
- 当前包未使用代码签名证书，Windows 可能提示未知发布者。公开分发前应补签名和真实 Windows 验收。

## Windows 实机验收清单

1. 普通用户安装，检查快捷方式、中文用户名/路径、1440×900 和 1920×1080、125%/150% 缩放。
2. 断网启动，确认建角、场景图片、操作按钮均正常。
3. 新建角色并推进数次，记下姓名、年月、资源和当前事件；退出并重启，应完全一致。
4. 导出 JSON，关闭重启后导入，确认进度一致；取消导入不得改变进度。
5. 已有进度时重复运行安装包，再启动确认进度；卸载再安装，确认进度仍在。
6. 第二次启动应聚焦原窗口，避免同时写档。
7. 两条快照均损坏或新版未知存档时必须显示保护提示，不自动覆盖。仅在复制的测试档案中验证。

## 参考

桌面使用 Electron 的标准安全自定义协议承载 IndexedDB 与绝对资源路径：[protocol](https://www.electronjs.org/docs/latest/api/protocol/)。安装器采用 NSIS 并显式关闭卸载数据删除：[NSIS](https://www.electron.build/docs/nsis/)。
