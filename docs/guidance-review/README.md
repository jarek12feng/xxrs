# 全游戏引导审查与调整（2026-11-05）

## 最新约束

玩家只需知道当前阶段目标，不需要系统逐步安排操作。常驻提示给目标和眼前现象；人物、器物与道路提供可发现线索；失误反馈说明已经发生的原因。复杂挑战可主动展开进一步提示。不能为了探索感藏起资源、时间、致命风险、不可逆选择或硬性门槛。

本轮检查现有主线从药乡入道、炼气到筑基、金丹、凝婴及元婴护渡的目标投影、战斗来势、消息线索和关键试法。不是删除所有“先、再”字样：真实前置条件、已发生的过程、人物自己的计划、失败恢复与可选详细说明有不同用途。

## 调整范围

| 范围 | 调整 | 保留 |
| --- | --- | --- |
| 开场、药坪与坊市 | 目标改为求学、基础行装、补图；移除常驻的交谈—交药—试阵路线清单 | 初次装配教学；入宗/散修自选；行动报价 |
| 炼气、药窟、青石与护送 | 区分当前淬脉/凝元目标和已发现线索，古阵目标不再报出完整解法 | 必经历练、丹方/内府图缺口、撤退与伤势说明 |
| 筑基沉井、三地取材、古道 | 目标聚焦当前缺口；移除试运连招、接应整段流程与取材固定顺序 | 必要神识修习、培养门槛、可选取材路线及免费出口 |
| 筑基交锋 | 默认来势只描述真实敌招；原复杂战术和初试应对移入“查看应对提示（可选）” | 当前伤害、承伤、药草、已学能力收益和撤退成本 |
| 识海探阵 | 不常驻列出四轮顺序；主动展开局部征象与动作的关系 | 四轮/六纹目标、回震、创伤与免费恢复说明 |
| 金丹观潮、重逢与问法 | 常驻目标改为取得实测、护住本念等结果，资源与路径选择留在对象操作中 | 分工、来源、能力门槛、命令报价与保存状态 |
| 外海与宗门斗法 | “来势”从指定守/辨/攻改为重击、暗流、空隙等现象 | 实战预览、战术代价和致命后果 |
| 离照试炉 | 目标保留凝定条件，处理手法移到可选提示 | 每次操作真实耗时、封存辅药、失稳保留成果 |
| 凝婴、天劫与元婴护渡 | 缩短整章路线清单；雷势只描述现象，接雷与护渡策略可主动展开 | 正式天劫风险、有限资源、叩关资格、舟队位置与行进年月 |
| 结契、传讯、物品成长 | 礼式由双方商议；“接下来”改“相关线索”；新宝物回执不强制推荐固定连招 | 已学能力的准确效果、可选关系、已完成事实 |

拍卖、工坊、装备管理、突破报价、存档错误和失败恢复以选择条件/代价为主，保留其明确说明。已有的“敌情与应对”“交锋明细”“此地见闻”等折叠内容保留。没有为所有页面新加攻略按钮。

## 规则与实现边界

未修改战斗伤害、敌招顺序、成功条件、掉落、资源和月份结算，也未新增任务或存档字段（仍v58）。`foundationBattleCue`只保留观察，原策略拆为`foundationBattleHint`供可选详情使用；天劫`responses`保持原值。提示展开不发游戏命令，不写存档、不消耗回合，换敌时恢复折叠。

这轮是全流程引导层的审查与调整，并非所有关卡规则重做。已有确定性挑战仍沿用现有规则；能否让陌生玩家自然读懂线索、少查提示且不迷路，需正常新档真人试玩验证。

## 验证

新增组件回归：复杂提示默认关闭，展开不发命令，换敌后关闭，操作代价与撤退成本不进入折叠区；试炉验收条件和时间仍直接可见。既有用例保留地点/身份/阶段/动作/结算断言，仅同步改写的提示文本。首轮全量出现5处旧文案断言，修正后定向6文件32项通过。
