# 筑基行旅、听松试剑榜与金丹前收束

2026-10-30，根据用户“金丹前剧情全部打通”“筑基多些挑战”“听松试剑榜分境界”“上榜后奖励反馈”实现。当前工作区功能，不代表已提交、推送或发行。

## 已实现范围

- 在青嶂归路已记录后，从山河见闻进入“筑基行旅 · 青玄界”。听松行前居、无名渡、晴川药庄、雪线旧门、听雨旅亭、云外古道属于同一界；每次行旅消耗一个游戏月。旧药路线继续保留，未新增跨界玩法。
- 筑基修行独立累计 0–600，0/200/400/600 对应初期、中期、后期、圆满。吐纳每月 18 + 主修研修阶数 × 2，剑道历练 8，劳作 4；每场首次挑战胜利最多增加 40。上限后的奖励如实显示实际增长。每 100 修行增加挑战气势 4、伤害 1，每 200 增加护体 1；这些加成只作用于本次新增的筑基挑战。
- 主线：沉井守卫 → 三选一传承 → 离渡实战 → 交接出口 → 古道核实、接通信号 → 外缘与补给 → 向程砚学稳脉 → 内外接应 → 圆满后整理凝丹准备。六场剧情挑战含两场可选挑战，另有五场筑基争榜。
- 传承将对应主修研修至通达；装备后，长春守势／剑经反击／归元辨影额外伤害 4、减伤 2，必须实际装配。程砚稳脉在后续筑基挑战减伤 2。
- 无名渡寻姐与三份取证可选。郁晚舟在实际相见后才算确认生还；公开需相互印证记录与证言范围同意。可先护送或破禁出渡，后者损伤原簿，但可补查副联，不锁主线。
- 药庄三种交接、雪线三种处置、旅亭两种生活结尾均可完成、保存与回访。药庄回报灵草 6；雪线获得照夜篇并研修一阶；旅亭减伤势 1。不同处置保存各自交接结果，但尚无动态经营、工钱经济或持续运行的 NPC 日程模拟。
- 成年知己完成职业同行后，可约递信或旅亭碰面。既有定情后需两次明确表达才结契；朋友也可用灵草 2 换一份下场减伤 2 的共同准备。正常分别至少三个月后在行前居重逢，离开期间禁止同时邀请出游或雾海同行，不因现实离线扣好感。
- 已结契且正常重逢者，在古道触发有接应约定的失联；否则是闻岑的探索队事故。未知消息、确认避险、成功救回分阶段保存。内部同伴主动配合，程砚守外围；筑基期即可全部撤回，不把营救无限拖到尚未实现的金丹。
- 陆迟近况承接实际父亲来信与赠丹选择，未参加的经历不补发。

存档 v17，v16 及之前迁移时新域为空，不补发经历与奖励；无法识别的未来版本仍受保护。用户本轮不要求旧档体验兼容，但持久化校验与防误覆盖继续保留。

## 结果阅读与来招提示优化

常驻行旅结果和最近一场榜单结算现在先显示一句结论，详细经过、实际奖励与对手回应可展开；新结果到来时收起旧展开状态。即时结算回执保持完整，战斗中的逐合反馈仍直接可见。人物去向不再在同一面板紧接场景描述重复一遍。

来招描述与战斗共用同一回合 pattern：沉井与首次登榜保留明确教学，其余挑战描述实际动作（收势、换气、阵纹变化），不直接说出推荐招式。伤害、承伤、耗草预览继续保留；未改数值、结算、时间消耗、存档格式或随机序列。

再次从争魁检查点手动六合获胜，确认灵石 159→189、清心丹 0→2；手动展开旧结算确认内容保留，获胜后新结算默认收起。390px 内容宽度复查时将立绘改为占用约三成列宽，避免把来招文字挤成窄列。见 [动作提示截图](battle-cue.png)。此项不代表移动真机验收。
