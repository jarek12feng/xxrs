# 筑基战斗即时反馈 · 2026-10-30

用户授权实现气势条、实际伤害/回气飘字和关键效果短提示。本轮表现层接入覆盖筑基行旅与筑基试剑榜；不改变规则数值、存档格式、随机序列和资源结算。此前数值调整见 [筑基构筑数值修复](foundation-balance-review.md)。

## 实现

- `foundation-journey/feedback.ts` 从行动前状态、成功保存后的状态及本次命令投影临时回合结果，复用规则预览函数处理交锋结束后已移除的临时气势。伤敌与承伤截到实际剩余气势，治疗与扣除分别呈现；击倒不显示未发生的反击或治疗。
- `App.vue` 仅在 `persist` 成功后发布临时结果，保存失败不播放。读档/新角色/其他成功行动清除旧反馈；关闭结算回执时也清除。临时结果不进入存档。
- `CombatFeedback.vue` 在出招按钮上方显示双方气势，400ms 平滑变化、500ms 飘字；新结果替换旧计时器和飘字，不阻止下一次行动。组件卸载清理计时器。
- “循隙反击”“固护减伤”“辨影破核”“周天贯流”“沉井传承”“回春”等只读已触发效果；保留最后一回合的静态文字，供玩家和辅助阅读工具查看。减少动态效果时直接更新数字和文字，不播放位移或气势条过渡。
- 最后一击在获胜结算回执中继续显示，避免敌人临时状态清除后丢失反馈。重新打开普通面板不重复播放旧回合动画。
- 复用已有 `actionSound` 保存后播放入口与攻击、防御、辨影、受击、胜利等 WAV 资源，视觉组件不自行播放声音。本轮没有新增素材或重复触发音效；素材存在与音效路由已核对，本次不声称完成听感验收。
