炼气 100 年、筑基 200 年寿元基准保持；已受突破减寿仍保留。没有离线扣寿、强制失败或新增必做任务。金丹仍未开放。

沉井传承已有“直接授予对应主修通达”的规则仍保留，因此不能把提前付费研修假说成后续永久节约时间；本轮实际验证的可选节时投入是二阶灵器。装备还保留同阶攻守与越阶用途。

## 可重放证据

`before.json` 是本次修改前实际运行留下的审计数据，`after.json` 是修改后结果。它们是固定策略和控制条件数据，不是自然玩家成功率。

- 炼气：3 条准备路线 × 2 道途 × 3 资质 × 16 分散种子，共 288 条公开命令流程，修改前后均完成。首次筑基年龄由约 25.3–28.6 岁变为约 26.7–32.3 岁。修改后累计支出 236–300 灵石、劳作 30–54 个月、结余 0–44 灵石。这是主动选择劳作的保守策略，不证明劳作为唯一或最优收入方式。
- 18 条完整公开命令筑基流程：3 主修 × 3 机缘路线 × 普通／提前精炼。普通路线不入宗、不打榜、不恋爱，仍完成苏婉宁接应和圆满归山。普通路线从修改前约 36.5–39 岁，变为约 127.3–134.4 岁；提前投资组约 110.3–116.2 岁，实际节约约 17.1–19.3 年（含投资筹资和制作时间）。
- 普通参考路线圆满余寿约 65.6–72.7 年，提前投资组约 83.8–89.8 年。当前不是“人人逼近寿尽”的设计；更晚开局、错误准备、反复失败会消耗预算，后续金丹尚未计入。炼气期依然较宽裕，筑基期开始让数十年的机会成本可见。
- 105 组控制交锋：7 场 × 3 主修 × 无装备／两种一阶／两种二阶装备。固定构筑不是新角色路线；有界求解失败不等于全局无解。105 组均找到通路；长春二阶装备七场均存在换招解，连续守势均不能通过。
- 新增针对存档小数积累、跨速率预测、长闭关事件中断／寿尽／战斗锁、报价与升级、医修单招、玄鳞螈三构筑、准备节时及按钮发出真实命令的回归。
- 回归过程中发现并修正了速率分界预测误差：本月收益必须使用本月行动前修为判定阶段，不能取底层临时更新后的修为。
- 既有分散种子失败恢复回归继续覆盖首次失败、连续失败、无资源恢复和确定性。完整成长样本不等同于强制所有种子都经历多次失败。
