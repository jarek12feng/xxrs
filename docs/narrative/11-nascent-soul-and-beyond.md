## 1. 金丹后期至元婴的完整顺序

归潮所得与后期融汇 → 离照取药及传承取舍 → 金丹圆满综合考验 → 正视牵挂与交接承诺 → 可选结契/重温旧约 → 研成可续至元婴的完整功法并亲自试雷 → 化婴丹、灵地与护持就绪 → 三段凝婴行功 → 亲渡三重天劫 → 稳固境界和出关重逢 → 元婴大典 → 新能力实用与道侣机缘/高阶探索。

最新天劫实现与素材、无专属音效/BGM的实际边界见 [天劫记录](../golden-completion/nascent/tribulation.md)。三段行功完毕仍是金丹，须依真实战力应对劫雷并保住自身气势，最后才正式结婴。

取药、研修和灵地联络可以交错筹备，不要求按界面顺序重做已经完成的准备。圆满不是修为满后免费晋升；主线历练和本境考验必需，恋爱、清完所有旧案或替每个人完成愿望不必需。

## 2. 消息必须来自人和经历

| 阶段 | 信息来源 | 玩家得到什么 |
| --- | --- | --- |
| 初成金丹 | 陆怀真或散修引荐人说明自身传承限制 | 知道为何离开熟悉的药路，以及去找什么人 |
| 外海 | 顾沧遥、叶问苓交谈与合作 | 得知诸宗会及凝婴机会，提前备战 |
| 问法席 | 沈观微根据玩家实际修行成果谈缺口 | 明白化婴丹、法门、护神与灵地各自的作用，不凭好感直接获准元婴 |
| 归潮 | 定神珠、抱元凝神录、灵髓与实测阵压 | 必须温养、研修、应用，持有不等于掌握 |
| 离照 | 残存丹室与当代炼丹者互验 | 知道如何处理主药以及原法为何需要适配今世环境 |
| 圆满后 | 自身试炼和当面问法 | 清楚还缺哪一项、何种失败可恢复、正式叩关会付出什么 |

沈观微是第一位持续来往的元婴前辈，利益是稳定潮路、培养能承担探索的后继者。帮助需基于真实合作，不要求玩家无限跑腿；她的经验也受自身功法和认识限制。未受她指导者须能通过另一位合格传授者或已验证法门得到必要知识，不能因拒绝加入澄渊宗封死主线。

## 3. 圆满综合考验与道心无碍

圆满考验建议依托离照修复后的试丹禁室：玩家以自身丹元维持连续运转，在护神、护体与破禁之间安排有限资源。它验证金丹后期的整合能力，与归潮识海阵压、药窟药性处置有区别。不同主修有至少两种合理应对，失败保留取药、法门和已开通路线，恢复后重试。

“道心无碍”指正视真实欲望、承担作出的承诺、承认无法挽回的损失。它不是全体 NPC 好感满、无仇人或所有支线完成，也不是结婚后获得必成功加成。

圆满后开放一次行前整理，依据实际记录只取少量重要事情：

- 师门：交接已接受的职务，或者明确暂不任职；散修处理自己的合作承诺。
- 故乡与旧人：回信、拜访、交托或接受已经发生的离别。没有亲历的案件不强行要求忏悔。
- 恩怨：处理自己尚未履行的明确约定，或承认仍愿承担追索风险；不要求敌人原谅，不强制赔偿没有做过的错事。
- 伴侣/同道：说明长关与远行计划，尊重双方未来安排；无恋爱者也能与同道告别或独自立愿。

准备阶段必需明确作出自己的决定，随后突破中的定神阶段检验所选方案与实际准备；不以一句“我已放下”直接跳过行功，不把情感选择换算为隐藏善恶骰子。未完成可执行交接时给具体入口，不使用含糊的“尘缘未了”永久拦截。

## 4. 结契的重点场景

筑基已有结契能力保留。金丹圆满、凝婴之前是新增重点仪式窗口，不能把早期结契角色强行退回恋人。关系分支如下：

| 实际关系 | 场景 | 对突破的影响 |
| --- | --- | --- |
| 成年、已定情且经历充分，尚未结契 | 双方商议 → 亲友见证 → 礼后独处，明确同意才成立 | 无独占突破资格，不以高额聘礼为硬锁 |
| 已结契 | 重温原约，谈各自境界差距、长关与远行 | 保留原仪式和已有共同记忆，不再发一份婚礼奖励 |
| 已定情但暂缓 | 接受“叩关之后再谈”或先各自修行 | 不惩罚、不反复催婚，不默认分手 |
| 同道或单身 | 一次告别、祝愿或独自立愿 | 同样具备完整问心与凝婴通路 |

三场内容：

1. **商议**：在听松行前居或实际落脚处，两人决定居所、联络、礼仪规模和邀请名单。苏婉宁说清自己的测绘与凝丹/凝婴计划，不以放弃事业证明爱情。
2. **行礼**：沿用中式衣冠与朴素仪式，少量故人根据健在、知情、关系及能否抵达决定出席。温蘅、季衡、陆迟、叶照等都不是默认全到；远方友人可有来信。
3. **礼后**：宾客离去，整理旧图与行囊，共进一餐，谈失败如何照料、成功后去哪里。留有可回访物件，不仅弹“关系升级”。

正文台词基调：苏婉宁愿相伴，也愿继续走自己的路；玩家承诺联系与尊重，不承诺控制她的一切危险。仪式成功保存后才呈现信物与身份变化，取消、刷新和重复选择不能重复结契。婚礼不消耗多年寿元；有旅行和筹备成本则明示，不另造按日倒计时。

## 5. 凝婴筹备与突破

硬条件：金丹圆满、本境历练与综合考验完成、凝婴法门已掌握、护神准备已完成、至少一枚化婴丹、适用灵地与明确护持方案、身体状态允许、问心交接已作决定。化婴丹每次正式叩关消耗一枚。定神珠是现有路线的护神来源，其他等效来源如新增也必须通过相应挑战，不由普通商店直接替代。

离照取药是共同主线；宗门协作与独立探索可以形成不同准备。自炼与委托炼丹各有成本和能力要求；灵地可由故宗与外宗合作、以真实经历交换轮用，或修复已探明的独立静室。未入宗、非冠军、不恋爱者均能满足硬条件，但都要付出实质历练。

凝婴过程拟分“化丹归元—守识凝形—内外相合”，具体动作与损耗另做规则平衡；不把当前筑基/凝丹三步仅换标题。关键选择须依据已知现象与准备，正式风险事先可见。失败损失当次丹药、年月及可恢复伤势，保留修为基础、法门、护神成果、关系和渠道；重炼所需材料有明确可恢复来源与成本上界，无永久劣婴封路。

元婴寿元、修行速率与新战斗能力尚未定数值，不能直接沿用金丹 500 年或旧 legacy 数组。开放前必须完成全寿元收支、败退恢复与下一段能力兑现，不能先把角色 realm 改为 3 再留在无可行动界面。

## 6. 出关与元婴大典

先写私人的出关，再写公开的大典。稳固后见实际在场的伴侣/师友，以一个小动作确认平安；再由师门或友人提出庆贺。大典可选择简礼或正式观礼，也可暂缓。单身和散修都有成立的版本：散修由自己与合作道友择地设席，不自动入宗。

| 场次 | 玩家决定与现场 | 持久结果 |
| --- | --- | --- |
| 筹备 | 定地点、规模、邀请与愿意承担的身份；公布可负担费用 | 记录选择，拒绝职务不失元婴境界 |
| 故人相见 | 按实际经历安排来客、来信与缺席；旧师长可坦然接受学生已超越自己 | 承认原关系、继任和离别，不批量复活故人 |
| 外宗观礼 | 澄渊、衡璇、照霜使者有各自目的；座次与交谈体现新地位 | 记下具体合作意向，不等于所有宗门臣服 |
| 正式见礼 | 玩家介绍道侣或以个人身份受礼，可谢师、述志 | 道侣身份只来自真实结契，礼物按来源一次结算 |
| 宴后密谈 | 元婴同道谈高阶灵机困境、回星墟与古界路 | 提供下一程可信线索，未出席者另有同等可达的问法渠道 |

第一次大典主要兑现成果，不固定以袭击破坏喜悦。旧怨可体现为缺席、条件、试探或来信；若已有明确仇杀风险，先在筹备中提供应对，不突然强制死掉宾客。重要收益不能由奢华程度决定，不做无限宾客送礼刷钱。

苏婉宁有自己的来往与见闻，可在大典中取得测绘合作，而非只站在玩家身旁。她尚未达到同境时，不能让元婴同道自动把她称为元婴前辈。

## 7. 道侣的独立成长与元婴机缘

先补金丹期间的成长链：筑基归山后展示她准备凝丹的法门和材料；分别期间有实际合作所得，重逢确认成果；金丹阶段独立测绘潮路并学习护神。玩家可帮助但不能一键赠金丹，伙伴也不会随主角突破自动追平。

元婴后安排“回星墟同行”：她从多年的旧图与实测差异发现一条路线，带来研究、准备与自己的目标。玩家的元婴能力可抵挡外层界风，她负责辨认地势变化、建立退路，双方处理有限资源与其他探索者。她取得适合自己的凝婴机缘后仍需亲自研修和叩关。

同一遗迹也提供玩家所需的高阶修炼线索，保持双方都有目的。朋友版尊重独立关系；单身者可与测绘队或阵修合作，必要界路知识不被恋爱垄断。她已通过其他渠道突破时改为共同研究，不重复领取第二份凝婴资格。

暂缓帮助不触发现实离线死亡。若游戏年月接近角色真实寿元，须事先有可见消息、合理准备期与已知选择；首版不引入随机道侣死亡。失败保留勘路与已取得成果，可恢复重试，不能再用失踪绑架重复筑基篇。

## 8. 元婴以后、人界秘密与灵界

元婴初期：新能力在回星墟外层得到实际使用，能维持跨越旧险境的护持；大典带来的新合作与职责都有可拒绝边界。

元婴中期：回星墟实测证明高阶灵机受界路限制。玩家寻找适配当世的法门，争取通天灵宝相关见闻，见到有志化神却失败的同道。修炼仍能有进展，不设“全界无一条路可走”却要求继续打坐的假目标。

元婴后期：四方围绕“先修本界灵机、试开有限界隙、保守维持封界”发生分歧。玩家通过局部试通完成可验证成果，再争取化神机缘。选择改变谁投入、哪些地方承担风险与谁愿同行，不等于一句对白决定天下命运。

化神与人界卷收束：具备承受界隙的能力，完成稳定通道、保护本界与告别/交托。走向灵界前，明确单程成本、可能返回的条件和同行者要求。道侣若未具备条件可以共同筹备，也可以商议先后远行；不强制抛弃、不免费传送、不在切图时清空关系和功法。

灵界为后续独立地图，有自己的资源与人物，不自动成为仙界。长生终点定义见世界设定；本稿固定因果与伏笔，灵界的完整境界表和商业交付范围仍须另行规划。

## 9. 场景与验收要求

问心、结契、大典都使用场内人物、器物和道路作为入口，长文进见闻；不重新堆成文章式面板。关键信物、宾客、主人公与伴侣分层，避免把固定名单烘焙进背景导致亡者出席。减少动态与键盘操作不丢信息。

实现后覆盖：新恋人/早已结契/暂缓/单身，门内/散修，前辈不在场，故人已死/失联/未认识，三主修，败退与重炼，长关中断，仪式/突破/大典中途保存恢复，拒绝职务，重复命令与未来存档保护。真人复述需确认“为什么凝婴、谁告诉我、结契是否自愿、元婴后具体能做什么”，不以测试数量替代剧情体验。
