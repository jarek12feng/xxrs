## 1. 故事承诺

玩家最初只是一个能救下眼前药工的修士。随着修为提高，他开始有能力进入别人到不了的地方，听到别人不敢说的话，也逐渐发现：救出一个人、证明一个人无罪、让这个人以后能安稳生活，是三件不同的事。

主轴不是“所有门派都坏、只有玩家清醒”，也不是“为苍生便可牺牲任何人”。好人会在局势中留下不能推卸的责任；坏人可以真心爱自己的家人，但这种爱不会抵消他伤害别人的行为。玩家可以有私心，故事应回应其选择，而不是替玩家宣布道德成绩。

体验应在紧张、得意、亲近、失落和安稳之间变化。每章至少兑现一次主动成长：旧日必须绕开的危险，如今可以正面处理；过去看不懂的痕迹，如今可以查验。但力量只能打开调查和救援的路，不能自动替证人作证、替伴侣决定人生。

## 4. 人物设计：每人都必须想要一件与玩家无关的事

| 人物 | 欲望 | 不肯承认的弱点 | 底线与主动行为 |
| --- | --- | --- | --- |
| 郁青（既有） | 找到姐姐，把药队生意重新做起来 | 害怕“她自愿离开”比死亡更难接受 | 可以因玩家未经同意公开身份而生气；仍亲自送药，不站在原地等主角完成所有事 |
| 郁晚舟（姐姐，拟名） | 让受害者有不受追索的生活 | 擅长替别人考虑，容易替别人作决定 | 拒绝用另一批无名者替换旧受害者；必须面对自己替同伴隐瞒亲属的责任 |
| 沈听澜（既有） | 让不会御剑的人也能走远 | 容易把“公开”当作天然正确 | 尊重居住者拒绝公开住址的权利；愿意修订自己的名作 |
| 尹照川（既有） | 让归路无需某个英雄夜夜守着 | 口头讲轮值，实际总把自己排到最后 | 不接受伴侣以离别要挟他弃守；也必须兑现休息和交接的约定 |
| 温蘅（既有） | 尽可能让眼前的人活下来 | 救治经验可能被她当作替病人决定的理由 | 愿交出旧诊簿接受质疑，不要求恩情抵罪 |
| 季衡（既有） | 让护送队服从可执行的命令 | 把“我来担责”误当成已经向失去亲人的人交代 | 愿说明当年信息不足，而非声称牺牲都值得 |
| 祝庭（新） | 保住无名渡与自己的清白名声 | 认定幸存者依赖自己，因而自己有权管他们的未来 | 会销毁证据、限制离渡；必须有可证实的主动罪行，不能只靠气质阴险定罪 |
| 阙明棠（新） | 保住药庄与工人的饭碗 | 担心承认家业来路便一无所有 | 既可担当继承者，也可能继续推迟赔偿；玩家不能一句劝说便改变她的一切 |

## 5. 世界规则提案：用于公平推理，不新增万能法术

- **灵痕只能证明接触与顺序。** 探灵灯能显露残留阵纹，不能读心、判断善恶、给出人名。残痕可因环境消失，关键结论必须有另一条证据通路。
- **阵图是工程，不是愿望。** 改阵必须有人、材料、时间与维护记录。反派不能在高潮凭空解释“我早已控制所有阵法”。
- **回声是有限记录。** 只重现留下痕迹的一段声像，不能回答新问题；孤立回声可能缺上下文。不得用回声单独给活人定罪。
- **阵引伤害是既成伤害。** 可以医治、减轻，不能一场胜利便让所有人境界尽复、记忆尽返。角色可以健康地活下去，不必以终身痛苦证明故事深刻。
- **寿元与闭关会影响约定。** 新任务不能偷偷绑定现实倒计时或一次长修炼造成不可知的死亡。关键变局须在选择前说明，使用明确剧情阶段，不暗改原月份语义。
- **玩家也能选择不查。** 不强迫读完每篇案卷才能主线成长；知情拒绝、暂缓、以后回来都是有效体验。拒绝爱情不封锁案件真相。

以上是未来叙事约束，不是现有规则的实现描述。每条落地仍须有可操作证据与验收，不能仅凭旁白成立。

## 6. 类型借鉴与原创边界

采用修仙网文常见的有效结构：低处人物被忽略的愿望、有限资源下的救人、旧物在成长后显露第二用途、公开胜利背后的私人代价、人物重逢后不再是原来的自己。采用悬疑的先置线索、动机与手段分开验证；采用爱情故事的共同事业、亲密小动作与相互修正。

具体人物、地名、案件证据、对白和结局均为本项目原创提案。本轮没有把某部小说的角色关系、标志桥段或原文搬来，也不声称已经逐部研究网文作品。后续若要指定参考作品，应单独记录“借鉴的叙事机制”，避免做换名复述。

不采用：强制失忆维持误会、连续假死、救命之恩兑换爱情、把所有女性写成等待营救的人、把善良路线做成数值惩罚、每次查案都靠最后一刻出现的新证人。
