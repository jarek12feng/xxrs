# 筑基同行、秘境分宝与恩怨

2026-11-02。依据本轮多次沟通确认；本页覆盖“每个阶段回旧药路升级处理办法”的旧提案。最新方向是继续走向新地域、新挑战，以约定和具体机缘吸引玩家突破，以少量有分量的故地重逢收束经历。

## 已确认的设计原则

1. 主线向前走。筑基初成在青嶂兑现一次旧困难，篇末归山回收成果；不在初、中、后期反复回同一段药路刷职位。中期取材、后期接应、归流要有不同职责，已走通的外缘不重复收费、打怪或领资格。
2. 秘境可以提前相约，达到约定境界再同去。门槛须有罡风、护体持续时间等世界内原因，提前展示值得争取的收益。伙伴各有所求，可靠同行和利益冲突都存在；不让好友随机变脸。
3. 出发由玩家决定。不按现实离线计时、不暗中判失约、不以迟到随机杀死伙伴。单次约定是可选成长经历，不封锁其他路线、苏婉宁主线、恋爱选择和晋升。
4. 独一份传承需要事先约定、当面协商。让宝、坚持协商、先夺宝、战斗撤退应造成不同资源和关系后果。谁先毁约必须记录；同伴态度取决于事实，不因玩家获胜自动认同。
5. 强大增加可做的事。战斗准备影响争夺结果，得到的方法有下一场即可使用的效果；恩怨不靠无限强敌拦路或清空成长惩罚玩家。
6. 师门任用承认已有亲历。合适的秘境成果可替代重复晋职差事，但任职仍可拒绝。丹堂、剑院、散修都保留自己的出路。
7. 苏婉宁不为反转临时改成夺宝者。本切片使用两位独立道友，不改变她相识、合作、分别重逢与双向营救的主线身份。

## 当前实现：照玄之约

本轮已接入规则、界面与存档；下列资源数值为当前实现，不是已经通过真人体验验收的结论。

### 人物与所在位置

- **贺崇**：筑基中期人族修士，旧伤妨碍进一步修行，惯用长剑。入府前说明寻补脉之法；面对唯一玉简拒绝药资交换，坚持留下传承，协商无果时毁约夺宝。可止争，不默认邪修，不将其画成妖兽。
- **叶照**：筑基中期阵修，寻找可带走的阵图，负责退路，重视分取约定。见证谁先毁约；贺崇先夺宝时护住玩家留下的阵钉，玩家先夺宝时不再护阵。非恋爱角色。
- 无名渡初遇，约定中期后在云外古道支脉“照玄遗府”会合。不要求回渡口再领任务；沿已有古道取材路线打通外缘后直入内府，不新增地图往返或另一份晋升主材。

### 先准备，再争宝（2026-11-02 最新修订）

- 宝物须值得争：护脉法改变后续筑基交锋的攻守，取得时不再附送金币与修为，避免一次争宝包办所有成长。
- 取消灵草 6、灵石 12 稳拿传承的选项；贺崇的旧伤不是少量药资能解决的。新角色只有战胜争宝对手才能得法；可让宝保交情或退出，但不会同时得传承。
- 贺崇由气势 160、攻势 23 调为气势 200、攻势 28，仍属筑基中期。境界门槛只是入场条件，不保证胜出；不加隐藏随机掉落或必败脚本。
- 入府前展示对手、己方攻守和当前整备缺口。主辅修研修、灵器精炼、养伤、备草、继续修炼均沿用现有机制，不增加准备清单硬锁。
- 失败伤势 +2、失去已用时间及补给，不得玉简；已得晋升主材保留。可继续成长后再战，也可正式放弃，不要求重打外缘或重复赴约。
- 不增加持久字段，旧 exchange 记录只保留读取，新命令不能再产出该结果；不为旧进度补奖。

### 操作与后果

| 段落 | 可操作内容 | 保存的后果 |
| --- | --- | --- |
| 相约 | 筑基后在无名渡答应或暂不同行 | 答应月份、是否赴约；谢绝后仍可改变主意，无失约倒计时 |
| 会合 | 筑基修行至少 200、离渡完成、古道外缘已通 | 不可用灵石或简单交货跳过外缘实战；若已通关不要求重打 |
| 入府 | 一月；灵草 2 留稳退路，或不耗草轻装深入 | 留退路且贺崇先毁约：争宝首合承伤 −4；轻装首合承伤 +3；玩家毁约得不到叶照护阵 |
| 让宝 | 收灵石 24，把唯一传法机会让给贺崇 | 玩家不得该法；保留交情，同样有一次补给 |
| 坚持协商 | 先不自动开战；贺崇抢简、斩向阵钉 | 贺崇毁约，叶照作证；玩家选择争夺或撤出 |
| 玩家先夺 | 明示毁约后果后，进入争夺 | 贺崇结怨、叶照失信；战胜也不能领取守约补给 |
| 争夺 | 使用现有回合战斗，具名人族对手贺崇；开战一月，无额外灵石费 | 胜后获得该法，不另发修为与金币首胜奖；败退伤势 +2，主动撤退不增伤 |
| 撤出 | 保留其他机缘、主材、已有修为与准备 | 可继续原晋升路线；以后追索只再战贺崇，不重打外缘；也可传信放弃追索 |
| 止争 | 未得玉简则放弃追索；已得法者付灵草 6、灵石 24 补偿治伤 | 双方停止追索，已学方法保留；不自动恢复信任和补给，不刷和解奖励 |

**照玄护脉法**是不可分抄玉简所授的方法，不是可反复交易的新材料：筑基交锋中守势之后接识阵，伤害 +6、承伤 −3。受法后玉简碎去；不凭空生成第二部原本。收益在同一战斗计算与预览中体现。

**任用承接**：让宝或在对方毁约后夺回玉简，可作为可靠亲历替代“首次主持筑基药运”；仍须中期、取材炼元，门内角色仍须受录内门。主动毁约夺宝不取得这项师门认可。既有药运路径保留，未参与照玄之约的玩家不受影响。

**归山回收**：尾声与履历分别记录相约、让宝、谁先毁约、是否止争。结仇后的当前实际作用是追索交锋、拒绝补给与不同人物回应；未实现随机追杀、跨地域仇敌事件或全世界声望传播，不作此承诺。

## 筑基阶段安排

- 初期：青嶂旧困难、无名渡传承；提前看见中期同行的目标。
- 中期：三路择一。选择古道者可同程赴约争机缘；另两路仍完整可达，不要求专程补清照玄府。
- 后期：整合周天、双向接应，已有手段参与挑战。照玄护脉法可用于后续实战，不新增一轮回旧府考试。
- 圆满：长风归流在圆满前完成，晋升回执改为归山与未尽行旅，不再让玩家重复准备已通过的考验。金丹仍未开放。

- 独立模块 `src/secret-pact/`：持久状态、纯规则、只读展示、组件分开。顶层命令 `secretPact`，所有增减资源与记录由命令处理。
- 争夺接入既有筑基战斗；不新增随机背叛，固定状态与操作保持确定性。月推进若遇死亡或事件，入府不扣药、不发奖。
- 秘境字段在存档版本 25 引入；当前工作区还含并行学习流程的版本 26。24 及更早支持版本升级后约定为空，不伪造相识和奖赏。非法分支、无资格传承、重复领奖与未来版本拒绝，无法识别的原档保留。

## 2026-11-04 分取与补给的结算接口

让宝补偿灵石 24、守约后的回春散 2 及止争材料仍采用原有剧情条件；`pactQuote` 显式提供成本/奖励并检查可保存容量。命令重验后通过 `economy` 原子结算，成功才记 outcome、supplies 或 settled；不能在报酬未到账时认定已分取/已收信。容量不足保留原选择现场，恢复容量后可重试，不自动替玩家选择争夺或离开。

选项通过 `story-interactions.projectInteractions` 投影，按钮读取同一份 available/error，执行仍发送原有意图。此轮没有改动贺崇/叶照立场、交锋胜负、护脉法效果和人物后果。证据见 [模块接入审查](../module-integration-audit-20261104.md)。
