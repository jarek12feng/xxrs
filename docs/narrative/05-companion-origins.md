# 知己来历与炼气伏笔

2026-10-30。补充 [后续大纲](04-companions-and-world.md)，为后续剧情与素材制作提供共同依据。**首批已接入：药庐路图、护送归途旧灯、初识回收与家世谈话。** 下文其余接点、远行及救援仍是提案。现有姓名、人物志向与成人身份沿用。

## 设计目的与边界

让筑基后的初识产生“原来这件事是你做的”的回响，让玩家认识一个早已在世界中生活的人。炼气仍以准备筑基为主，不插入一条必须完成的爱情任务链。

先认识事迹、做法或名字，再见到本人；不预告谁一定成为玩家的道侣。伏笔在未成年阶段只能是普通社会交集，不出现暧昧、婚约或成年角色等待玩家长大等表达。成年后的恋爱由双方选择。

两个人都可以作为世界中的修士被听说。现有异性配对规则决定可发展恋爱的对象，不要求未选择性别的玩家提前分流剧情，也不把另一个人从世界中删除。

## 沈听澜：不想只画别人已经走过的山河

| 层面 | 拟定背景与作用 |
| --- | --- |
| 家庭 | 出身经营小型刻印铺的家庭，从小接触旅图、行商账册与抄本。家人希望她画可售的图，生活安稳；不是落难公主或等待复仇的遗孤 |
| 修行来历 | 先学测绘，再随一位行脚修士学习修行与野外辨路；师承暂不命名、不新增宗门。修行让她能到达普通测绘者到不了的地方，但她仍须补足交锋与自保经验 |
| 个人愿望 | 既想绘凡人能用的道路，也想亲眼见到旧图之外的天地，留下属于自己的作品。公共理想与个人野心同时存在 |
| 现实矛盾 | 路图出售能支付远行开销，公共图又要让人负担得起；委托方可能要求隐藏通道。不能把她写成永远不需资源的无私圣人 |
| 缺点 | 相信自己实测的数据，急于公开成果，有时低估地图暴露住址的后果；面对陌生修行方法也可能过度自信 |
| 私下生活 | 爱收集各地粗纸、旧印章，会在废稿边画途中吃过的点心；精细之处来自观察，不靠统一“温柔女修”形容词 |
| 玩家为何被吸引 | 她有判断、有好奇心，能把眼前世界解释得具体；共同冒险中也有可以依靠的本领，而不是只等玩家保护 |
| 她为何亲近玩家 | 玩家认真对待她的工作，也有自己的道途；能指出她漏掉的风险，并承担共同决定。不是因为玩家境界高或送礼多 |
| 长期变化 | 从独自完成一张好图，到懂得协作、保护信息与传授方法；远行中形成自己的修行路数，不能每次进危险地区都等玩家带路 |

家人、旧师、刻印同行可成为后续联系，不急于给每人新增肖像与长支线。家人不是统一反对恋爱的障碍，师父也不因女主需要悲剧背景而默认死亡。

## 尹照川：想走得更远，也想让归路不依赖自己

| 层面 | 拟定背景与作用 |
| --- | --- |
| 家庭 | 出身渡口船工家庭，习惯看水势、听夜间信号。家人仍有自己的生活，不默认遭灭门或全靠他养活 |
| 修行来历 | 少年在修阵作坊学徒，凭手艺换取基础修行指点，后来承担旧引路阵维护。正式师承与所属暂不命名，避免凭空改现有宗门关系 |
| 个人愿望 | 想学会修复更复杂的古阵，亲自见识远方阵法；同时希望留下可维护、可交接的归路。他也想离开，不是天生只愿值守 |
| 现实矛盾 | 旧装置总需维修，现有教法不足以应对更深古阵；停下学习会被杂务困住，贸然远行又担心交接出错 |
| 缺点 | 善于解决器物问题，不善于承认自己疲惫；明知应培养接手者，却习惯自己补上所有缺口 |
| 私下生活 | 会修便宜的小物件，记得食物应趁热吃却常忘了自己那份；不擅长说漂亮话，熟悉后有朴素的幽默 |
| 玩家为何被吸引 | 他能在危险中清楚交代方案、认真兑现约定；又有需要学习和克服的限制，不是无所不能的可靠模板 |
| 他为何亲近玩家 | 玩家既肯合作，也尊重他的专业，愿意指出不合理的承担；有自己的目标，不要求他证明爱情就放弃一切 |
| 长期变化 | 从靠自己守住一盏灯，到能组织协作、放心远行；失踪篇中应使用已学会的交接与备用方案，不能抹掉此前成长 |

船工亲友、作坊旧同门、后来带的学徒可在远行和回访中交错出现。家庭背景与沈听澜不同，不把两个角色都写成寻找失踪亲人的同一种故事。

## 炼气伏笔：两个可选短接点

优先嵌入已有药路、坊市或护送回执，不新增独立地图、不增加必经战斗、不暂停筑基目标。下列是候选接点，每条人物线首版最多选两处，不把所有例子全塞进开场。

| 索引 | 炼气阶段看到什么、可以做什么 | 当时就成立的意义 | 筑基后回收 |
| --- | --- | --- | --- |
| ORIGIN-S1 改过的路图 | 药路旁一张图把近路划去，标注背药篓者应走溪边。玩家可读、忽略，或向管事反馈真实路况 | 有人在考虑普通人的通行；不额外发唯一功法或好感 | 初见沈听澜改图时认出同样画法。只有实际看过才出现认图选项 |
| ORIGIN-S2 退回的刻样 | 坊市刻印处留下要求补测坡度的退稿，旁人说作者宁愿晚交也不肯把未走过的路标成安全 | 展示认真与固执，不先讲完整身世 | 同行测路时可讨论旧图；没见刻样者正常开始，不丢失亲近机会 |
| ORIGIN-Y1 修好的旧灯 | 护送归途发现一盏旧灯已修复，工单写有替换零件与下次检查提醒；可读、忽略，或告知仍有偏暗的路段 | 玩家受益于他人劳动，灯不是专为主角点亮 | 初见尹照川修阵，工具或维修习惯与旧灯对应；具体工单署名可在制作时确定 |
| ORIGIN-Y2 待交的修件 | 坊市有人寄放给尹照川的备用件；玩家可顺路转交给公共收件处，也可不接 | 展示作坊关系与工作代价，寄放不占突破关键资源 | 后续本人知道有人协助，但只有交接记录明确写明玩家时才认识其贡献 |

不把读图和读工单自动算作“双方相识”。NPC 没看见、也没收到报告，就不能记住玩家当时的选择。正式初识依旧沿用山门改图、桥旁修阵等已有场景，新增两三句有条件回应，不重写为命中注定。

## 初识与后续的回收方式

沈听澜可以先问：“药篓若背得高，那条坡还好走吗？”玩家读过旧图时可谈自己的所见；否则直接参与眼前测路。她因实际交流了解玩家，不凭作者视角宣布早有好感。

尹照川可以提到此前修过的灯，但不能未经证实就说“我那夜专为你守灯”。玩家转交过修件且留有姓名时，他才道谢；不曾转交者仍可在新任务中建立信任。

后续可让旧图中的记号成为远行联络约定、让旧灯的信号方式成为共同接应语言；这些需要在相识后双方明确约定，不把炼气偶见的物件直接当作十全救援密码。伏笔首先服务当时生活，其次才被未来赋予感情。

## 时间、状态与旧档

现有人物年龄设定为沈听澜二十四岁、尹照川二十六岁。长期成长功能实施时，须先定义这是共同世界时间下的初始年龄还是初识年龄；不能多年过去人物年龄与经历仍自相矛盾。本次不改年龄数据，不偷偷增加寿元倒计时。

旧档没有伏笔记录，按“未知 / 未亲历”处理，不强加往事，也不扣好感；已相识或定情者可在自然谈话中了解家世，而不是重新触发初识。伏笔不是结契、核心奖励或救援成功的硬门槛。

玩家读过的见闻、实际帮过的事、NPC 是否得知分开处理；能由既有可靠事实派生的内容不新增字段。需要持久化时按项目版本、校验和迁移规则执行。跳过、返回和重复进入不重复发奖或推进关系。

## 素材与开发顺序

优先制作可复用的改稿路图、退回刻样、修灯工单、普通备用件及两位角色工作细节；沿用既有人物脸型与衣冠，不因补背景改变身份。物件图不把重要条件仅印在难读的小字上，文本由可访问 UI 呈现。无需现在制作父母、师父的整套肖像，也不画未批准的灭门或童年恋爱场景。

制作顺序：核对现有开场与相识入口 → 为每条线选一个短伏笔 → 做有无伏笔的初识回收 → 补筑基后职业与家世对话 → 再扩第二处伏笔。先证明不延长必经流程、人物更可记忆，再增加数量。

验收至少覆盖：看过 / 未看过、帮助 / 未帮助、NPC 知情 / 不知情、未成年、已成年未筑基、筑基新识、旧档已定情。人工试玩检查玩家是否记得人物的做事方式，而不只是认出一张图；不把伏笔数量等同于情感深度。


## 2026-10-30 首批代码接入

按新开局体验组织，不以玩家当前存档进度约束剧情设计。

- 药庐可读 ORIGIN-S1 路图；首次护送成功后，坊市归途可读 ORIGIN-Y1 修单。两条见闻均可忽略，不耗月份、材料，不加好感、不算相识。未选择性别也能阅读两人的事迹。
- 正式初识由原先仅要求成年，调整为年满十八岁且已筑基。入口和命令同时检查；不要求看过伏笔，不增加突破前置。
- 看过对应见闻才出现认图／认修单的交流，NPC 在这次交流后才知道玩家见过。认识选项与普通倾听好感一致，漏读不损失关系成长。
- 相识后可聊家庭与学艺经历：沈听澜的刻印铺、测绘与行脚师承；尹照川的船工家庭、修阵学徒与交接愿望。谈话不耗月份、不重复增加好感。定情仍不等于婚姻。
- 仅新增读过见闻的持久记录，存档版本 15；没有转交修件、报告路况等未实现的帮助记录。ORIGIN-S2、ORIGIN-Y2、后续救援与道侣成长未接入。

验证覆盖有无见闻、男女角色、未选择性别、未成年、成年未筑基、筑基初识、无效／重复操作与家世谈话；界面测试验证阅读命令与人物入口。人工新开局已走到药庐并读取路图，确认不推进月份、不建立关系；尚未完成两条关系线的全程人工试玩。
