# 剧情吸引力、目标感与主动性审查

日期：2026-11-05。依据当前工作区源码、场景选项和设计文档；不是正常新档连续试玩，也不是陌生玩家评价。本轮只审查并提出修改顺序，未调整游戏规则、数值或剧情门槛。

2026-11-05 首批优化已接入离照多方案试炉、古渡本领运用与问法承接，见 [实施记录](player-agency-implementation-20261105.md)。下列问题保留为审查时快照；元婴兑现和连续成长空档仍待后续。

## 判断

已有明确的长线追求、可记忆的人物冲突和真实的成长收益，不能概括为全程被动点击。但主动性分布不均：准备与争宝段落较强，教学、交接、部分能力展示偏弱。部分目标能回答下一步点哪里，却不足以让玩家期待下一步为什么值得做。文案润色本身不能解决这些结构问题。

## 应保留的基础

- 照玄唯一玉简：让宝、守约相争、主动夺简会改变法门所得、同伴支援和后续追索；利益与人物动机直接相关。见 `src/secret-pact/rules.ts:203`。
- 筑基三地取材：自备药物、租阵具，以及雪线用已装备灵器或已研修功法，确有资源与时间代价差别。见 `src/foundation-journey/view.ts:85`。
- 诸宗会胜法承接下一程：稳守、抢攻、辨阵分别影响后续气势、伤害或耗草，而非只有胜利评价。见 `src/conclave/victories.ts:23`。
- 镇潮印、定神珠在下一层继续使用；沉井传承有初次试运，能力所得与后续挑战已有衔接。见 `src/outer-sea/rules.ts:208`、`src/conclave/rules.ts:248`、`src/foundation-journey/progression.ts:23`。
- 恋爱不是通关兑换物，苏婉宁有自己的测绘和成长。重逢、信件与已做选择相连，值得保留。

## 优先问题

### P1：多处“亲手参与”仍是固定答案题

问法四个主题各两步，每步一个固定答案。选错只是增加错误记录并返回提示，选对进入下一步；角色的实际准备不会改变解题方式。离照试炉也固定为排潮再定性，观察文字直接给出该点什么。见 `src/golden-story/teaching.ts:7`、`src/golden-story/rules.ts:225`、`src/lizhao/assay.ts:28`。

初学时这样教一次是合理的；在金丹继续把固定顺序包装为核心考验，玩家容易觉得只是确认读过说明。问题不是提示太清楚，而是看懂之后没有需要权衡的事。

建议：保留首次教学，把后续重点改成已有本领的运用与取舍。例如用现有器物稳住药性、付普通试料换取更宽裕的操作、或以更长调息降低消耗。至少两条方案能够成功，分别付出已预告的成本；不要靠藏答案、加随机失败或增加点击来制造难度。已有相关亲历可以用于缩短重复讲解，仍保留必要规则验证。

### P1：重要突破后的能力兑现，行动过于单薄

元婴出关后的潮隙段落有正确的叙事意图：曾经金丹不能承受的乱流，现在可以护住测绘队。但当前操作是勘察、护持、渡过三次顺序推进，每步一月，主要检查前一步是否完成；成功表现在文本与状态改变。见 `src/nascent-soul/rules.ts:416` 和 `:812`。

这能交代剧情，却未充分兑现长线突破的分量。渡劫本身已有实战，问题集中在突破后的首次能力展示，不能因此把整个凝婴过程说成三次点击。

建议：在同一潮隙场景，让玩家选择先护住哪一段、用何种新能力改变旧限制，并看见舟队或通路发生实际变化。这里可以让主角从容、强大，不必刚升级就再放一个数值更大的敌人。验收关注“我亲手做到了以前做不到的事”，而不只是多出一行旁白。

### P1：部分阶段目标变成数字清单，闭关空档仍待验证

筑基目标存在“再积累到400”“修行至500”“再积累至600”等连续节点；金丹会前提示也允许继续闭关等待会期。自动闭关能减少重复操作，但并未自动提供新的短期追求。见 `src/foundation-journey/progression.ts:29`、`src/conclave/rules.ts:241`、`src/retreat.ts:10`。世界厚度计划D也明确尚未实施连续成长空档检查。

数值门槛本身合理，当前不足是部分提示只突出缺口，玩家不容易把这次积累与想要的能力、宝物或下一次挑战联系起来。这是结构风险，尚无本轮连续试玩数据证明具体空档有多长。

建议：各阶段同时说明“我想取得什么—眼下受什么限制—已有哪几种准备办法—练成后立刻用在哪里”。优先把现有法宝温养、研修、榜单、取材和赴会准备排出有意义的先后，不增加强制支线，也不削弱闭关作为修行方式的地位。允许准备完成者顺畅长关，不强迫每段闭关都出事。

### P2：古渡同行有三种名称，但核心行动差别较小

稳回流、辨双影、切旧桩会选择对应已有法宝/法门收益；当前主要差别是布锚由两月缩至一月，随后共用布锚与实测流程。没有先布锚则退回，布锚后实测成功。分工还可承接对应问法的减时，因此不能称三个选项完全相同。见 `src/golden-reunion/index.ts:18`、`:61`、`:122`、`:157`，以及 `src/golden-story/rules.ts:87`。

作为重逢后的轻合作，这段成立；若要承担展示不同金丹本领的职责，分工差异还不够。金丹尺度下省一月也未必有足够感知，须实测。

建议：三种方案仍共用场景，但分别让玩家观察水势、判断双影或选择切桩时机；使用对应宝物能明显改变操作或现场结果。保留普通绳尺成功方案，不把约会变成高压力副本，不把每句交流都改成算收益。

### P2：有些按钮许诺的主动性大于实际行为

照玄“暂不让宝，要求继续议价”在执行时必定触发贺崇先夺宝，实际是表明立场并进入冲突，没有继续报价过程。界面已有冲突预告，故不是隐藏惩罚；但“议价”容易让玩家期待实际谈判。见 `src/secret-pact/view.ts` 与 `src/secret-pact/rules.ts:210`。

建议：如果本意就是让贺崇显露底线，选项应直接表达“拒绝让宝，要求守约”；若要提供谈判，则需有既有资源、准备或交情能够改变的条件。无需为这一幕新建通用谈判系统。

## 修改顺序

1. 先选一段重复教学，改成两种可成功的实际解法；比较主动判断是否增加，而非按钮是否变多。
2. 加强一次大突破后的能力兑现，优先元婴首次潮隙护持。
3. 用同一正常新档记录筑基、金丹成长空档，重排已有目标与机会，再决定是否需要补内容。
4. 深化古渡三种分工，并统一选项承诺与真实后果。

必要历练继续保留，恋爱与杀敌不成为前置。一次生活场景可以只谈话，线性桥段也能有吸引力；需要改的是整段体验长期只有确认按钮，不能要求每次说话都得改变数值。

## 体验验收建议

让未读攻略的玩家在开场救人后、筑基中期、金丹取宝后分别回答：接下来最想做什么、为什么值得做、准备怎样做。记录回答，不由测试者提示答案。

同时记录：连续确认操作、真实取舍、主动改变准备、失败后是否知道如何调整，以及升级后首次使用新能力的位置。重点观察玩家能否将成功归因于自己的准备与判断，是否自发提及一个宝物或人物。固定种子可达、测试全绿及读完剧情均不能代替这些证据。
