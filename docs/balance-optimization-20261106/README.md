# 修为、凝丹与筹资衔接优化（2026-11-06）

用户授权根据数值审查优化明确问题。本轮改规则、相关显示与回归，不新增系统、晋升门槛或持久字段；当前版本继续承接。旧档保留年龄、余额、修为零头、已备灵地护持和行功阶段，后续行动使用新公式，不补发历史收入。

## 规则对照

| 项目 | 修改前 | 修改后 |
| --- | --- | --- |
| 现行炼气吐纳 | 180修为处，月积累单位48降到24 | 移至240修为的后期节点；119/239/359瓶颈及其历练条件不变 |
| 凝丹三段完成 | `100 - 紊乱×15`，覆盖所有准备加成 | 原准备总值 +10 - 紊乱×15，最终限制10～100%；未行功时仍用原公式 |
| 普通劳作 | 各境界每月5灵石 | 炼气5、筑基8、金丹12、元婴16；修炼、旅行和寿尽不领取工资 |
| 师门差事验收 | 送药10、护送8、校勘6 | 原报酬加境界补贴0/4/10/18；成本、耗月、现场完成与贡献规则不变 |

凝丹原准备总值为：55 + 根基的一半向下取整 + 主修研修层数×4 + 灵地加成（修复8，租用/师门12）+ 护持15 + 既往尝试加成（每次5，最多10）。所有加减合并后再钳制，显示与实际结算共用 `goldenChance`。满额准备可以抵消部分紊乱，但每层紊乱仍减15点。强推选项按相同公式展示未进一步调和时的最终把握。

例：根基24、主修2层、首次尝试、三段零紊乱，修复灵穴93%，租用静室97%；另备护持可到100%。不是所有零紊乱状态必成，也不要求所有玩家购买护持。已有失败可累积经验，旧灵地仍保留。筑基的原概率、寿元总上限、减寿和致命风险均不变。

工坊筹资预估和劳作实际收入共用 `monthlyWorkIncome`，差事报价、验收与宗门按钮共用 `dutyIncome`。旧单月出行使用劳作月推进的兼容路径同步剔除实际工资，避免涨薪后旅行凭空获利。商品价格保持，不把涨薪等比例抵消。
