# 筑基成长与苏婉宁主线实施记录

2026-11-02。本记录描述当前本地实现；金丹突破仍未开放，尚未提交或推送本轮改动。

## 已接通的玩法

- 筑基修行在 199、399、599 形成瓶颈。打坐及战斗奖励共用上限；分别通过传承应用、取得并处理一种机缘、完成长风归流解锁。修为与缺失条件在界面显示。
- 中期药庄、雪线、古道三路择一，依次准备、选路、实战、处理主材。可用自备物资或灵石服务准备；处理提供自炼、付费和宗门贡献途径。选择改变耗时、战斗或回访收益，首胜、处理和回访不可重复领。
- 接入岑霁、玄鳞螈、霜角鹿及闭关场景素材。原图及来源记录保留于 art-candidates/foundation-growth-20261102，运行资源位于 public/art/foundation-growth。
- 稳脉可由接应中的指点、药理修习或独立练习取得；后两者还需完成稳脉实战。听松榜阶段奖励提供有限补给，不替代晋升挑战。
- 长风归流改为筑基后期、修行至少 500 且已贯通周天时挑战；胜后才能积累到 600 并归山，消除过去“先圆满才能考圆满”的循环。

## 苏婉宁贯穿男性主角主线

青嶂共同开路相识 → 无名渡说明各自目的 → 三路择一共同取材 → 回程处理路图分歧 → 约定联络、分别、平安重逢 → 正式探路计划 → 古道断讯与内外接应 → 独自归流、圆满归山。

不恋爱也会认识和营救苏婉宁；男性路线须完成接应才可挑战归流。恋爱、定情、结契仍为双方成年后的明确选择。未成年角色可普通相识和合作，不出现告白。女性主角保留尹照川既有路线。

主线记忆与物资送达分别持久化；先前打通古道不等于已经送出救援补给。此时须另执行送补给，不要求重领首次战斗成果。主线地图选择在接应战斗中兑现对应作用。

苏婉宁替换了运行文案、人物配置及叙事文档中的旧名。已有 shentinglan-* 图片标识保留，避免更名使资源失联。
