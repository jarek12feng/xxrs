## 模块与性能

- `src/presentation/art.ts`：纯表现 ID、路径、可用姿态与精炼映射；领域状态不存图片 URL，素材不决定玩法。
- `CharacterSprite.vue`、`ItemArt.vue`：固定尺寸、底部对齐、异步解码；图标延迟加载。人物加载失败保留姓名，道具名称和操作始终由外部文本提供。
- 战斗 SVG 保留地形与独立招式效果，以同一资源清单加载人物图片；不再逐路径拼接身体。
- `usePageVisible.ts`：后台暂停表现动画，卸载清理监听。低动态偏好停用动画；保存失败不播放修行成功表现的既有链路保留并有测试。
- 原始 PNG 保存在 `docs/art-candidates/v1`，不放入运行构建。37 张运行 WebP 共 1,672,678 字节（约 1.60 MiB）；角色高 640px，道具高 192px。没有全局预加载整批角色。
- `node tools/export-art.mjs` 可重新导出（需要 PATH 上有 cwebp），仅缩放、压缩并保留 alpha，不修改原图。测试要求整批小于 2 MiB，并检查每个资源映射及降级姿态存在。
