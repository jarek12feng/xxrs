# v0.9.2 探索、人物与战斗反馈（待最终集成验收）

本轮仅调整表现层，不改变规则、成功率或存档格式。

- 探索：场景内展示回应、线索、准备失效、能力解锁和资源变化；移动显示起点与抵达地点，不再用大浮层遮挡手机操作区。
- 人物：选择后展示对应人物肖像、回应、关系变化、共同记忆与下一步；陆迟信任与道侣好感保持区分。
- 擂台：每回合就地展示气势变化、交锋结果和下一合意图；短暂出招反馈防连点，三招横排；胜负单独结算，展示新功法、奖励和后续方向。
- 普通回执可展开详情；支持减少动态效果；保存成功才展示结果，演出不重复执行命令。
