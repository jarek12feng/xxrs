# 药乡入道、求学与听松宗籍

2026-11-05。依据本轮首玩反馈及最新选择：入宗由玩家决定。此前“开场必须入宗”的临时答复已被后续要求覆盖。本文与实现同步；测试、实机范围见 [实施记录](initiation-review/README.md)。

## 世界内的起点

主角十六岁，出自青玄界听松山外的普通药乡。家中靠识草、晒药与季节药运生活。药乡供给草药，听松宗护路、炼药与传法，宗门和凡俗是相互依存的生活关系。听松是有凝丹传承的地方宗门，丹堂、剑院是同宗堂口，不是两个阵营。开场不讲全界宗主名册与封界答案。

先前运药遇险，随行老药师教过粗浅调息；温蘅后来认出主角能感应灵气，留纸请他来山下求教。老药师不是隐世大能，引荐不是宗籍，能引气不是已经掌握宗门功法。主角自己辞别家人与旧友乘药船来访，先安顿药包，再亲自辨认灵气、表达求道心意。

## 玩家先有自己的目标

远期求道可以从看百年后的天地、不愿受困于衰老、护住牵挂的人，或尚说不清的愿望出发。动机存档，不绑定功法、职业、善恶或突破概率。眼前目标明确为“凭引荐求教，获得真正的传承与修行条件”。药篓异常发生在自己熟悉的药路上，玩家能认出求援绳结，主动查明和选择营救方法。

后续仍是同一人的成长：炼气学会修行与承担有限风险；筑基有远行能力、面对分别与自身瓶颈；金丹走到外海诸宗，见到地方传承的边界；元婴以后才逐步面对人界灵机与封界旧史。开篇身份与求道目标是这条长线的起点，不能转回替 NPC 连续查案。

## 可玩因果

1. 随药船抵岸、卸下家乡药包。主动呈现身份与引荐，不藏在必须猜中的可选热点后。
2. 调息初试。强压气息会失败，放缓呼吸可感应灵气；不扣月、不罚钱、不发修为，不设强制失败。
3. 表明求道心意。随后出现漂回药篓，接现有辨痕、配药／归绳／稳息、选择路径与营救。前期能力是现场教过的粗浅运用，非凭空释放高阶法术。
4. 回药坪求学。执事让玩家以药篓和护路绳阵复核判断：辨清受力、留松归绳可以通过；盲目拉紧两绳会失衡，说明原因，允许重试。该练习不是收费战斗，也不要求先持有正式功法或法器。
5. 凭营救和试阵取得引荐，听取门规，再自主向温蘅／季衡行礼。入门后可以兼修。散修可以暂缓、同药队立约受教；以后回药坪再议师承，已得资源不重发。

营救不自动加入宗门；听完一段对白也不能跳过实际试阵。既有护送、药谷或古阵亲历亦可供后来求入者核验，不要求倒回少年教学。拒绝入宗不封死筑基及后续主线。

## 入道物资与界面

| 时点 | 实际所有与来源 | 界面 |
| --- | --- | --- |
| 新建角色 | 普通药囊、引荐纸、粗浅调息经验；灵石0、未有储物袋、无正式功法与法器 | 显示药乡来客与现场交互；储物袋、功法、洞府及宗门入口不出现 |
| 营救结束 | 营救报酬待交付；选择带回成株时四株灵草由温蘅代存 | 回药坪求学，不直接进入功法领奖 |
| 首次拜师 | 粗制储物袋；下品灵石12入门支给＋12药队营救与试阵酬谢；基础功法选学资格；堂口基础辅修 | 开放储物袋、功法、洞府、宗门事务 |
| 散修立约 | 药队支付营救、辨药与试阵合计下品灵石24；修补旧储物袋；可外传基础抄本选学资格 | 开放储物袋、功法、洞府，不出现宗门面板 |
| 散修后来拜师 | 保留原所得与主修；不再发入道行装和24灵石 | 此时才出现宗门面板 |

两路均只发一次；带回成株的四株灵草随首次行装交还。总开场24灵石沿用旧“初始12＋营救12”的总量，但全部有剧情来源，不增加起步财富。储物袋只记录持有与入道来源，不新增空间容量/活物模拟；文案说明它是最粗浅收纳法器，不等同于高级随身洞天。首册依旧在长春诀、听松剑经、归元息中自选，不锁剑医。

药队契约不是永久任务债务：往后委托另议，不强迫接受全部差事。宗门提供传承与渠道，同时要求护路守约；后续贡献须通过实际行动取得。当前不新增退宗惩罚或整套叛宗系统。

## 全游戏共同约束

- 能力有修习与境界来源，器物有品阶和实际用途；不得靠开场赠品跳过成长准备。
- 普通凡俗物资与修行灵物分开叙述；灵石是稀缺交换资源，不能把普通晒药者写成随手送高阶法宝的富户。
- 门派、散修都有传承来源与代价。入宗可选，宗门专属资格不能给未入宗者。
- 寿元、闭关与长途行程按既有共同月历；谈话和局部搬动不假造数年流逝。
- 世界见闻随亲历展开，人物不全知，不在新手阶段预告封界真相。
- 延续既有药谷／药窟、照玄、离照等晋升历练，不以本轮绳阵替代后续真正实战。

借鉴修真题材常见的求道、师承、资源、境界与寿元逻辑，不照搬任何指定小说人物、桥段或专有设定；本轮没有进行特定小说的原文研究，也不宣称全世界观已经重新验收。
