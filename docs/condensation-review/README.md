# 凝丹双路线与金丹初行实施记录

后续更新：金丹外海开篇已继续接入，最新范围见 [外海记录](../outer-sea-review/README.md)。下方为凝丹批次当时记录。

2026-11-02，本地未提交、未发布。设计见 [双路线设计](design.md)，全卷规划见 [金丹篇](../golden-core-design.md)。并行写入已统一为单一实施方，保留双路奖励方案。

## 已接入

- 筑基内比一胜灵石 24、护脉丹 1；两胜固定凝露芝心，不与普通补给互斥；三胜额外选灵地或一次护持。按历史新成绩补差，不重复发放。十年前剧情通知规则保留。
- 后期可在凝露药圃选择与柳知微分药或独行，通过守药石偶实战取药。成功必得主药，独行与分药有不同首通收益；可以撤回、败退后恢复和补取。
- 主药自炼或委托成丹，租用、修复或兑现师门灵地，护持可选。筑基圆满、贯流及归山仍须完成，恋爱不作为额外条件。
- 每次叩关六个月，消耗成丹及已备护持；失败伤势 +2，保留灵地、功法与筑基成果，可补取再试。成功年龄不清零，寿限增加三百年，既有永久减寿保留。
- 成功后可通过命令穿过云壁，取得首次勘路酬劳，基础伤害与护甲各增加 10。金丹之后不再显示炼气进度条；后续修行明确尚未开放。
- 存档 v29，保存当前药圃交锋、机缘与突破结果；不为旧角色补剧情或大比奖励，未知档不覆盖。

## 本次整合修复

未备灵地时不再虚增 12 点成功把握；未选择魁首培养时先处理奖励再叩关，避免突破后悬空；显示六个月后的年龄、按突破前寿限计算的余寿及成功延寿；金丹状态栏明确显示本境状态。

## 尚未开放

穿云壁是首次能力兑现的小切片，不是完整外海冒险。外海实战、多宗门人物连续活动、金丹功法转修、金丹法宝与拍卖、宗门间大比、金丹中后期、化婴丹与元婴突破仍待逐批实现。金丹提前五十年通知仍属于设计，不能当现有可玩比赛。

十张场景候选见 [素材交付](../art-candidates/golden-core-20261102/batch-one-review.md)。除已接入听松内比外，不能因有图而认定对应地区开放；人物、独立宝物丹药功法及关键过程素材仍待制作。
