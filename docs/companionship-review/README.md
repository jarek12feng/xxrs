# 筑基同行：首个可玩切片

2026-10-30。用户授权开始筑基后的推进。本次按 `docs/narrative/04-companions-and-world.md` 第 11 节的第一步，落地一次共同历险与分歧；不代表结契、分别成长、失踪救援、无名渡或金丹已经实现。

## 当前入口与玩法

成年、筑基且已在山门相识后，打开“人物关系”。无需定情、读过炼气伏笔、完成寻亲或夺取试剑榜魁首。

- 沈听澜：为远行勘路，玩家稳石或辨路，她测量凡人可走的坡度；发现图上地物会暴露药舍住址后，选择公共干道配当地引导，或暂缓刻印、修替代路。
- 尹照川：为远行学习稳阵，玩家校验上游，他负责灯讯；指出工单漏记后，选择双人交叉轮值，或低负荷备用线留出培训时间。
- 三种准备：根骨与剑意合计 12；神识 8、心得 2；消耗灵草 4。伤势须不高于 2。满足一种即可，无随机掉落；条件不足不扣资源、不消耗种子。
- 协作后取得已有辅修功法护身诀；已习得则心得 +2，上限 4。该奖励每段角色旅程只结算一次。两条人物线同等奖励，不更改关系承诺或增加好感。
- 归路试验：未装配护身诀承受伤势 2 并退回，方案和功法保留；装配后新增伤势 0，完成交接。可关闭面板回洞府免费静养和调整装配。
- 路线选择的成本与回访不同：公共图、备用线不耗材料；替代路、双人轮值消耗灵石 6。刻印延期、问路、维护与航班安排是这一段的有限剧情后果，不是新增动态运输或经营系统。
- 此短段行动不推进月份，阅读、离线、切换页面不会触发伤亡。原有修炼、休养仍按正常月份推进。
