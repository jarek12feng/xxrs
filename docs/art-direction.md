# 中国修真美术设定

日期：2026-10-29。依据用户明确要求：所有素材符合中国修真类游戏设定；丹药通常用丹瓶盛装，怪物可取材旱魃、僵尸与各类妖兽。本规范适用于角色、敌人、道具、场景与后续动作素材，不借美术制作新增系统或数值。

## 物件的身份先于装饰

| 类别 | 视觉设定 | 应避免 |
| --- | --- | --- |
| 丹药 | 丹瓶为主体，玉、瓷、陶等材质；窄口、瓶塞、绳结与封签。筑基丹用暖赭圆腹瓶，清心丹用青瓷细颈瓶；少量小丹丸仅作识别 | 珠宝盒里的巨大宝珠、餐碟盛丹、装液体的西式药水瓶、现代药盒 |
| 药散 | 回春散用宽口药罐、木盖、药粉与竹药匙；与丹丸有区别 | 为统一而误画成丹丸、宝石、液体药水 |
| 功法 | 线装书册与玉简并存；纸、线、玉、刻纹明确，文字由 UI 绘制 | 魔法书锁链、欧洲纹章、载体暗示新增稀有度 |
| 灵草 | 有可辨根茎叶的灵植，少量灵气；当前仅有通用灵草 | 仅靠荧光区分、擅自画成多种可采集资源 |
| 武器与灵器 | 中式剑制、剑穗、朴素玉/铜构件；归元灵瓶作为法器应与丹瓶在尺寸、装饰和用途上区分 | 西式十字长剑、科幻器件、每件都镶满宝石 |
| 文书与剧情物 | 宣纸家书、手绘航图、竹木药签、中式探灵灯 | 欧洲羊皮卷地图、现代标签、把剧情物暗示成新增消耗品 |

## 人物与敌人

人族敌对 NPC 是独立、持续发展的重点，不以妖兽替代。每位具名人物记录身份、利益/立场、关系、衣装锚点、惯用器物、对话形象和交锋姿态。敌对不等于邪恶：切磋竞争、资源争夺、误会和阵营冲突分别设计，保留态度变化的视觉空间，不凭外貌追加剧情事实。

现有擂台三人：巩砚以稳重体态、土灰衣装和护送药队经历为锚点；裴逐风以窄袖、剑和敏捷轮廓表现快剑；邱星罗以学者衣装和阵盘表现阵修。三人均为人族切磋对手，不套用劫药客或鬼怪形象。

鬼物可采用残影、虚实边缘、旧衣与执念关联器物区分身份；不一律画成西式床单幽灵。普通游魂、怨灵与有姓名的鬼修应分别设计。当前没有新增这类战斗或数值。

- 主角与配角以中式衣冠、束发、布鞋/靴、剑与药囊构成身份；先保持同一人的脸、衣装与道具一致，再派生动作。避免把所有角色都画成披挂碎布的同一轮廓。
- 劫药客是人族散修/劫修，保留蒙面与旧衣，不改成西式盗贼甲。
- 蚀阵傀儡仍为既有古阵守卫，使用石雕护法轮廓、风化石甲、朱砂符纹与嵌入阵盘；不使用机械关节、机器人头盔或巨大水晶核心。不得直接改名为旱魃，避免图文和战斗身份冲突。
- 后续尸怪方向：僵尸以僵硬步态、干枯皮肤、旧衣与符箓表现；旱魃用干旱、焦裂、热浪和古老尸煞气质，与普通僵尸区分。无需依靠血腥细节。
- 后续妖兽方向：妖狼、妖狐、蛇蟒、山猿、灵禽等，以真实兽体结构加少量修炼异相形成辨识。设计单列题材、栖地、轮廓、攻击方式；不做泛西幻兽人、恶魔或恐龙拼贴。
- 旱魃、僵尸和新妖兽目前仅为后续美术方向，尚未制作完整动作或加入玩法；仅为已有敌人替换素材时不得暗改敌人身份。

## 每张图的接入验收

1. 遮住名称后，容器/衣冠/武器/怪物轮廓仍能辨认修真题材与类别。
2. 道具在 48/64px 有明确轮廓，名称和用途仍可读；不只靠颜色区分。
3. 角色全身、武器和衣摆不裁切，透明背景无实体黑框；待机/出招/受击保持身份与朝向。
4. 无现代、科幻或突兀西幻结构，无伪文字与新增品质标识。
5. 确认已有游戏对象、显示入口与状态映射，再导出压缩资源；制作原图与提示词入档。

制作工具：image_gen；修订原图在 `docs/art-candidates/v2`，提示词与参考图随修订清单保存。已接入范围见 [接入记录](art-integration.md)。
