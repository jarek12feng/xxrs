# v0.9.1 · 行动有回响

## 修复的问题

原先所有操作成功后只保存并更新状态；突破确认框立即关闭，炼丹只改变背包和卷宗。玩家无法在操作处识别结果。

统一的只读反馈投影接入 App 的命令/保存边界：

- 突破：聚气周天演出；成功金色扩散，失败暗红回震；显示真实结果、判定、丹药消耗、修为、伤势、寿元变化和后续准备建议。
- 炼丹：丹火、炉印、凝丹演出；显示实际所得和投炉成本，同时说明净变化已包含月收入。不把寿元耗尽误报成丹成。
- 闭关、炼器、第一卷营救、第二卷两种闯关、第三卷阵门及旧地图挑战共用结果卡。
- 日常修行、补给、装备、学法、宗门事务、人物选择等显示非阻塞回执，6.5 秒后收起，也可主动收起。完整记录仍在卷宗。
- 结果卡先于待决剧情显示，玩家确认后接续剧情；自动修行使用轻量回执，不每一轮弹窗。

## 安全与边界

- 保存成功才展示结果；存储失败不切换状态、不播放成功演出。
- 保存期间及重要结果卡打开时禁止重复命令；跳过、关闭动画不产生额外命令。
- 刷新读取已保存状态，不重放动画或再次扣资源。结果卡是临时 UI，不迁移存档。
- 尊重减少动态效果偏好；Escape 先跳过演出、再关闭结果；对话框有焦点管理和背景 inert。
- 手机结果卡限制高度并允许内部滚动，触控按钮保留足够高度。
- CSS 动效复用已有素材，不新增图片、音效、服务端或规则随机行为。

## 验证

新增 20 项单元/真实 Vue App 挂载测试：炼丹输入与净收支、死亡、奖励封顶、剧情接续、突破两种结果、无效命令、失败营救、队列炼丹、日志截断、保存失败、重复点击、自动安排、Escape、减少动态效果、刷新恢复。全部 156 项测试通过；构建及差异检查通过。

隔离来源 5183 浏览器实测：采药回执、炼丹演出/所得/到期家书、突破失败（65% 把握，判定 71；丹药 −1、修为 360→324、伤势 +2、护脉丹纹生效）、390px/360px 手机宽度结果布局无横向溢出。未操作 5173 用户存档。突破成功另由固定种子挂载测试验证。未做移动真机或音效验收。

`tools/feedback-preview.ts` 以公共命令生成独立验收存档，参数为新输出文件、模式 refine/break、种子；输出采用 wx，拒绝覆盖已有文件。
