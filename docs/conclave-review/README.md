# 诸宗会、归潮秘境与金丹阶段成长

2026-11-02，本轮本地实现，尚未提交或发布。用户确认先完成“大比争资格 → 秘境取宝 → 宝物改变实力”的可玩流程。本轮落实该流程并接通金丹中期、后期；不把元婴设计写成已开放。

## 玩家道途

退潮内府取回法宝与功法 → 修满前期、凝炼丹元 → 五十年之约赴诸宗会 → 两胜取得入境资格 → 与叶问苓约定路线 → 外殿取得定神珠 → 温养护神 → 深处取回抱元凝神录与凝婴灵髓 → 参悟/转修、积累并突破金丹后期。

- 沿用古渡交接潮图时的五十年预告，不新增常驻比赛导航。到期来信打断长关，不自动报名。赴会从古渡出发，地图只读显示当前位置。
- 澄渊宗顾沧遥争取修堤灵材，照霜门纪闻霜寻找凝神法，衡璇院程砚舟检验阵势。分别与具名人族修士斗法，不拿怪物替代人物。叶问苓继续校勘潮阵，双方约定阵图交付与玩家取宝。
- 正会持续两年，之后各宗轮值补试。首两名对手各胜一次即可入境，不必第三胜；第三场是自愿争优。胜绩跨离场、失败和补试保留。每场首胜灵石 18，第三胜 32，不可重复刷奖。此批不制作周期排行榜或跨届冠军榜。
- 斗法失利伤势 +2、半年后可再试；主动撤回不加伤。秘境失利伤势 +2，不清已通层数、不丢未耗尽行装；养伤后可重返。允许随时撤回，无稀有掉落抽奖，不强制失败次数。

## 凝婴条件与后续边界

明确保留三项独立条件：化婴丹（未来炼制、每次叩关消耗）、已参悟的凝婴法门、已温养的护神宝物。此批提供后两项及一份丹药主材，未实现化婴丹成丹、圆满试炼、元婴突破或失败补丹。定神珠是本条道途的必要宝物，镇潮印仍是前期法宝；普通法宝不自动替代护神宝物。后续若扩展等效宝物，须保留实战资格与取宝经历，不能用普通买卖绕开。

## 时间与数值对照

旧版已研修且参悟澄息篇的金丹吐纳约 0.30 点/月，初探后修满 299 通常超过五十年预告准备期。此次只调整金丹基础记账 3 → 6，完整前期构筑变为约 0.45 点/月；得凝婴法门后约 0.55 点/月，寿元末期仍按原衰减。炼气、筑基速度不变。预估、实际、零头、阶段上限共用规则。

公开命令样本均从新角色正常资源流程生成：三主修 × 两种入境路线 × 两种备战 × 两种参悟，共 24 条，均走完两场大比、两层秘境、后期突破并安全返乡，逐步校验存档和命令重放。样本于预告后第 559 月完成中期准备，尚余 41 月。原始结果见 [routes.json](routes.json)，工具 `tools/conclave-audit.ts`。脚本按来招选招，只证明这些路线可达，不代表所有策略胜率、真人节奏或平衡全面达标。
