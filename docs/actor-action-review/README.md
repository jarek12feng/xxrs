# 人物行动表现模块：实施与接入

日期：2026-11-06。承接用户对开始页、人物朝向的反馈，以及随后授权的行动表现抽象。此处记录已实现的第一批，不等同于全游戏动作系统或规则引擎重写。

## 实现

`src/presentation/actor-action/motion.ts` 是纯 TypeScript 运动控制器。调用方提供已审查的路径、可选面向目标和抵达回调；控制器维护位置、步态帧、运动方向与抵达朝向。渲染器只投递现实经过的毫秒数，不能据此推进游戏年月。

- `approach({ path, faceX?, instant? }, onArrival?)`：替换行程，旧抵达回调作废；路径坐标在一次实例内保持同一空间。
- `advance(ms)`：推进表现；跨越多个路径节点时保留路径，垂直移动不强制转身。
- `skip()`：直接到本次终点，面向目标，抵达回调至多执行一次。
- `cancel()`：停在当前位置，不执行抵达回调。
- `reset(point)`：用于换场或已保存成果确定的新脚点，不伪造抵达。
- `dispose()`：终止并拒绝后续动作。
- `snapshot` / `show`：只读副本，供不同渲染器显示。回调可接续新动作；最终显示期间卸载不会再打开旧交互。

`playback.ts` 是纯 TypeScript 有限帧播放器。接口为 `play(frames)`、`stop(reason)`、`dispose()`，时钟由适配器注入；统一处理完成、跳过、替换、减少动态效果、卸载及过期计时回调。内容帧和已保存状态的差异判断仍属于原场景模块。

`environment.ts` 是浏览器适配器，统一 Escape、后台与动态效果偏好的中断和监听清理。它不进入领域规则。Vue 的 RAF 与 Phaser 的 update(delta) 是两个实际渲染适配器。

`presentation/art.ts` 的 `actorAppearance` 统一姿势图片与镜像投影。行走图的原始方向和静止/出招原图分别处理，镜像只作用于人物图像。CharacterSprite 同步解码姿势图片，避免异步解码在切换帧时短暂露空。

## 实际接入

- 开场 Phaser：移除重复的 tween 路径推进与停步反转逻辑，接入相同运动控制器；保留原导航障碍、透视比例和脚点。
- 普通 Vue：`useSceneApproach` 改为适配器；既有 RoadWorld、MistWorld、QiWorld、QiNarrativeScene、FoundationWorld、GoldenWorld 等调用点直接使用新控制器。
- WalkingActor 和 CharacterSprite 共用素材方向投影，Phaser 也读取同一投影。
- 开场配药/引路/护阵/营救：`createActionSequence` 保留已保存快照的变化检测，使用共享播放器。
- 公共 CombatField：`createCombatSequence` 保留同战斗、下一回合、真实净伤害判断，使用共享播放器；其炼气、筑基、外海和会谷调用点随组件接入。
- 旧的重复运动、序列计时实现已删除，并非只增加一层转发。

规则与存档：不新增进度字段、不修改存档版本。规则命令、成本、伤害、奖励仍由原领域模块计算；保存失败不发布新状态，表现层不补结算。抵达回调只能打开现场交互等表现，不应执行领域结算。

## 第二批：专用场景接入（2026-11-06）

- `useActorPlayback` 将 Vue 的帧状态、计时、Escape/后台/减少动态效果及卸载清理集中管理。探望测记原有展开、指图、回应三段复用它，仍只在新保存探望或明确点击“再看测记”时播放。
- `useCombatPresentation` 将公共 CombatField 的保存战报适配提取，并接入离照专用战场。保留分潮禁阵、傀儡与韩砺舟的真实身份及原战斗规则；读档不再按最后一招的 effect 重播 CSS 动画，也不常驻攻击姿势。仅同战斗下一回合播放，Escape/离开停止，不能改变战况。
- 探望、古渡重逢、结契共用 WalkingActor/useSceneApproach。男性复用现有筑基步态；缺图、未载入或旧女性角色直接抵达，不把静态立绘滑移冒充步态。抵达再打开目标操作，可略过，切换目标撤销旧回调。
- 重逢与结契按人物/器物设置独立抵达点、面向目标。苏婉宁校图立绘镜像朝向左侧玩家；结契桌面对白和操作栏靠右，人物脸部保持可见。其他既有礼成灯光、信物与共同测读仍由保存结果直接投影，没有新加结算或进度字段。

验证过程：首轮定向 5 文件 23 项通过。新增离照 Escape/相同战报验证后，发现整场测试统计到了其他组件的计时器，改为直接断言战况与演出；另有公共战斗用例抓到浏览器 clearTimeout 调用上下文错误，已用闭包适配修复。修复后含 GoldenWorld、离照、探望、重逢、结契的 5 文件 24 项通过。第一次全量 1592 通过、2 失败发生在上述修复前，不作全绿声明。最终全量结果见下。

隔离浏览器：`specialized.html` / `specialized.ts` 使用正式场景与领域命令，但状态只留内存，不读写玩家存档。在 1280×720 验证结契灯火、约书、人物走近及转向；重逢实际邀约、相见、走向水尺再回人物旁相向交谈。截图 `covenant-facing.png`、`reunion-return.png`。离照与探望本批为自动化组件证据，未另做真实浏览器完整路径；不代表正常新档连续试玩或全部专用场景已迁移。

后续仍可逐步迁移 QiWorld、FoundationWorld、GoldenWorld 等场景自有结果反馈计时；本批不宣称所有表现计时器已统一，也未新增 NPC 自由行走、全角色步态或礼仪逐帧素材。

第二批最终验证：`npm test -- --maxWorkers=2 --testTimeout=15000` 全量 246 文件 / 1594 项通过；`npm run build` 通过（保留已有大块体积警告）；`git diff --check` 通过。期间并行 estate-life 类型错误曾使构建失败，最终工作区修复后上述构建通过。本轮未提交或推送。

## 第三批：现有入口接完（2026-11-06）

详见 [完整接入清单](coverage.md)。青嶂、雾海、炼气、筑基、金丹、雷劫、凝婴行功、旧远征战场、首次试招、交锋飘字、行动回执、抵达提示及修行短反馈均使用共享播放器。场内走近与大地图旅行共享 frame-clock，Phaser 保留自己的 update 驱动方式。

没有新增规则、进度字段或动作素材；结果仍由成功保存后的状态投影。保留减少动态下静态结果提示、玩家主动确认回执、旅行暂停和续播；修复同坐标路线数组因父界面重绘造成重复抵达，以及无浏览器静态渲染读取 document 的问题。旧测试中的“两次 clearTimeout”实现断言改为实际清理与无迟到回调验证；旧战报姿势断言调整为读档待机，仅新结算播放。

过程回归曾发现静态渲染错误，且一次测试运行期间发生代码替换，不能作为最终结果；修复后静态场景、素材、旧远征、播放器、旅行定向用例通过。最终全量结果另列于下。浏览器证据范围见 coverage.md。

第三批最终验证（代码固定后）：`npm test -- --maxWorkers=2 --testTimeout=15000` 全量 **249 文件 / 1599 项通过**；`npm run build` 通过，保留既有大块体积警告；`git diff --check` 通过。新增播放器、旅行及远征组件回归覆盖此次接入特有的中断/重复抵达/读档边界。未提交或推送。
