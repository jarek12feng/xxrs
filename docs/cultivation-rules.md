# 修行、寿元与突破统一规则

更新：2026-10-30。本文整理本轮用户确认的玩法规则，作为后续成长数值、战斗与提示调整的依据。用户随后授权按本文优化代码。炼气与筑基的本轮落地、数值对照及验证见 [实施记录](cultivation-review/README.md)；更高境界仍为设计，金丹突破尚未实现。

## 1. 修行目标与境界

玩家以同一个角色追求突破、证道长生。每个大境界依次分为前期、中期、后期、圆满，不跳过阶段。小境界由真实修行积累决定，达到对应门槛即可提升，不把查案、恋爱或可选支线完成情况当作小境界的硬性前置。

圆满是当前大境界的修行终点，不会继续打坐就自动进入下一大境界。下一大境界须另行准备和尝试突破。

## 2. 打坐与寿元衰减

- 打坐消耗游戏内年月，增加修行积累，可以从前期修到圆满。
- 随着当前剩余寿元减少，打坐效果逐步变差。规则应提前可见，不能到临终才突然告知修炼失效。
- 衰减影响打坐新增收益，不倒扣已经获得的修为，也不撤销已达到的小境界。
- 根骨、功法和修行机缘仍能影响效率；一般准备不能轻易抵消全部衰减，让无限闭关成为最优解。
- 衰减不自动套用到现有关口奖励上。通关所得修为、资源和能力仍按关口规则结算。
- 批量闭关逐月计算：每月更新寿元和当月效率，不能按开始时的收益乘总月数。事件或寿尽立即中止后续月份。

本轮数值采用剩余二十年以内线性衰减至约 25%，实际收益四舍五入，存活月最低 1；寿尽月为 0。筑基基础每月 2，根骨、精修、匹配传承、古道稳脉各可增加 1。数值仍需真实玩家体验反馈，自动路线证据见实施记录。

## 3. 寿元与人生终局

每个境界都受当前寿元上限约束。剩余寿元 = 当前寿元上限 − 已活年月；以月为结算单位，展示为年、月。

- 当前寿元耗尽，当前角色游戏结束，不得继续打坐、战斗、领奖或推进篇章。
- 小境界提升不自动重置年龄或补满寿元；大境界突破成功按该境规则延寿，保留真实年龄与人生经历。
- 寿尽结算优先于该月收益及突破结果，不能靠死亡当月的奖励或延寿复活；界面必须提前提示时间不足。
- 完成本篇不等于死亡，角色有寿元时继续原有道途。寿尽后可以读取此前存档，或新建独立角色，不继承跨世奖励与关系。
- 压力来自游戏内行动消耗的年月，不根据现实离线时长扣寿元。

突破后的寿元增量、衰减恢复程度须与各境总流程一起校准，不能简单重置为“年轻状态”，也不能让成功突破后仍毫无可行动时间。

## 4. 大境界突破与对应丹药

每次突破大境界必须同时满足：当前境界圆满、持有对应突破丹药、符合该境已明确展示的必要准备条件。无对应丹药不能发起突破；普通修为和打坐不能替代丹药资格。

**对应丹药既是必需消耗，也提供突破成功率加成；有丹不等于必定成功。** 界面展示已计入丹药的最终概率和各项准备效果，避免将同一丹药重复计入两次。

- 丹药的首次取得须与探险、秘境或关口成果关联。可以直接获得成丹，也可以取得丹方与必要材料后炼制；不能从未冒险就靠普通劳作绕过关键资格。
- 保留现有筑基丹流程：遗府取丹与丹方、自留或赠丹、之后付出材料与时间补炼。已有丹方不因突破失败或赠丹而失效。
- 失败消耗本次丹药，并结算事先展示的代价；只要尚有寿元，就应有可理解的再获取或补炼路径，不因一次失败永久失去资格。
- 必需丹药不能被可选恋爱、完整查案或不可恢复的一次随机掉落垄断。
- 更高境界将来各用对应丹药；名称、来源、成本和加成在该境设计时确定。本规则不代表当前已经能结丹。

现有炼气突破的具体概率、补炼材料和失败代价继续见 [第一卷规则](foundation-volume.md)。除非另有数值对照与回归依据，不因本次整理擅自替换。

## 5. 战斗与越阶

同等常规准备下，境界差距应构成明确的实力差距，普通修士通常难以战胜高一个小境界的敌人。**玩家通过闯关寻找机缘，逐步获得越小境界战斗的实力，并以当前大境界内无敌为成长追求。** 这一差距用于激励探索与准备，不能成为无论如何准备都无法跨越的硬性封锁。

特殊功法、针对性道具、装备搭配以及道侣合作等，都是形成越阶实力的路径。通过机缘取得并正确运用这些手段后，玩家应能可靠地战胜一部分原本打不过的高小境界对手，不能只有极低概率侥幸获胜。各手段保留真实取得条件、适用范围或消耗，越阶能力随着准备逐步形成，不由任意一件普通装备直接包办。

成长兑现应有可感知的顺序：同境立足 → 获得关键机缘 → 越小境界击败强敌 → 完善构筑、争取本境顶尖实力。“大境界内无敌”是可追求的后期实力目标，不要求每个角色刚入境就能横扫，也不作为进入下一大境界的强制成就。跨越多少个小境界由实际构筑与对手决定，不先写死所有越阶只能跨一阶。跨大境界不默认为开放能力，须有单独明确的规则依据。

道侣合作须在战斗中有真实作用，例如互补攻守、配合破阵或创造出手机会；具体机制另行设计，不把一句陪伴文案当作协作能力。参与须符合道侣的成长、行踪及当前关卡是否允许协作，独自试炼保留独战要求。独行玩家也应有功法、道具等可达的越阶路径，不能以恋爱或结契垄断本境顶尖实力。本轮已接入基于现有结契、重逢、在场与共同准备状态的有限协作：正确应对时协助牵制，并提供一阶越阶支撑；榜单与归流仍独战。尚未实现独立道侣战斗面板或自由队伍系统。

敌人应显示所属大境界、小境界及危险提示。可尝试的越阶挑战与剧情尚未开放的关口分开处理，不能用纯文案声称敌人高阶却没有实际差异。同境战斗仍保留功法、装备、招式和准备的作用。

## 6. 探险、关口与原有奖励

**保留现有关口奖励及已约定的取得方式。** 修为、灵石、材料、功法传承、装备、护法、通路和人物后果等已有成果，不能因加入丹药门槛或寿元衰减而被整体替换为丹药奖励。

- 关口既能提供当下成长，也能承接突破机缘；并非每个关口都必须发突破丹。
- 打坐提供稳定积累，冒险提供节省修行年月、取得突破资格与特殊战斗手段的机会。
- 关键战斗机缘应安排可检验的兑现机会：取得前难以战胜的对手，取得并合理运用后可以击败；保留已有奖励，让玩家看见此次闯关如何改变自己的战斗能力。
- 首通奖励与原有重复领取限制继续保留，不因规则调整引入无限刷奖。
- 若未来确需调整某项奖励数值，须逐项说明原值、新值及原因，并验证主线可达性；本次整理不调整奖励。
- 可选人物故事继续可选，不强迫玩家为突破完成所有支线。

## 7. 炼气与筑基的难度关系

筑基阶段的晋升路线须难于炼气。差异应体现在更高的修行投入、更有压力的寿元取舍、更强的对手和更有要求的机缘争取，不能只增加重复点击或对白长度。

验证时同时比较绝对游戏年月与所消耗的可用寿元比例。筑基延寿后仍应需要主动选择修炼与探险，但不能让正常准备的角色必然寿尽，也不能让新晋筑基角色靠几轮短闭关轻易追平整个境界的挑战。

## 8. 玩家必须看得见的信息

| 位置 | 显示内容 |
| --- | --- |
| 常驻角色信息 | 大境界、小境界、剩余寿元；年龄及寿元上限可查看 |
| 打坐准备 | 当前每月实际收益、寿元衰减影响、本次最长耗时；无法安全完成时明确提示 |
| 晋升进度 | 下一小境界所需积累；耗时估计必须考虑后续衰减，不能只用当前收益相除 |
| 大境界突破 | 对应丹药的持有与缺口、已知取得路径、最终成功率、耗时与失败代价 |
| 挑战准备 | 敌人境界、越阶风险、已具备的特殊应对、能否协作及协作效果、既有关口奖励 |
| 寿元紧迫时 | 文字提示剩余时间和当前修炼效率，不能只改变颜色 |

## 9. 实施与验收边界

本轮已接入炼气及筑基统一小境界表达、寿元对打坐效率的影响、常驻剩余寿元、实际战斗境界差距与筑基修行节奏调整，并回归寿尽终局、筑基丹门槛和关口奖励。实测范围见实施记录；金丹及以上尚未开放。

持续回归至少覆盖：

1. 只打坐能跨小境界；圆满后无丹不能跨大境界。
2. 其余条件相同时，低剩余寿元的打坐收益更低；批量与逐月执行结果一致。
3. 寿尽月不发收益、不继续行动；突破延寿不重置年龄，不复活死亡角色。
4. 无丹拒绝不扣资源；用丹成功、失败及补炼再试均按规则执行。
5. 对照同一高小境界对手，普通准备难以取胜，获得并合理运用指定机缘后能可靠取胜；分别验证功法、道具与未来协作路径，保留克制和消耗边界。验证独行也能追求本境顶尖实力，不能只测试“禁止越阶”而不验证成长兑现。
6. 现有关口奖励逐项回归，首次与重复领取不混淆；可选支线不变为突破前置。
7. 新角色多资质、多功法、固定种子重放；记录两大境界耗时、寿元余量、失败恢复与重复操作量。

自动测试与模拟只证明规则及路线可达，不代表真实玩家已认可节奏或商业化体验。数值定稿另附对照和验证结果。
