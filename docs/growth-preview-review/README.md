# 装备、功法、晋升与伤势变化预览

2026-11-02。用户授权优化成长数值展示。本轮为现有操作补充预览与实际结果反馈，不增加玩法系统或综合战力评分。

## 已接入

- 储物袋：比较当前灵器与候选灵器的攻守、器纹和特殊用途，保留品阶说明；回春散展示本次可恢复的伤势与实际效果。
- 功法：求教、装配、研修旁可展开比较。明确习得不等于装配；未装配功法的研修预览明确为“研修后再装配”。同时列出卸下的效果与新打法代价。
- 工坊：取得、精炼、刻纹前比较完成后的效果；未装备灵器明确需另行装配，费用、工期、可用性沿用现有报价。
- 人物与洞府：受伤时展示相对无伤状态的气势和突破把握变化，提供静养与服药入口；按钮沿用行动校验和保存流程。
- 突破：显示成功后的实际攻守与寿元上限；修复旧“延寿十八年”为现有规则增加一百年上限。共享 `breakthroughSuccess` 供成功结算与预览使用，保留已损寿元。
- 行动回执：伤势、筑基修行积累和境界变化也生成能力对照；新装备与新功法未装配时明确提示。原有小境界能力开放提示保留。
- 筑基采用 `foundationPower`，包含筑基修行积累；低于一整点的吐纳提升显示零头积累速度。气势是下场交锋初始值，不承诺恢复正在交锋的气势。

## 实现边界

`growth-preview.ts` 仅以浅层状态投影调用既有规则，不执行命令、不克隆整份存档、不消耗随机种子，不扣资源或推进月份。`growth-feedback.ts` 同时服务预览和实际回执。Vue 组件只展示与发出既有命令。存档格式与数值规则未改变；筑基成功字段赋值提取为共用函数，结果不变。

预览展示当前境界的基础攻守与已知条件效果，不提供虚构敌人的伤害或胜率。实际交锋仍受敌人、招式、境界压制和临场效果影响；未模拟未来剧情打断、工期中的寿元效率变化及随机突破结果。炼气与筑基修行尺度不同，不直接比较两者吐纳数字。
