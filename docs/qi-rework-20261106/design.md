# 炼气试玩整改 · 2026-11-06

本轮授权：逐项修复九项试玩问题，允许补充场景与剧情。优先正常新档、可恢复挑战和世界内因果。

## 九项对应

1. **中期太快**：普通吐纳约每月 2 点，资质、功法和研修影响效率，未满一点的积累随存档保留。119 修为停止自动晋升；主修研修与心得达到要求后，闭关半年并亲自贯通小周天。有限灵息中需平衡推进与脉压，整股和分股均能成功，强冲会受伤。其他活动附带修为也受瓶颈限制。
2. **筑基丹廉价**：遗府越阵之后，先解开六重封丹阵才出现丹药归属选择。补炼必须循凝元内府药图探采玉髓芝；普通灵草不能替代主药。自炼需心得4、神识8，六月温养后亲手析药、调和、凝丹；火候错误会消耗余力并可能毁丹。携真实主药委托丹师为另一条路。筑基须圆满、两处晋升历练、丹药、根基12与无伤；三段行功也不把成功率抹为100%。旧直接突破命令同样检查。
3. **NPC对话**：补齐人物热点类型，将现有气泡系统接到坊市、拍卖会及漏接人物；剧情事件显示人物和有指向的气泡。陆迟的场景立绘使用透明人物资源，原画像仍可用于肖像。
4. **战斗结果**：实际交锋从进行中变为结束时，显示胜利、战败或主动撤离；补齐原先被排除的护送战。结果须确认，保留原有具体奖励、名次和人物反馈，不再次发奖。
5. **宗门差事**：开始只花时间及材料，不领奖。药舍辨寒热与包扎、夜路护灯与接引、藏卷校勘分别有三种现场线索和有限余力；错误会失败，验收才给灵石与贡献。三类现场采用不同背景与对象。
6. **提示遮挡**：人物交谈、现场操作与结果页开启时，任务追踪和已知线索提示让出阅读空间；操作收起后恢复。
7. **温姓NPC背景**：温蘅新透明全身立绘替换开篇、求学与相关旧资源引用，已检查 alpha 与实际药庐气泡。
8. **交易场所无人**：坊市加入掌柜，拍卖会柜台/主持位显示交易管事；炼气坊市同时显示许照岚与裴铸。
9. **任务同一妖兽**：药谷改逐香灵貂，正确化解三次扑袭可护药驱离；护送改人族劫道者，化解四次阻截可护车通过；古阵以辨识枢点解除守卫。也保留直接击退路线，与秘境守关妖兽区别。

## 时间、存档与恢复

新档开府约期为第120月，旧档原约期保留。存档升级至59，旧角色已越过中期者保留资格，已得丹方/丹药不收回；不补发主药。新试炼、主药、进度、火候、余力随存档保存。重新开始同样采用新约期。保存失败不结算收益，重复命令不再次扣料或发奖。

闭关界面显示年岁、季节、预计出关时间与剩余寿元；行动回执记录实际经过年月。失败保留此前历练，可收手、养伤、重新探采；开始时明示耗时和材料。炼丹队列在投入一炉材料后暂停给玩家掌火，不在成丹后重复启动同一订单。

`command-route-metrics.json` 为9条公开命令新档样本：明心善悟、三路线、三个种子。中期第68月，筑基第279–285月（39岁），150–153条命令。样本选择把遗府孤丹赠予同行者，表中 firstPillMonth 是角色之后首次持有自炼丹的月份。它们不是最速解、全资质统计或真实玩家分钟数。

## 验证记录

最终测试、构建结果见 validation.md。规则测试包含三条正常新档至筑基、两种行功解法、失败恢复、材料门槛、委托与自炼、存读档确定性、旧命令拒绝与战斗结果。App界面测试覆盖真实命令接存储、刷新续炼、保存失败、结果确认、宗门交付和事件中断。

实际浏览器从普通新档经过药乡、渡口、药庐、雾林到山祠，确认温蘅透明立绘、气泡及窄窗口提示让位。没有将此短程操作说成完整新档至筑基的浏览器验收。陌生玩家60–90分钟、完整桌面尺寸组合、Windows与Steam仍需单独试玩验证。没有提交或推送Git。
