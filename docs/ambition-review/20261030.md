# 青玄界：目标、获得感与听松试剑榜

用户确认世界命名和复用现有擂台的方向。本轮不新增排名算法、数值、奖励、系统或存档字段，不改参赛年龄。领域状态仍由原命令结算。

## 实现

- 标题、开篇和地图引入青玄界。
- 行旅目标按已有营救、旧阵、归路状态分阶段：摘要直接显示本程目标；展开后说明本篇终点和可选上榜入口。青嶂归路完成后明确本篇完成，寻亲与擂台不是强制清单。
- 当前行动引导不再默认折叠；首胜后漏装主修或首件灵器会提示装配，装配后回到古阵准备。此提醒限定在首胜阶段，不抢走筑基目标。已有真实收益对照与筑基攻防提升继续复用。
- world-ambition.ts 为只读投影。试剑榜按本世 0/1/2/3 胜呈现未入榜、初登榜、入围决胜、魁首；显示下一名对手、原有参赛限制和具名回应。首胜结算同屏展示上榜、原奖励和装配入口；轮回不继承本世名次。
- 战斗来招描述保留动作线索，移除直接指定正确按钮的句子；观摩、招式伤害范围及成本信息保留，规则未改变。
- 人生回顾增加营救选择的成果与代价，按真实救草/取药状态呈现，不给无记录旧档编造经历。既有路线结语、人物回响与未完事项保留。
- 视觉复查发现新目标入口继承了浅底浅字，已为目标区按钮补齐深色底、焦点色与桌面避让空间。
