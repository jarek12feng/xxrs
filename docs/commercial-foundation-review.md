2026-10-30。用户授权处理两项 P0（首玩 / 整篇验证、篇章终点）及前两项 P1（战斗差异、选择后果与文案），随后明确以新角色为准、不考虑旧档体验。本轮没有新增金丹、经营、联网、付费或轮回系统，没有联系外部玩家、发布、提交或推送。

## 已交付的玩家体验

- 开局营救取得功法后，主提示先引导装配，再回访药工；保留救药选择的后果说明。不会自动替玩家换装。
- 筑基行旅与争榜提供按实际研修收益计算的吐纳入口，每次最多 12 月，接近下一关门槛时减少月份；事件仍暂停，满修行不收取多余月份。伤势与缺补给直接提供原有静养、劳作入口。
- 主线现在是：沉井传承 → 离渡试用 → 古道稳脉与内外接应 → 修行圆满 → 贯通周天 → 长风归流试炼 → 听松归山尾声。最终试炼三阶段随剩余气势切换，考验稳住、辨清与释放。周天贯流使筑基交锋相邻两合换招伤害 +5、承伤 −2，并在最终试炼实际使用。新篇章仍可延续原角色。
- 单身、不取证、不做支线、不争榜均可完成上述主线。金丹未开放，篇章尾声明确交付范围，不把预告当功能。
- 药庄三个处置分别接验药、分圃试种和送药到新站，奖励分别为灵石 8、灵草 4、回春散 1；需要亲手执行一次，保存和回访不重复发放。
- 雪线三个处置分别接见证路线、保密接应、修架留引；实际回访后，分别影响古道接应的前两合辨影伤害 +3、首合减伤 3、守势后反击伤害 +3。均是可选帮助，不锁主线。
- 旅亭的两种安排各有不同回访，歇脚最多减伤势 1；结契后可在行前居共度一次雨夜晚饭，男女道侣有不同场景。没有现实离线惩罚，也未强制把晚饭变成救援门槛。
- 清理“不会凭空给你安排恋爱”“不附赠稀有功法”“不会在原地复制人物”等开发说明式台词，改为人物行动与可观察场景。操作提示保留必要条件、费用与恢复说明。

只调整筑基挑战；旧青嶂战斗、炼气擂台、筑基概率、修行收益与经济公式未改。

| 江问荷 | 攻击 27 | 攻击 24；连守伤害 −6、承伤 +3；在换气回合反击伤害 +12、承伤 −6 |

## P0 玩家验证与交付物

`npm run package:playtest` 生成 `release/foundation-commercial-<source hash>/`，包含静态生产包、源文件指纹 / 产物 SHA-256 清单、观察表和使用说明。`npm run preview:playtest` 在本机 5219 提供生产预览。普通地址没有试玩工具；`/?playtest=1` 可自愿开启本机内存记录，刷新前导出，不上传。

[更新后的观察表](first-30-min-playtest.md)覆盖首 30 分钟和同一角色整篇累计时间，明确求助、提前退出、外部中断、检查点与已有存档的统计口径。工具不推断理解、迷路或付费意愿，也不替代观察者。

**外部玩家样本仍为 0。** 本轮已交付玩法优化、测试入口与可复测构建，但 P0 的陌生玩家留存、整篇实际时长与付费篇章满意度仍待 5–8 人形成性观察及随后新样本复测，不能标记市场验收通过。没有新增账号、联网统计、收费功能或营销发布。
