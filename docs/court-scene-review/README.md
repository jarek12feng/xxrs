# 会谷人物比例与现场操作优化

以下为首批记录；同日追加修复见文末，范围和旧行为以追加记录为准。

2026-11-04。用户要求先改善场景人物尺度、透视站位及反复切换管理页的问题。本批限定会谷安全场景，复用现有素材和领域命令。

## 改动

- 会谷主角由固定 195×260 像素改为随场景等比显示；前景人物高 33%，道友与候场对手高 29%，同排 NPC 脚点统一到场景高 74%，主角走近沿前景 82% 石台。保留外海与秘境原布局，不把全世界人物比例一并改动。
- 顾沧遥、叶问苓和候场对手本身可点击或键盘 Enter 交谈；悬停、焦点和选中有反馈，原地面标签继续提供发现与键盘导航入口。两名道友仍共享已有讨论内容，不虚构独立剧情。
- 主角沿已审查的石台走近；可略过，打开交谈不等待动画完成。沿用原移动的减少动态效果、忙碌中止与卸载清理。
- 会谷歇脚处与取得宝物后的现场加入“整理随身器物”，只列真实持有物，显示容量、出战情况及拒绝原因。收回、出战均由原宝物命令执行，不自动换装，不开放现场制作或拍卖。
- 整备结果留在同一局部面板，现场操作不直接改资源、时间、种子或存档格式。

## 浏览器证据

独立端口 5324，`tools/court-scene-preview.html` 使用公开命令生成两胜会谷检查点，不读取或写入玩家存档。这是组件集成检查，不是新档连续试玩，也未验证完整 App HUD 遮挡。

- 实际 App 内浏览器视口 1920×1080：检查人物同排比例、前后地面落点；点击顾沧遥打开交谈与已有入境选择；点击歇脚处展开随身器物；收回归元灵瓶，容量 10/10→8/10 并显示专御；重新出战恢复 10/10，面板保留。
- 实际视口 1280×720：检查场景构图；Escape 收起整备回到地面入口；以 Enter 打开程砚舟交谈，进入第三场自愿切磋，原气势、招式、退场按钮可用；主动撤回后回到会谷，原两胜资格保留。
- 图片：[1920 场景](court-1920.png)、[1920 现场整备](loadout-1920.png)、[1280 场景](court-1280.png)。

## 验证

定向回归 2 文件 17 项通过。首轮 1 项仍断言旧走近位置 58%，按本次候场站位更新为 60% 后通过；没有放宽规则断言。新增真实 Vue 点击验证人物交谈只改变表现、现场收回调用原命令、月份和种子不变、整备后面板保留。

生产构建（含 TypeScript）通过，仍有既有大于 500 kB 分块提示。全量 `npm test -- --maxWorkers=2`：147 文件、1052 项全部通过，58.25 秒；`git diff --check` 通过。

## 边界

本批是会谷构图和现场交互改进；没有制作新人物动作、口型、完整自由寻路或新美术，不把现有步态和姿态移动称为完整演出。外海、其他境界与所有女性步态没有推广。未验证 Windows/Steam、系统缩放、2560×1440或陌生玩家沉浸感。未提交、未推送。


## 2026-11-04 追加：六项问题修复

- 外海古渡主角同样采用场景高 33%，NPC 高 29%，同排脚点 80%；摆放在前景石台。顾沧遥、叶问苓可直接点击交谈，保留地面入口；约定成功后收起旧面板，再次交谈仍可查看当前约定。
- 会谷两位道友分别展示守势演练、潮阵推演；共同相识与路线选择仍通过已有命令处理。各自走近点改为 33% / 62%，前景主角显示在后排 NPC 之前，避免重叠时前后关系颠倒。
- 随身器物与宝物页共用纯只读整套装备预览，出战／收回前显示三种正确应对的伤害及承伤净变化，包括专御得失；容量或场景条件不允许时只显示拒绝原因。此处是器物基础修正，不承诺实际战斗伤害。
- 小于 600px 时标题、目标上下排列，319×669 实测二者边界为 13–117 和 125–240.6，无重叠。
- 场景容器使用 clip，键盘恢复焦点禁止滚动整张场景；现场面板仍可内部滚动。浏览器实测聚焦后场景 scrollTop 为 0，标题保持可见。
- 清心丹改为药力上限 24 内最多 +2（此前神识 12 后 +1），保留本境上限、三月共享药性间隔与原材料／时间成本。神识 23 时只 +1，达到 24 不消耗；炉房、物品与拍卖描述同步。无存档结构变更。
