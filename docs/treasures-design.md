# 宝物与拍卖会

2026-11-02，用户确认丰富宝物、加入有境界限制的拍卖会；拍品可随机，但应当有用，覆盖宝物、丹药和功法。本文是设计契约，实现及验证另见 treasures-review/README.md。

## 境界与见闻

炼气、筑基以灵器为主；筑基中期开始听说法宝。金丹、元婴以法宝为主，元婴中期开始听说通天灵宝。听闻、见到、持有、驾驭是不同阶段，不以残片冒充完整可用法宝。金丹突破、元婴和通天灵宝玩法不在当前开放范围。

灵器/法宝/通天灵宝是器物层次，下中上极品是同层品质，精炼是培养程度，不能混成一个阶数。当前旧灵剑、灵瓶保留普通/精炼成长，新灵器明确品质与培养状态。未来完整品质体系随内容增加，不批量制造只有数值不同的装备。

## 当前可玩范围

保留一件主灵器（听松灵剑或归元灵瓶），增加一个辅器位，镇岳钟、照隙镜、缚风索三选一装配。辅器不能互相叠加，战中不能换装；器物进入库存不会自动装备。镇岳钟强化守势、牺牲攻势；照隙镜奖励正确辨影；缚风索降低反击时承伤但减少该招伤害。接入现有共用回合战斗投影，不改变旧概率关卡的判定。

炼气中期可取得钟、索；筑基可取得镜，筑基可精炼辅器一次。全都有稳定的坊市委托来源，拍卖是一种有机会省钱的选择，不能替代晋升历练。委托与精炼耗一月，扣费前处理寿尽和剧情中断，未完成不扣料、不发物。可卸下、换装，不新增职业绑定。

## 拍卖规则

坊市小拍：炼气修为 120（中期）起可入场。筑基拍卖：达到筑基才可入场。未来金丹、元婴拍卖分别要求对应境界，当前只作设计，不放假按钮。高境界可回低阶会场购买补给。

目录三席：一件未拥有的辅器、一份可用丹药、一部未学功法。各席从适用池按状态种子抽取；候选耗尽则以护脉丹或回春散替代，已满神识时不抽清心丹。炼气不抽筑基器物。筑基丹暂不入池，避免绕开既有遗府取丹和丹方成长。功法复用已实现六部，竞得即学会、不自动换装。

公布目录时同时固定对手预算、拍品和起价，持久保存，不因刷新、退出界面或查看目录重抽。先免费查看、筹资，再主动赴会；赴会耗一月，现实离线不推进。每场结束后按游戏时间间隔十二月可再取得目录，不靠重开按钮免费刷货。

每件拍品逐轮出价；对手只有有限预算，超过预算即落槌。玩家可设出价上限，每次仍主动确认，不自动连续代拍；不足余额或超过上限不扣款、不推进。仅成交时一次扣款发物，落拍可跳过、整场可以离开，之前拍得物品保留。未付成交价不能领取。重发同命令和读档不能重复结算。

拍品显示实际效果、适用阶段、起价、加价幅度和常规来源参考价。高价竞争允许退出，不保证拍卖总是便宜。主线必需资源保留其他渠道；贫困可正常劳作恢复，不新增入场费、资格任务和恋爱门槛。

筑基中期目录旁加入法宝见闻：镇潮印作为高阶修士的展品说明法宝威能与驾驭要求，不可竞拍、不可领取、不增加战力。元婴中期通天灵宝同样先以见闻进入世界，未来再设计实际获取。

## 状态与边界

新模块 treasures 拥有辅器库存/装备/精炼、拍卖目录、当前拍次、预算、成交记录及游戏内开场时间；world 仅组合状态和转发命令。UI 只读报价并发命令。随机仅消耗 State.seed；无系统时钟、后台计时器、离线推进。存档格式升级，旧版只补空宝物域，不补经历和奖励；未知版本不覆盖。

验收覆盖：境界拒绝、种子重放、目录恢复、缺钱/超预算、放弃/落槌幂等、功法与丹药实际入袋、三辅器战斗差异、交锋禁换装、时间中断、版本迁移及未知档保护。全套测试和构建不代替自然首玩、长期平衡与设备验收。
