## 实现与玩家路径

- 沉井石偶胜利后，无名渡现场新增“沉井回声 · 炼神残篇”。四轮探阵取得分念诀，研修三月永久上限+6、神识+3；成为“试运新法”之前置，因而是新角色筑基中期前必要历练。不限主修、宗门、恋爱，也不要求先买丹药。下一场试运中守势接辨影伤害+4、承伤−3，预览与执行共用计算。
- 归潮深处完成后，外海古渡新增“归潮拓本 · 潮隙取髓”。此项可选；挑战后炼化玉髓永久上限+6、神识+6。筑基常规24可到30，金丹常规48加两项成果可到60；晋升不重置成果。元婴初成继承，不扩展长期元婴成长。
- 高神识可自行护神入阵，低神识可花灵草4辅助。回声/逆潮/阵隙要求安排念力与心神；失败创伤1，主动撤出无新增创伤。免费调息三月愈1，清心丹/养神丹可另选疗复1/2层；同一颗不同时成长与疗复，疗复不受成长冷却影响。
- 永久神识与有效神识分离：创伤每层降低有效神识3，最多3层；容量仍取永久值，不因受创卸装或使保存非法。专御使用有效神识18门槛。容量最高22，全部器物成本24，仍需选择。
- 圆满/凝婴经独占该领域的C聊天接入统一神识投影：禁室心神随人物有效神识提升至最多26，凝婴额外心神最多4，策略总量最多12；护神抗性实际抵减回震。普通低神识仍须按原阶段应对，不自动跳过行功/天劫。
- `spirit/` 独立保存、投影、报价/执行与现场组件；原 `spirit.ts` 保留稳定导出。人物面板和功法页显示成果、有效属性、恢复与研修。进行中的探阵由现场强制承接，不可跨域修炼、换装、服药或发起其他剧情。
