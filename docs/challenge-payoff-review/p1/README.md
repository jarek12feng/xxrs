# 三项 P1：战斗取舍、备战与胜利后果

2026-11-04。接续前三项 P0；本批三个 P1 均落在现有会谷与归潮流程，没有新增境界、技能栏或独立战斗系统。

## 1. 可预判的阶段与统一战斗计算

此前会谷在新增护势／蓄势机制之外，仍按底层固定三回合 `pattern` 判定正确应对，器纹也读取该固定答案。现在会谷、归潮将可见阶段的有效应对集合传给公共战斗模块，基础加成和装备效果共用该集合；其他章节保留原行为。多个应对可以同时有效，各自伤害、承伤、下合铺垫仍有差异。

| 对手 | 前半场 | 气势至一半后 |
| --- | --- | --- |
| 顾沧遥 | 护印卸力，辨影打开下合反击空隙 | 散印推掌，稳守铺垫下一合反击；也可承担掌劲直接抢攻 |
| 纪闻霜 | 长剑蓄势／落剑，可打断或辨剑 | 近身短剑／回剑调息／霜影试探，按当前状态接剑或追击 |
| 程砚舟 | 封上一招 | 按本场累计次数封最常用招式；同数先反击，再守势，再辨影 |
| 归潮外殿／阵枢 | 三合潮势 | 两合潮势；保留先守／先辨的铺垫及抢攻反震取舍 |

界面提前说明半血转势，回合提示、报价、战败建议读取同一阶段。不增加隐藏随机变招。这里是减少固定轮换的通用性，不是保证所有重复打法都会输；准备充分或付出更多药材的稳定打法仍允许成功。

## 2. 备战和用药的真实代价

- 自行备战：不付演练费用，依靠已有功法、装备。已选演练也可撤去加成，不返还此前花费。
- 守势演练：原半年、12 灵石，保留护体 +3 与辨后接守额外承伤 −5。
- 潮阵推演：原半年、6 灵石，保留辨影伤害 +6 与辨后抢攻伤害 +8。
- 两项演练互斥，不能全买后叠加。训练、装备与主修继续通过统一报价影响战斗。
- 战中可以关闭“允许守势用药”。选择只改变表现层的待提交意图，出招时通过 `useHerbs` 命令传入；报价和结算共用该值。关闭后长春守势不恢复、不耗草，也不再承担原用药收敛攻势的 −2 伤害。其他主修不凭空获得恢复。切换开关不推进回合，读档默认允许用药，实际每合耗用已保存。

同一长春检查点、无演练：有限搜索得到五合／耗草 1／余气势 58，六合／耗草 5／余 86，以及关闭用药的五合／耗草 0／余 51。剑经检查点无演练五合，潮阵推演四合；守势演练则提高余气势。这说明存在费用、回合数、药材与损伤取舍，不代表任何方案全局最优。

## 3. 胜利留下记录并影响下一程

每场新交锋累计三种出招次数及实际耗草；取胜后保存到会谷胜绩，最多五场，失败／撤回不记作胜利。NPC 回应和奖励都读取这份持久记录，不从当前装备、最后一句日志或当前训练倒推过去。

- 顾沧遥认可偏稳守的胜法：背潮石道的秘境起始气势额外 +4。
- 顾沧遥认可偏抢攻的胜法：主流路线的秘境反击伤害额外 +2。
- 顾沧遥或纪闻霜一战以辨影为主要应对：叶问苓将观察补入潮图，每层行装灵草 −1；两场不叠加。
- 记录同时保留真实次数、回合与耗草，玩家可在“此地见闻 → 道友记下的交锋”回看。归潮两层取胜同样入册。
- 收益无需额外领奖、复刷或强制回访；商议路线、准备行装与下一场战斗直接兑现，路线按钮、实际扣除和气势上限同步显示。

胜法归类：辨影多于守势且不少于反击为辨势；否则守势不少于其他两式为稳守；其余为抢攻。归类不决定通关资格，不需要第三场争优才获得凝婴主线资格。本批人物反馈限会谷已有顾沧遥、叶问苓及交锋记录，不扩写其他章节的同伴剧情。
