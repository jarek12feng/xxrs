# 挑战、准备与突破成就感优化

2026-11-04。本轮落实四项方向：关键敌人区别、准备影响过程、可控破境、成长向前兑现。保留现有主线、三个战斗动作和单机命令架构，不增加境界、强制失败或重复刷关。

## 已实现

### 战斗与准备

- 顾沧遥未破护势时抢攻伤害 −12、承伤 +3；上一合辨影后抢攻伤害 +16、承伤 −4。长春守势可用消耗换稳定，辨后抢攻可以节省耗草。
- 纪闻霜交替蓄势／落剑。蓄势时抢攻伤害 +7、承伤 +3，削弱下一剑；辨影放弃部分即时伤害，在下一合创造反击与减伤机会。落剑时守势可进一步缓冲。已有基础招式、装备、主修仍叠加，由同一报价结算。
- 程砚舟根据上一合动作封锁，连续同式伤害 −10、承伤 +5，换招伤害 +5、承伤 −2。首合单独提示，不能描述不存在的上一合。
- 照神阵枢每三合产生阵压；温养、上一合辨阵与当前守势分别抵消压力，抢攻有额外反震。定神珠保留价值，但不会自动打赢。
- 守势训练除护体 +3 外，辨后接守势额外承伤 −5；潮阵训练除辨影伤害 +6 外，辨后反击额外伤害 +8。训练不叠加，继续复用原互斥准备。
- 战况由已保存的回合、上一合动作和准备推导，不增加隐藏随机变招；提示、预览与执行共用计算。

### 筑基与凝丹行功

新增三段：引气归流、稳住经脉、凝聚道基／金丹。正式 UI 的突破入口改为进入行功；每一步通过命令保存，不能在行功期间换装、修炼或跳过阶段。

| 阶段 | 筑基可用准备 | 凝丹可用准备 |
| --- | --- | --- |
| 引流 | 神识 6 | 神识 12 |
| 稳脉 | 根基 18 或护脉丹纹 | 根基 24 或凝丹护脉阵 |
| 凝聚 | 当前主修研修 1 或根基 20 | 当前主修研修 2 或根基 24 |

每段还可选择灵草调和（筑基 2、凝丹 4，已有紊乱 −1）或强推（免费，紊乱 +2）。稳妥完成不强迫耗药；充分准备后允许轻松成功。最后把握为 `max(10,100−紊乱×15)%`，0 紊乱必成；只有强推留下的风险使用原固定种子结算。

最后确认才服一枚突破丹，筑基一月／凝丹六月，原寿尽和剧情打断优先级保留。主动收势调息一月，保留突破丹、灵地与进度，已用灵草不返还。成功回执列出玩家的三段办法和实际战力变化。旧底层 `break` 命令保留原直接叩关计算，供已有规则调用兼容；正式玩家入口不绕过新行功。

存档 v36 新增 `ascension`，v35 正常档只初始化为空，不重置装备、神识或剧情。更旧版本沿既有迁移后初始化。未知未来版本、损坏行功阶段和非法组合拒绝，不覆盖原档。

### 突破后兑现

- 筑基后的下一程沉井挑战，前两合灵元初运伤害 +6、承伤 −6；进入渡口、实际战斗与首胜回执对应说明，无额外领奖或强制回旧关。
- 凝丹后沿用原独自穿云壁命令与外海解锁，加入丹元护体和云壁前后位置的状态驱动表现。属于简短表现，不能称完整飞行动画或自由寻路。
- 凝丹回执显示同装备下战斗基础伤害／护体变化，指向云壁及外海；修正原晋升回执在金丹后错误沿用筑基圆满目标，以及行功日志误称开炉筹备。

## 2026-11-04 第二批：现场反馈、败退恢复与破境声音

本批落实前三项优先优化及用户追加的突破音乐需求：

- 三段行功采用洞府环境与已有打坐人物素材，左侧灵流收拢、丹田灵光及紊乱色调随保存的阶段变化，右侧保留选择、成本与撤回。不是新增逐帧动画；减少动态效果设置关闭过渡。窄屏纵向滚动，PC 1280×720 双栏。
- 会谷与归潮战中显示护势／印隙、霜剑蓄落、封锁招式、阵压倒数。只读已保存回合，详细报价与现有规则保持一致。
- 败退记录新增真实末合出招、伤害／承伤、战术结算原因和两种调整建议；不是对整场所有回合的归因。记录沿用 `conclave.last` 与日志，存档仍为 v36。
- 败退自动展开会谷歇脚处，可换装、购草、静养并查看再战与训练入口；继续遵守伤势和半年补试，不免费重置战斗。浏览器实测发现原演出结束通知会关闭整备面板，已修复并加入 Vue 回归。
- 筑基／凝丹成功分别播放原创短配乐「道基初成」「丹成云开」及不同成功音效；配乐文件各 12 秒，11 秒时开始恢复场景音乐，短乐不循环。只在成功持久化后的境界变化触发；失败、寿尽、未突破及读档不触发庆祝。下一行动、后台、静音、读档、新建与卸载清理短乐。沿用配乐音量、行动音效音量和手势解锁。
- 音频由 `tools/generate-breakthrough-audio.py` 确定性合成，无第三方录音采样；实际时长、峰值与来源见 `public/audio/breakthrough-v1/provenance.json`。此为短合成配乐，不称真人乐器录制或专业混音验收。

浏览器检查使用公开命令检查点，不读写玩家存档。1280×720 筑基阶段图见 [行功场景](ritual-scene-1280.png)；会谷无额外训练检查点连续抢攻五合败退，末合伤害 44／承伤 17，伤势 2，自动打开复盘、灵草购买和静养入口；两次静养至伤势 0，等补试开放后重新登台，恢复为第 1 合、气势 96。见 [敌方来势](battle-signal-1280.png) 与 [败退恢复](defeat-recovery-1280.png)。
