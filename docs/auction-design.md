# 场所与会期拍卖

2026-11-05。依据本轮用户确认：拍卖不作为常驻随身入口；不同会场分布于不同地点，有不同场景装饰；低阶每年、高阶若干年举办；同届不能通过重进刷货。首批实施与证据见 [拍卖接入记录](auction-review/README.md)。本文覆盖 treasures-design.md 旧的随身参拍、统一十二月冷却与赴会耗一月条款。

底层统一游戏月，第 n 届开场月为 n×周期；开场月包含、截止月不包含。坊市第一届第12月开放，第13月起不能入场；晴川第一届第60月开放，第63月起不能入场。现实离线、阅读与面板开关均不推进时间。场所本身可以常在，参拍只在窗口内开放。境界要求沿用炼气修为120与筑基；高境界不让小会场自动换成高级拍品。

接入现有规则的真实地区位置：坊市还须不在内陆远行地点、雾海现场或其他探索；晴川必须在 estate 且无其他行程/交锋。不能用遗留 road.stage 直接在远处参拍。不另建一份玩家位置，不用 UI 打开事件当作旅行。现有世界仍是分章节位置，本轮未声称全世界统一位置重构。

## 玩家流程

当地场景拍卖行热点 → 管事会讯 → 领取本届目录 → 可离开筹资或在当地候会 → 窗口内入席 → 逐口竞价 → 成交交付/正式退出 → 返回当地场景。

- 坊市与晴川首次会讯在实际会场获知；金丹可在外海古渡向商旅打听沧澜会馆，获知地点与周期。已建立联络后，公告期通过现有来信系统传递会讯；消息不抽拍品。已领取目录可在随身宝物中只读查阅，远处不能领取新目录或竞价。
- 提前公告期内才能领取目录，首次领取时固定随机拍品、起价和对手预算并持久保存。读档、面板开关、切换其他会场再回来均保留原届。
- 领取目录后可离开地点筹资；返场时仍需核验地点与会期。关闭现场操作只收起面板；已经入席时仍属本场，不能去做其他月份行动。
- 正式退出使本届剩余拍品全部放弃，已有成交不撤销；本届不能重新参拍。完成三拍也不能重开。
- 新会次才生成新目录；丹药允许重复。独特器物/功法在存在其他合适候选时避免相邻两届重复；候选耗尽转为补给，不保证每届全新或必有稀有宝物。
- 三处会场独立会次记录，不共用下一场冷却。切换会场不会覆盖未结束的已知目录。只保存每处最新一届，不增加无界历史集合。
- 已知目录的截止时间在闭关与旅行报价旁提示；普通拍卖不强制中断修行。到场可选择候会至已公布的开场月，按月结算寿元，遇剧情/寿尽即停，未入席不算参拍。
- 赴会旧的一月成本取消：道路由旅行领域结算，到达后的入席、竞价与退场为零月。候会单独显示明确月数，不重复收取旅行时间。
- 关键晋升资源继续由原历练渠道获取；拍卖不成为必须赶上的主线关卡。

## 模块与状态

`src/auction/` 拥有会场配置、目录/价格、会次模型、校验、只读报价、竞价和展示。公开调用集中在 `auctionQuote`、`auctionNotice`、`venueAuction`、`auctionTimingWarnings`；既有 treasure 命令仅分发到拍卖模块。`applyAuction` 只修改命令私有草稿，失败整份丢弃。装备、药物、功法交付复用 equipment/economy/techniques，只有落槌付款发物。

为减少对既有活动互斥的扩散，当前选中会次仍存 `treasures.auction`，另有按会场索引的 `auctionArchive` 保存其他会场最新目录；同一会场不能同时出现在两处。旧 `nextMonth` 留作兼容数据，新规则不读取它决定会期。原 `treasures/catalog` 仅兼容导出，不再拥有拍品规则。

存档v46：当前会次加入届号、开场月和截止月；每会场记录独立校验。v45及以前完成原迁移链后补空会场记录，旧拍卖安全散场，不补发物品，不退已成交款，不自动传送；已成交记录、库存、种子、年月保留。未知或损坏档仍拒绝覆盖。

## 场景表现

复用 NarrativeStage 的全场景与对象交互。坊市木厅有药柜、临街门、木台暖灯；晴川交易院有石台、隔席、护物阵纹、窗外水道与药田。两个独立背景由授权素材聊天生成，见 [素材记录](art-candidates/auction-20261105/README.md)。主角/NPC新增逐帧动作不在本轮范围。

## 世界地图与赴会旅行（2026-11-05 补接）

坊市小拍标注在山下坊市，晴川筑基拍卖标注在晴川药庄。地理配置将两处拍卖厅登记为所属地点内的场所；场内走动不另计年月，跨地点仍沿既有道路结算。地图只在原地点已发现时显示标注，不提前展示高阶拍卖会。

世界图详情与旅行预览共用 `auction/map.ts` 的只读投影。未询问会讯时提示前往当地问询；已经取得目录后，按当前旅行方式与剩余行程显示提前抵达、仍在入场窗口或将错过本届。截止月不可入场。旅行资格不足时不显示虚假的抵达预测。浏览地图不领取目录、不推进时间、不改变种子或拍品；实际参拍仍由现场命令检查。


## 金丹商盟会馆（2026-11-05）

外海古渡的商盟泊船提供初次问询，须已结识当地修士。玩家自行选择打听后，世界图显示独立地点「沧澜会馆」并接入现有会讯投递与关注行程。古渡—会馆单程 12,000 里、2 月，使用同一地理配置与可续航 passage；会馆不是古渡内的零月热点。赴馆、返渡均有旅行预览与表现。入厅与竞价不额外推进年月，提前到场可领取目录后候会；未知地点不能从地图直接进入。

会馆设独立海景、白玉台与青铜护宝阵背景。首批每届三拍：温养灵材匣（灵草12、玄铁4），养神丹或药材匣，研修札或药材匣。养神丹仅在尚有神识成长空间时入池；研修札提供心得2，心得上限4，领取目录及出价分别检查余量。普通资源仍可通过采药、炉房和研读获得；镇潮印、定神珠及法宝胚的历练与温养流程不由拍卖替代。本轮未新增可直接购买的完整金丹法宝或新功法体系。

会馆估价：灵材匣56、养神丹48、药材匣36、研修札24。沿用种子生成起价与对手预算，成交才交付；没有按现实离线刷新。新地点资格、同届目录和来信知情独立保存。v49在旧迁移链最后补 `goldenKnown=false` 与空金丹目录，不把已有金丹境界当作已获会讯，不改旧竞价或已得资源。当前共享v49同时包含其他剧情字段，其范围以相应文档为准。
