## 已落地

- 筑基中期、已入宗且没有古道接应危机时，在真实归山/师门事务交接后由同门许砚舟告知十年后的内比；只提升境界不会凭空弹出独立玩法入口。接受、暂缓均由玩家决定。
- 日期保存为通知月 +120 月，显示举办年月、预计年龄、剩余准备月数；备战可正常修行、探险、整备。到开场时同门传讯，长闭关和批量修行停下，不自动报名。首版会期一年，错过不罚主线，之后相逢可得下届消息。金丹 +600 月仅设计常量，尚无金丹运行入口。
- 赴会后才展示会场与三位对手：许砚舟护后路、温序行功、沈砺访剑。三场不同招序，共用已有构筑、灵器、工坊器纹和草药结算。每场整备一月、灵石 2；最多十二合。认输记负不加伤，真正败北伤势 +1，场间可以免费静养与调整构筑。胜负均推进本届，不要求冠军才能成长。
- 首次达到 1/2/3 胜分别多一档表现奖，每档选择灵草 4 或回春散 1；只补历史最好成绩与已领奖档数之差，同成绩续届不刷奖。三胜才称魁首，弃权不伪造胜利。领完新成绩奖后道别，场景消失。
- 战斗中核心入口拒绝修行、工坊、换装、拍卖和其他交锋。事件/寿尽先结算，不扣未开始斗法的整备费。古道危机中允许暂不参赛，避免提醒阻塞救援恢复。
- `src/sect-contest/` 分配置、状态校验、规则和场景 UI。世界入口仅接命令、时间提醒和真实交谈发现；规则无 Vue/浏览器依赖。存档格式 v28，未知版本仍不覆盖；没有补造旧角色的参赛史。
- 会场图来自独立素材聊天，检查后接入 `public/art/sect-contest/tingsong.webp`。窄屏等比例显示，不裁人物武器；桌面图文并排且按钮使用明确深底浅字。

## 规则对照

此前：只有随时挑战的试剑榜，没有有日期的内比、同门邀约或届次赛果。
现在：试剑榜保持原职责，内比从世界中得知，十年备战后赴会，独立保存届次/赛果/最佳成绩/已领奖档。晋升条件、原主线门禁、主修倍率均未因内比加码；可不参赛完整成长。
