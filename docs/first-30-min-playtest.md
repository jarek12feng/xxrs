# 前 30 分钟试玩流程与反馈记录表

适用：`playtest-20261029-A`，见 [冻结与复评](playtest-freeze-review.md)。当前为模板，尚未招募、联系或测试外部玩家。本文件不给玩家指定通关路线；时间段用于观察，不用于引导其赶进度。

## 一、准备与招募

1. 首轮邀请 5–8 名未玩过当前游戏的目标玩家，包含修仙题材及文字/轻策略 RPG 玩家，不全部来自熟人或开发团队；后续综合验证另招 20–30 名新玩家。
2. 使用已核对冻结清单的生产构建及独立浏览器档案/测试来源。记录实际设备与分辨率，不覆盖日常玩家存档，不用热更新服务。
3. 确认能正常建角、操作和保存；记录构建标识与产物校验值。两道途尽量都有样本，但允许玩家自选，不事后分配来美化结果。
4. 默认只记脱敏笔记；如需录屏，先征得玩家同意，不采集无关个人信息。观察者不解释构筑、攻略和隐藏后果。
5. 每名玩家复制下方记录表；同一轮使用相同说明、计时方法和提问顺序。

开场统一说明：

> 这是一个修仙单机游戏的试玩版。请像平时玩游戏一样，自由选择并游玩约 30 分钟。我们在测试游戏，不是在考你；卡住、没看懂、觉得无聊都可以直接说，也可以随时停止。需要帮助时可以提出，我们会记录哪里让你困惑。

不提前告知应在第几分钟装配、打赢或突破，不介绍长春/剑经/归元的最优策略。

## 二、现场流程

计时从可操作的建角页开始，包含建角、阅读、迷路、正常加载和演出；游戏月份单独记录。外部来电等中断记录开始/结束，另列原始墙钟与扣除外部中断后的有效游玩时间，不扣除游戏自身等待或卡顿。

| 阶段 | 观察者工作 | 不应做的事 |
| --- | --- | --- |
| 0–5 分钟 | 观察建角、理解目标、首个推进动作；5 分钟时只问一次“你现在想做什么？”并记录原话 | 提示具体按钮、告诉玩家正确目标 |
| 5–15 分钟 | 记录首件成长奖励、装配、使用及首次战斗时间；观察是否注意到收益 | 提醒领装备、配功法、推荐招式 |
| 15–25 分钟 | 观察奖励如何用于下一次准备，失败后是否能自行恢复，是否出现重复段 | 因进度慢而代操作、注入材料或跳关 |
| 25–30 分钟 | 记录当前追求、停滞及继续意愿相关行为，不催促通关 | 强制筑基或指定支线 |
| 30 分钟 | 原样记录进度，统一说“计时结束了，你可以结束，也可以按自己的意愿再玩一会儿” | 用奖励、任务要求或劝说换取继续 |
| 30–40 分钟（自愿） | 记录继续时长和实际动作，不在此时访谈打断 | 把留在页面或聊天算继续游玩 |
| 结束后 5–10 分钟 | 按下方问题访谈；必要的构筑/失败补测放在访谈后另开记录 | 用后续教学覆盖首玩记录 |

玩家提前结束时立即记录原因并进入访谈，不要求凑满 30 分钟。需要帮助时先记时间、问题和当前状态，再问“你已经尝试过什么？”；仍无法继续可给最小必要提示，逐字记录，相关节点标记辅助完成。

### C. 卡点与行为记录

导航停滞指因找不到入口、不知下一步而超过 2 分钟没有推进；正常阅读、比较方案与思考不算。重复段指连续 3 分钟缺少新信息、有效选择或能力变化，先记录，再判断是否影响体验。

| 起止时间 / 时长 | 场景与状态 | 行为与原话 | 导航/重复/规则误解/性能/其他 | 求助与提示原文 | 后续结果 | 证据 |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | |

记录两类规则预期：擂台收尾是否预计会受击、青嶂击倒后是否预计仍受反击。未自然遇到时标记未覆盖，不为制造失败干预玩家。

### D. 结束访谈

按顺序开放提问，先记录原话再做归类：

1. 你现在最想做的下一件事是什么？为什么？
2. 哪一刻觉得自己变强了？具体改变了什么？如果没有，也直接记录没有。
3. 你为什么选现在这套功法和装备？它有什么不利之处？
4. 哪一段最无聊或最困惑？当时想做什么？
5. 失败后，你觉得有哪些可行办法？实际试了哪一种？未失败则标记不适用。
6. 哪个人物或选择让你记住了？有没有想换一种方式再试？
7. 如果今天不继续，主要原因是什么？如果继续，想追求什么？

## 四、跨样本汇总与判定

首轮 5–8 人以问题发现为主，报告原始人数与个案，不因少数人顺利就宣布达标。以下门槛沿用优化计划，正式判断用于后续 20–30 人综合验证；不同冻结编号分开汇总。

| 指标 | 口径 / 分母 | 后续目标 | 本轮结果 |
| --- | --- | --- | --- |
| 5 分钟内理解目标并推进 | 独立完成两者人数 / 全部有效首玩样本 | ≥80% | 待填 n/N |
| 首件可装配奖励后 2 分钟内装配 | 独立装配人数 / 自然获得该奖励者；另列未获得人数 | ≥80% | 待填 n/N |
| 15 分钟内获得能力并使用 | 独立完成者 / 全部有效首玩样本 | ≥70% | 待填 n/N |
| 30 分钟完成成长循环 | 独立完成者 / 全部有效首玩样本 | ≥70% | 待填 n/N |
| 导航停滞超过 2 分钟 | 至少发生一次的人数 / 全部有效首玩样本 | ≤20% | 待填 n/N |
| 失败后 2 分钟开始恢复 | 独立恢复者 / 自然失败者；不足 5 人另补测 | ≥80% | 待填 n/N |
| 能解释一项真实成长 | 结束访谈能解释者 / 全部有效首玩样本，未访谈单列且不算成功 | ≥70% | 待填 n/N |
| 自愿继续并实际操作 | 30 分钟后自愿操作人数 / 全部有效首玩样本，提前退出算未继续 | ≥50% | 待填 n/N |
| 能说明两构筑差别与代价并改招 | 符合者 / 独立构筑补测人数 | ≥70% | 待填 n/N |

有效样本指进入可操作建角页的目标玩家；因游戏无聊、卡住或游戏故障退出仍保留在分母。纯外部中断导致无法完成观察的样本单列原因、原始结果和排除数量，不补填成功，不与正常退出混同。分母为 0 时写“不适用/证据不足”，不能填 100%。不把口头支持当购买意愿验证。
