# 主线总纲：玩家自己的证道之路

更新：2026-10-30。性质：当前创作与产品方向，供所有开发 session 接手时优先阅读。未来章节仍是设计，本文不代表金丹及以上内容已经实现，也不构成一次性扩展全部系统的任务。

## 一句话主线

**玩家是一个想突破凡身、证道长生的修士；通过修炼与构筑争取机缘，在秘境和人世中作出选择，以一次次大境界突破走出自己的一生。**

玩家先有自己的愿望，再与别人结缘。陆迟寻父、郁青寻姐、宗门旧事都能影响这条路，但不能取代玩家自己的道途。游戏要让玩家持续感到“我在变强，而且快要发生一次质变”。

## 单一角色的持续道途

2026-10-30 用户确认取消以轮回为核心的成长循环。玩家以同一个角色突破境界、走向新地域与未来界域，与故人分别重逢；主界面显示修行年、月，年龄与寿元另列，不常驻显示“第几世”。

- 完成本卷只记入修行履历，不表示寿终，也不要求重开。修为、已学功法、装备、地图进度与人物关系继续保留。
- 寿元与突破延寿保留。寿尽是人生结局，可读取此前存档或另启新程；不再发跨世积分、传承解锁或前世相认奖励。
- “另启新程”建立独立角色，重新选择身份、资质与道途，不携带上一角色的能力、物资或关系。先归档当前旅程，归档失败不进入新建；新建并非世界内的转世事件。
- 修行履历记录实际成果和未竟之事，不再用“下世可以试试”引导反复刷开场。自留孤丹的护脉丹纹、赠丹后的护法仍属于当前角色的真实收益。
- 新界域是原角色的后续旅程，不是下一世。转世暂不属于当前或已批准的未来玩法。

当前实现保留已有存档结构与内部事件标识字段，不因界面世数消失而修改随机或事件去重规则。旧 `next` 命令名仅保留为无继承的新角色重开入口，非 `none` 传承请求直接拒绝；玩家界面使用先归档再新建的流程。历史传承字段不再由新旅程解锁、累计或在新角色间复制，不为本次另造旧档剧情分支。

## 世界尺度与地图

当前界域为 **青玄界**，听松山是起点。听松山与山下药路、青嶂关与云栈、雾岭与雾海属于同一界；炼气、筑基是修行境界，不是地理界域。

世界地图先展示青玄界的本界地理概貌。已开放路线仍按剧情与修行条件进入；提前看见地名不代表亲历、不授予航图或线索。现有远景名“昆仑雪域、太虚古墟、蓬莱仙境”归于青玄界内的雪山、古墟与外海仙岛，均未开放；“仙境”不是仙界或飞升状态。无名渡、药庄、雪线旧门、听雨旅亭与云外古道已在筑基行旅开放；地名预览不自动授予案件证据。

后续新界域使用各自独立的地图，待实际发现时才展示对应入口；暂不指定界名、跨界修为门槛或飞升机制。新增界域应有独立环境、修行机会与当地人物，保留旧界域的往事与回访设计。当前只实现青玄界地图呈现，没有跨界玩法。

地图配置见 `src/world-geography.ts`，仅含本界数据。界域标识与存档中的修行境界 `realm` 分离；未来真正实现跨界时再增加领域状态、命令与迁移，不能靠切换界面直接改变角色位置。地图地标与连线使用固定配置，换章只改变当前行程高亮、所在位置、访问记录与通行条件，不替换整张本界地图。同一地点的不同剧情阶段共用位置（例如云栈旅亭与旅亭来信）；尚未进入的地区可查看地理预览，不提前发线索或提供传送。布局仍为示意，不表达精确路程。

## 持续推进的循环

**知道下一境能做什么 → 闭关积累与选择功法装备 → 挑战当前险境 → 争取关键机缘 → 准备突破 → 境界质变 → 用新能力解决旧困难、走向新天地。**

- 长期：证道长生，走完一段有结局的修仙人生。当前版本尚不承诺完成这一全程。
- 中期：突破下一大境界，进入此前不可进入的地方，获得新的行动能力。
- 短期：补齐一种破阵手段、练成一门功法、拿到一枚必要丹药，或为一次挑战换好装备。
- 每次回到主界面，应能回答自己卡在哪里、可以做什么、完成后能去哪里。放置负责减轻积累负担；主动冒险与准备负责选择。当前没有离线收益实现，不能把“闭关八小时自动结算”写成现有功能。

## 大境界是一卷的骨架

这里的“卷”是创作组织单位，不要求修改现有章节 ID、地图名称或存档。旧文档按地图划分的“三卷”不等于已经做出三个大境界。

| 每卷必须回答 | 创作要求 |
| --- | --- |
| 我为什么要突破 | 提前看见具体能力或世界门槛，不能只显示下一境名称与倍率 |
| 我如何准备 | 已有功法、装备、资源或关系能形成不同应对；不要用统一战力数字代替全部策略 |
| 我为什么要进这个险境 | 关键机缘与修行瓶颈有因果联系，古洞府的原用途也应说得通 |
| 我争取到了什么 | 通关兑现明确成长；必要机缘不能靠反复随机掉落拖延 |
| 我付出了什么、留下了谁 | 选择改变人物关系、后续路径或世界行为，不能只有结算文字 |
| 突破如何发生 | 清楚展示资格、风险、准备收益和失败恢复；不要求每境都重复炼同一种丹 |
| 新境界有何不同 | 安排一次立即可用的新能力与一次旧难题回访，再展开下一阶段 |

每卷可包含数次冒险，但不能让所有支线都成为突破的前置清单。核心闯关有门槛；选修故事可以拒绝、暂缓或错过。必要机缘要有恢复通路，不能因拒绝恋爱或没读完案卷永久锁死。

第一卷的明确区分：**筑基丹是突破必要条件，准备影响成功把握；遗府通关与突破不是同一次结算。** 遗府目前是选择型破阵，不是已做好的新 Boss 战。失败保留取得的丹方和经历，允许补炼再试。具体门槛只在第一卷记录和领域规则维护，其他文档避免抄写数值造成漂移。

## 同行者与有来有往的世界

2026-10-30 补充：筑基后重点展开成年异性知己线，经共同冒险、信任与分歧、定情，双方可结为道侣。道侣有独立修行与行踪，先经历共同生活、分别成长与正常重逢，再安排一次有铺垫的失踪、成长闯关与双向救援。单身仍可完整证道，不以爱情垄断必要机缘。

旧 NPC 不随章节结束消失：有人再次相见，有人突破、留乡、寿尽或探险陨落，重要人物须有可信去向与消息来源。新地域同时引入有自身目标的同辈、高手与普通人，不把所有人串到同一阴谋，也不让旧人全部同步升级。

具体剧情阶段、关系奖励、人物命运、失败恢复与制作顺序统一见 [后续剧情与游戏设计大纲](narrative/04-companions-and-world.md)。其中筑基期有限流程现已实现，实际范围见 [实施记录](foundation-late-review/README.md)；现有定情不自动等于结契，需双方明确表达。更高境界与长期动态生活仍是方案。

炼气阶段已在药庐与护送归途接入两处可选知己见闻，成年且筑基后初识再回收，详见 [知己来历与炼气伏笔](narrative/05-companion-origins.md)。未成年不写恋爱暗示；伏笔不是突破或结契前置，也不能给旧档补造往事。

## 后续 session 如何使用

1. 开始成长、剧情或目标提示工作，先读本文，再读 [第一卷记录](foundation-volume.md) 与 [剧情目录](narrative/README.md)。技术约束见 [实施记录](implementation.md)。
2. 开工说明本次服务哪一个修行目标、玩家能做什么选择、完成后新增什么实际能力或后果。单纯扩写对白不算完成成长闭环。
3. 区分“当前实现”“本次拟改”“远期提案”；核对源码、存档和 Git 状态，不能把本地实现、已提交、已合并和已发布混写。
4. 文档冲突按最新用户指示与根目录 AGENTS.md 执行。本文负责主线方向，第一卷记录负责该段规则，剧情目录负责未实施方案；旧版本与冻结文档只记录当时情况。
5. 后续变更主线或实现范围时，同步更新本文相应状态及对应专题，不另写一个没有入口的平行总纲。本轮只修订文档，不授权自动实现全部提案。

## 试玩时必须问到的事

玩家是否知道下一次突破为了什么？是否能说出自己的准备选择如何帮助过关？是否真的用上刚获得的能力？是否记住一个由自己选择留下的人或后果？是否愿意为下一次质变再走一段？这些需要实际试玩观察，自动测试只能证明规则执行，不能代替吸引力验证。
