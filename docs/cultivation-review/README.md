# 修行、寿元与越阶：实施及验证

2026-10-30。本轮依据 [统一规则](../cultivation-rules.md) 修改现有炼气、筑基玩法。所有变化在本地工作区，未提交或发布；工作区其他剧情、商业化优化改动保留。金丹突破仍未开放。

## 规则对照

| 项目 | 调整前 | 本轮实现 |
| --- | --- | --- |
| 小境界 | 筑基有阶段显示，炼气未统一 | 炼气每 120 修为、筑基每 200 修行划分前中后圆满；纯积累可晋升 |
| 筑基打坐 | 每月 18–22 | 基础 2；根骨至少 8、主修通达、匹配沉井传承、古道稳脉各 +1，最多 6 |
| 寿元与打坐 | 收益不受剩余寿元影响 | 最后二十年线性衰减，系数为 0.25 + 0.75 × min(1, 剩余月数 / 240)；四舍五入，存活月最低 1，寿尽月 0 |
| 筑基日常旁路 | 历练 +8、劳作 +4 修行 | 保留原剑意、灵石等活动收益，不再额外增加筑基修行 |
| 突破耗时 | 立即判定 | 耗一月；先结算寿尽、剧情暂停，再消耗丹药并判定。成功只增加原有十八年寿元，不重置年龄 |
| 大境界丹药 | 筑基丹必需 | 保留遗府取丹、分丹、补炼、概率及失败恢复；无丹不可突破 |
| 越阶 | 主要依赖通用战力，部分数值直接锁入口 | 显式敌人小境界；每个未抵消的小阶令伤害乘 0.45、承伤 +12；移除战斗纯修为入口封锁，保留剧情条件 |
| 机缘兑现 | 传承等提供原加成 | 匹配且通达的沉井传承、已装配二阶灵器、符合条件的道侣协作各抵消一个小阶，可叠加；不抵消大境界差距 |
| 道侣合作 | 共同准备药包 | 保留药包 +2 防护；结契、重逢、在场且共同准备后，非独战关卡可协作一场，正确应对伤害 +4、承伤 −3 |
| 关口奖励 | 原首胜修行、资源、传承等 | 保留奖励和重复领取限制；独战仍可用原药包，仅禁止现场道侣协作 |
| 准备提示 | 按固定月收益估算，旧战斗门槛文案 | 逐月计算衰减与寿尽；区分同阶应战参考值与必要剧情准备，提示可凭机缘越阶 |

未新增持久状态字段，复用现有传承、装备、结契、行踪、共同准备与战斗状态。新角色为验收基准，不提供旧档专项兼容保证，未知存档保护维持原行为。

## 自动验证

最终全量：59 个文件、487 项测试通过；类型检查和生产构建通过；`git diff --check` 通过。生产构建仍有主包超过 500 kB 的体积提示，本轮不将其写成性能验收通过。

新增测试验证小境界、寿元衰减、批量与逐月一致、圆满与寿尽边界、无丹拒绝、突破成功延寿、死亡及剧情优先；战斗对照验证同一离渡对手，普通准备无胜法、匹配传承可独胜、二阶灵器可独立提供越阶路径，多机缘可叠加，协作不能出现在离队或独战场景。协作预览与命令结算的血量、敌方气血和耗草一致。

战斗对照使用边界状态隔离变量；协作尚未做从新建角色一路恋爱、结契到合作战斗的完整浏览器试玩。

## 新角色路线替代验证

通过公开命令从新建角色开始，三资质 × 三主修 × 四种子 × 三行为画像 × 三招式策略，共 324 条；成功路线均逐命令 JSON 往返并固定种子重放一致。没有直接发放修为或关口成果。

| 策略 | 完成筑基篇 | 说明 |
| --- | --- | --- |
| 当前收益优先 | 108 / 108 | 按当前伤害、承伤、治疗选择；失败后有限次数补给、研修与装备准备 |
| 按来招提示应对 | 108 / 108 | 假设玩家正确理解当前提示，不读取未来回合 |
| 固定连招 | 48 / 108 | 其余 60 条在古道外缘四次尝试后停止；记录为未完成，不隐藏失败 |

成功路线炼气阶段为 40–64 月，筑基阶段为 112–180 月，总计 156–244 月；篇末剩余寿元 351–588 月。筑基所需游戏年月明显高于炼气，正常主线并非必然寿尽。寿元极低的衰减与终局另外由边界测试覆盖，不能据正常路线宣称已完成临终策略的全流程平衡验证。

机缘奖励保持不变。纯打坐可以跨小境界，冒险仍是获取突破丹药资格、提升效率与越阶能力的来源。尚未证明现实玩家愿意接受更多游戏年月或操作量，实际游玩时间不等于游戏内年月。

数据：[汇总](summary.json)、[完整命令与战斗记录](routes.json.gz)、[源码指纹](source-manifest.json)。旧替代验证报告对应旧规则，不能复用为本轮结果。
