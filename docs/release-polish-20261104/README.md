# 现有内容四项优化

2026-11-04。基于 `3f1b839`，用户授权执行行动信息与导航、成长准备与失败恢复、高风险代码收拢、性能测量与优化四项。首发目标另为完整元婴与本界收尾；本轮只改善已经可玩的内容，没有实现新剧情或新境界。

## 1. 行动信息与导航

- `action-diagnostics.ts` 在命令确实被拒绝后，复用领域报价和错误接口给出具体原因，覆盖成长、制作、旅行学习、主要章节、突破、补给与擂台。未覆盖的旧命令说明现场选项变化，不伪造原因。诊断不执行命令、不消费随机数、不代替执行校验。
- `scene-activity.ts` 分别提供交锋归属、现场归属和普通行动中断原因。App、StoryScenes、场景路由和自动暂停复用；炼气秘境两战之间也保留现场，旅行中不能切换章节。
- 在会谷准备、当前战斗、秘境内部是不同状态；在会谷没有交锋时仍能劳作等，不因统一判断误锁所有行动。战斗只保留系统、存档、设置等安全面板入口，原章节仍负责撤退。

## 2. 准备、成长与恢复

- 炉房各配方可查看筹备缺口，明确所选自制/成品/委托、费用、工期、效果与尚缺资源。选中后自动定位到方案，查看本身不改状态。
- 灵石、灵草与心得提供分别确认的批次准备：按缺口和原收益估算，单次最多十二月；原事件、约期、寿尽和上限仍可提前截断。材料购买是明确标价的另一选择，未学采药不阻止通过原坊市买草。不自动开炉、买货、切换功法或代选剧情。
- 当前筹备方案在本次会话内跨面板/事件保留，读档或新建角色时清除，不写入领域存档。成品实际到账后显示本次完成，必须自行选择再次筹备，不把成功后的下一份缺口误当未完成。
- 伤势面板保留静养一月与服药，并提供最多伤势月数的免费静养，痊愈即停。仍有时间/寿元成本，不将“免费”写成不耗时间。
- `preparation-rates.ts` 共享原劳作、采药、研读、静养的基础收益，筹备预估另复用功法效果，避免在 UI 中复制一份计算。正常价格、成长速度、战斗数值均未调整。
- 已有等预算构筑、失败补丹、成长兑现测试随全量回归执行。本轮改进操作与反馈，没有足够新真人证据支持普遍提高收益、压低敌人或宣布三构筑已经平衡。

## 3. 会话、自动修行与收支

- `session/use-game-session.ts` 接管加载、保存、报错与状态发布；写入成功前不切换游戏状态，不并发提交。失败保留原状态并停自动运行。
- `session/automatic-clock.ts` 接管计时器生命周期，等待上一操作完成，再判断后台/忙碌等条件；卸载停止。仍只有规则命令能推进月份。
- 坊市补给接入统一原子收支：库存满不扣钱、不记命令，腾出空间后可重试。
- 擂台费用、耗草、首胜奖励与重复功法补偿接入统一收支。入场检查胜利奖励容量；旧战中存档在最后一击仍重验，失败不消费回合/RNG/胜绩/功法奖励。撤退仍可用。
- 不删除合法迁移代码，不机械迁移所有章节，不改存档版本。

## 4. 性能测量

工具 `tools/release-performance.ts` 使用正常命令生成金丹后期受控存档，与新档分别测量命令、保存和读取；每项预热十次，记录三十五次的 p50/p95。不是正常 UI 从零游玩，也不是 Windows 硬盘或浏览器帧率测量。

在 Node v24.7.0 + fake-indexeddb 环境，金丹后期样本为第 2473 月、序列化 30868 字节。原始结果见 [修改前](performance-before.json) / [修改后](performance-after.json)。

| 金丹后期操作 | 修改前 p50 / p95 ms | 修改后 p50 / p95 ms |
| --- | --- | --- |
| 单月命令 | 0.143 / 0.169 | 0.139 / 0.160 |
| 保存 | 0.722 / 1.603 | 0.608 / 1.893 |
| 读取 | 0.586 / 0.773 | 0.334 / 0.413 |

检查发现 IndexedDB 读取本来已产生隔离快照，当前版本仍经迁移接口再深拷贝；正常加载还校验并克隆无需恢复的 previous。现在当前版本直接校验，旧版才迁移；只有 current 无效才解析 previous，同次保存复用旧档识别结果。保留写入候选快照、单事务、未来版本拒绝与坏档恢复。

结果支持删除这段多余工作；保存 p95 反而上升，单轮亚毫秒结果有噪声，不能宣称所有存储指标提升。未测首屏/切场帧率、长期内存、Windows 实机与 GPU，也不把现有大分块提示称为已解决。

复现命令：

```sh
npx esbuild tools/release-performance.ts --bundle --platform=node --format=esm --outfile=/tmp/xxrs-release-performance.mjs
node /tmp/xxrs-release-performance.mjs
```
