## 当前定位与范围

《长生未央》是以同一人物追求突破、证道长生为主线的本地单机修仙游戏。PC / Steam 为产品方向，桌面鼠标键盘优先；现阶段仍是开发试玩版。

应用版本为 `package.json` 中的 `0.15.0`，当前存档版本为 `src/save-version.ts` 中的 `60`。版本号不等同于已发布包的内容；本次核对时工作区仍有未提交修改。本页不宣称这些改动已提交、推送或发布。

## 近期优化

### 药庄自主生活与雪线用途

晴川药庄现有潮药处理、分批护运、直接购药和凭实际合作记录求教。分层封药能降低制药耗草与护运损耗；两类合作各自备货，允许暂放或离庄，购买不产生专业认可。

第二批把所得接到雪线实际用途：查看护寒缺口，按原工坊报价自炼或购买，雪线通过真实地图返庄补给。护寒、战中续航与战后疗伤分开说明。帮助默认折叠，没有增加晋升门槛、职业锁、声望货币或全世界模拟。

同一正常“行路问心”存档已从107月续玩到511月，完成首次到庄、护运换草、求教、制药、自炼护寒、七合雪线取髓、五月返庄购草及重载。最终停在药庄，灵草5、灵石6、筑基修行232；寒髓晶已得但未处理。见 [完整路径与截图](estate-life-review/README.md)。

### 炼气与数值衔接

炼气九项整改包含瓶颈、实物操作与师门差事，存档v59；新档约期为120月，旧档保留原约期。筑基命令层要求根基12、无伤及已有资格，战斗结果需确认。

后续数值调整将炼气吐纳减速点移至后期240；凝丹行功保留准备加成，普通劳作与师门差事按境界适度提高报酬，预估和结算共用。无新增存档字段，不回补旧收入。见 [炼气验证](qi-rework-20261106/validation.md)、[数值对照与路径验证](balance-optimization-20261106/README.md)。

### 场景、人物与引导

开始页与建角布局、人物素材方向和抵达朝向已修正。新建入口以男性主角为当前设计入口，旧女性存档及规则支持保留。

共享人物行动模块负责路径、停步、略过、朝向和有限帧播放，Vue / Phaser 通过适配器接入；公共战斗、离照、探望、古渡重逢和结契已有相应接入。规则结算与已保存成果仍由领域层负责。不是所有场景计时器、全体角色步态或逐帧演出都已完成。见 [开始页](start-facing-review/README.md)、[行动表现两批记录](actor-action-review/README.md)。

引导保留阶段目标与现场现象，复杂解法提示默认折叠，成本、风险、硬性前置和恢复说明保持可见。见 [引导记录](guidance-review/README.md)、[场景统一约束](scene-and-time-contract.md)。

## 接下来优先做什么

1. 以正常新档补齐当前版开场至筑基的连续路径，观察玩家是否能自行理解瓶颈、准备来源与下一步目标；记录卡住、失败与恢复，而非只看通关。
2. 继续检查能力与资源的后续用途，补上物品说明、行前报价和制作回执之间的语义差异；药庄循环先做少量陌生玩家观察，再判断是否扩到其他地域。
3. 沿现有场景逐步完善角色行动、交锋反馈和PC布局，复用共享模块；补齐专用场景与实际鼠标/键盘验证。
4. 在明确试玩版本上复验存档、性能、Windows实机与音频，再决定发布；不以新增高境界或更多系统替代现有内容验收。
