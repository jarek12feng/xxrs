## 设计检查

- 炼气：沿用本轮已实现的小周天、淬脉/凝元历练、封丹阵、玉髓芝探采、亲手掌火、根基及伤势条件，相关公共命令回归覆盖三种取材路线。不能恢复为纯打坐跨所有瓶颈或直接点对白拿筑基丹。
- 任务：现有宗门三种差事需现场履行，交货/护送/校勘使用不同过程；收益、重复领取与状态约束由规则测试覆盖。
- 筑基、金丹：保留沉井、照玄、观潮/遗府、诸宗会、问法、离照及突破准备的实际条件。本轮没有额外添加任意月份墙或强制恋爱条件。
- 当前工作区另有数值优化成果，具体前后对照见 `../balance-optimization-20261106/README.md`；本轮没有重复覆盖其数值方案。
- `golden-routes.json` 是本轮实际重跑的三种功法金丹后期到凝婴公共命令结果；只证明参考路线可达，不等于玩家成功率或现实小时数。
- 敌人身份与重复挑战检查依托 qiEnemy、人族对手映射、各章战斗配置和全量回归；没有为了“不同”把有剧情身份的修士改成妖兽，也没有声称每次重复挑战都新增一种敌人。
