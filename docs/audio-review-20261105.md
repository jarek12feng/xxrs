# 2026-11-05 音乐与音效补齐

本轮仅改音频表现与场景报告接口，无规则、数值、存档结构变更。工作区原有引导层等修改保留。

## 问题与处理

- `foundationAudioScene` 原先接受所有筑基以上境界，导致金丹/元婴沿用筑基背景。现限于筑基；金丹、元婴平静修行用云海曲。
- 旧音乐只观察 App 外层场景，不知道 StoryScenes 内部章节选择。现由实际渲染章节报告音乐上下文；青嶂/雾海也读取各自场景，防止旧地点串音。切换修行页不继续播放隐藏遗迹配乐。
- 战斗统一复用 `combatOwner`，覆盖宗门大比、凝丹取药、外海、诸宗会、离照、神识、器物试炼、圆满/接雷。原筑基沉井/雪线交锋保留水边/风雪环境。死亡优先级最高，标题不继承存档战斗。
- 外海遗迹/归潮用沉井灵痕与水声；古渡常态用行旅与水声，重逢实测用尺绳过雨，问法用两岸应灯；离照险境用悬疑，试炉室用两岸应灯；元婴初成用云海归灯。拍卖会用平稳行旅曲，未额外添加人声喧闹。
- 新增纯投影 `journey-sound.ts`，补齐主要新章节的逐招、胜败、主动撤离、丹药、温养/重铸、神识创伤与恢复、问法完成、试炉验证/失手、结契、重逢分别、护渡完成及拍卖成交。奖励读已保存字段差异，不凭点击按钮或战斗消失猜测胜利。终局反馈仍由统一入口优先处理。
- 元婴突破原先复用金丹短乐。新增 `nascent-rise.wav`（12秒）及 `nascent-breakthrough.wav`（4秒），原创程序合成五声音阶弹拨/钟音，无外部采样。生成脚本与来源清单保留，实际 PCM 数据检查见 `audio-review-20261105-assets.json`。短乐不循环，随后回到场景音乐；两文件共约2.8MB。

## 验证与边界

自动测试覆盖实际组件切章事件、场景优先级、死亡覆盖、突破区分、结果/撤退区分、重复结果不庆祝，以及原播放器手势解锁、静音、切场、后台暂停与释放。音效仍在保存成功后播放，自动修炼不逐月刷音效；无新增播放器、定时器或 eager 资源加载。

本轮复用原有原创配乐，未新增每个关卡独立曲目；非全游戏逐按钮声音重新编排。PCM与自动测试不能证明主观听感、长时间循环疲劳或设备混音合适。本轮未做正常新档全程试听、真人耳机/扬声器试听、Windows/Steam声音验收。
