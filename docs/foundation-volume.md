# 第一卷：争取筑基机缘

2026-10-30。用户确认以玩家证道长生为主线，把大境界突破组织为关卡；本轮完善已有炼气到筑基流程。此文记录当前规则与后续创作边界，取代旧文档中“无丹可突破、遗府可永远错过”的描述。不新增金丹或新战斗系统。

## 玩家经历

| 段落 | 玩家要做什么 | 故事与成长的联系 |
| --- | --- | --- |
| 入山 | 救回药工，取得第一册功法，认识陆迟 | 有自己的立身之处，也知道有人同样在寻找筑基机缘 |
| 准备 | 修行、疗伤，选一种能穿过石阵的手段；可护送药车取得灵器 | 洞府积累为一次明确的冒险服务，护送战检验已有功法与装备 |
| 探府 | 第三十六月赴约，至少 180 修为并满足一种破阵条件 | 实际准备决定可用解法；不能再用无条件绕路直接拿丹 |
| 分丹 | 留丹先筑基，或赠丹给陆迟后补炼 | 成丹只有一枚，丹方可以带走；让利有时间与材料代价，也有护法收益 |
| 叩关 | 修为 360、筑基丹一枚，再决定是否固本、疗伤 | 丹药是资格；根基、剑意、伤势与护法决定成功把握 |
| 兑现 | 筑基后回青嶂旧阵，挑战守阵傀儡、取得转运册 | 已有伤害与减伤提升、功法通达和灵器精炼让境界改变行动能力 |

青石遗府是已有的选择型破阵关，不在本轮把它描述成已经实现的回合 Boss 战。青嶂护送与守阵交锋仍承担战斗体验。若后续实测认为遗府高潮不足，应优先丰富这一个关卡的应对与结果，而非新增多个系统。

## 当前明确规则

- 首次取丹：遗府内获得成丹与补炼丹方；没有通过遗府的新角色无法提前炼制筑基丹。
- 破阵：炼气至少 180 修为，并满足以下之一：根骨 8、神识 8、悟性 8 且心得 2、灵草 4、剑意 4，或渡口旧约传承。各解法沿用原有伤势与资源代价。已有筑基旧档仍可护送。
- 退出：不耗月份、不发奖，陆迟先行且失去本次赠丹护法机会；后续可独自重返。选项在行动前明确告知。不会每修行一月都再次弹出赴约事件。
- 失约：保留关系疏远的后果，允许独自重返取丹；不能在独行时虚构赠丹、信任增长或陆迟的在场回应。
- 分丹：自留获得一枚丹与一次护脉丹纹；赠丹不立即得到成丹，保留原有护法加成。两条道途均可依丹方补炼，剑修可购草，不强迫换路线或重新开局。
- 补炼：沿用三个月及原材料公式；不是免费发丹。医修保留采药优势，悟性、心得与神识保留降低炼制成本的价值。
- 突破：必须持有并使用一枚丹。无丹或试图绕过用丹的命令不改变状态、不扣资源、不消耗种子。沿用基础 45、用丹 20 个百分点与其他现有修正，成功率上限 95%。界面不再提供可选用丹勾选框。
- 失败：消耗本次丹药，沿用修为、伤势、寿元与护脉丹纹规则；丹方和通关结果不重置，可疗伤、补炼再试。

## 对照与存档

| 原规则 | 新规则 |
| --- | --- |
| 可无丹尝试筑基 | 每次必须用丹 |
| 医道或丹札传承可提前炼筑基丹 | 新角色先闯遗府取得丹方；之后两道途都可补炼 |
| 不准备也可强行绕过石阵 | 至少 180 修为及一种实际应对手段 |
| 失约后本世遗府关闭 | 关系代价保留，开放独行重返 |
| 丹药可选加成 | 必需消耗，预览始终计入；准备不足明确禁止突破 |

第一卷规则不新增存档字段；当前整合版本为 v15，沿用知己来历功能已有的迁移，不因本次准备优化再次升级。已取得的丹药保留；旧档自留/赠丹成果视为已经取得丹方，已有 crafted > 0 视为已学会炼制。旧筑基不降级、旧破阵记录不重置。未识别的旧档仍交给既有迁移器处理，本轮不放宽校验或覆盖未来版本。

独行通关用既有 self 记录取丹，用 luchi=distant 保留关系疏远；不能仅凭 self 文案就声称两人共同探府。新的一世重置通关和丹方，已选丹札只保留原有初始草药与采药能力。

## 后续各卷的创作尺度

每一卷都要写清：玩家想跨越什么门槛、为何要去冒险、准备怎样改变行动、同行者想要什么、所得如何分配、突破后具体能做到什么。人物有自己的目标，玩家有可承担代价的选择，不由剧情宣布唯一正确答案。

后续境界不应机械重复“打守卫拿丹”。可分别围绕功法缺陷、传承取舍或旧日恩怨展开，但金丹、元婴和飞升在本轮都只是方向，不展示为已开放玩法。

### 规则与数据边界

本轮不改门槛、修行收益、突破概率、材料消耗或战斗数值。破阵选项提取为同一纯函数，供事件校验和准备显示共用；准备显示对修为门槛单独列示，不能靠显示“手段已具备”绕过 180 修为。批量操作仍使用已有 advance（1–12 月），没有新增离线收益或自动选择。本项无新增持久字段，当前整合存档版本为 v15；过程与人物回应只读既有分丹、境界与破阵记忆。旧档已送达父亲来信时仍优先呈现已知生还和故乡状态。
