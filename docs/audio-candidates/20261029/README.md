# 原创声音素材 v1.1 · 2026-10-29

用户本轮明确授权制作文件、替换当前背景音乐，并在晋升、打斗、装备升级等位置使用音效。本次是声音范围的单独授权，不解除玩法、数值、剧情及布局的冻结。声音修订标识 `audio-20261029-C`，不将本版本观察混入 `playtest-20261029-A`；原冻结清单与既有 Windows 试玩包不覆盖。

## 文件与试听

- 无损文件：仓库 `public/audio/original-v1/`，28 个 WAV，44.1kHz / 16-bit / 立体声，总计约 49MiB。
- `试听合集.m4a`：顺序为下表五首各 12 秒（之间 1 秒空隙），然后下方音效顺序（之间 0.5 秒空隙）。
- `render.py`：原创音符编排、音色合成、混音和导出源码。依赖 Python 3、numpy；试听 AAC 转码使用 macOS afconvert。
- `analysis.json`：每个文件的时长、峰值、RMS、循环接缝幅差和 SHA-256。
- `素材包.zip`：无损文件、试听 AAC、制作源码和本说明。

所有旋律与声音均在本轮以程序合成，不使用原 music.zip 中歌曲、录音、第三方采样或音乐模型服务。拨弦/笛声/钟鼓是合成音色，不是真实民乐录音。当前属于第一版声音草案，不以自动检查代替听感评价。

## 本轮补齐（声音修订 C）

- 新增 failure / death / rebirth / reunion / closure / work 六个 WAV：失败、死亡、轮回、相聚、收束、劳作。
- 失败基于实际修为损失或挑战次数/结果判定，包含满伤势突破失败、雾境护归路无伤失败；剧情打断、重复访问不伪装成挑战成功。
- 死亡优先于劳作等引发它的动作；轮回优先于旧世状态。自动行动仍不重复发声，但死亡/本世完成会提示一次。
- 雾境成败、寻亲支线胜负/和平通行、赠丹、陆迟来访、定情、分享记录、家书送达、归灯与封存本世接入相应提示。
- 新功法用发现音；师门采药/抄卷/守夜复用采集/研读/防守音；历练复用攻击音，劳作增加轻鼓敲击。
- 山祠点灯前保持悬疑，实际点灯后改为归家主题；“有人等你归来”使用归家主题。重复查看已完成章节不重放结局提示。
- 本轮没有新增具体雨滴、水岸、风铃环境采样；现有背景氛围继续保留。真实设备听感与长时间疲劳度仍需人工试听。

## 验证边界

日常五类音效目标 RMS 为 −26dBFS，低于战斗与成长提示；不会按修行月份循环播放。

文件检查：全部为有效 PCM；无数值削波，峰值留有至少 3dB 余量；循环首尾幅差小于 0.004。RMS 是信号能量测量，不冒充 LUFS 或主观响度。

集成检查覆盖：状态变化对应音效、静音/零音量、手势解锁、后台暂停、卸载释放、延迟 play 回调、文件缺失、素材完整性，以及原有保存失败不发成功音和场景音乐切换。浏览器实际点击开启后显示新曲目正在播放。未声称逐个音效已在人耳监听或全部游戏剧情中手动验收，Windows 实机混音仍待试听。

原音乐素材留在 `.local-music/` 与原始归档中，本次不删除、不覆盖。新版从正式静态资源路径读取，可随生产构建离线打包；已发出的旧 Windows 包不会自动改变。
