## 对照游戏与大纲后的缺口

原 v1 只有洞府、悬疑、同行、远望、交锋五种通用配乐。筑基后的职业协作、成长兑现、正常分别与重逢缺少独立声音身份；雨棚、水岸、檐铃及雪线环境此前没有文件。补充素材承接 `docs/mainline.md`、`docs/foundation-volume.md`、`docs/narrative/README.md`、`04-companions-and-world.md` 与筑基同行首个切片。

制作交付时尚未接入播放器；随后已按用户要求完成接入：7 首配乐、4 条环境循环、13 个有对应事件的音效进入游戏。`memorial` 已纳入资源目录与试听，但当前没有确认死亡后的纪念事件，因此不伪造剧情触发。详见 [接入与试玩记录](integration.md)。

## 复用及不新增的部分

炼气与日常修炼继续复用 v1 的 home、gather、cultivate、meditate、study、medicine；突破成功/失败、普通战斗、受击、升级继续复用 breakthrough、failure、strike、guard、hurt、upgrade 等。v2 不复制这些文件换名充数。未制作人物台词配音，也没有虚构金丹或飞升阶段已完成的声音方案。

正常分别、发出灯讯、收到回应、真实脱险、确认死亡的纪念各用不同素材。失联或收到遗物不能触发 memorial；同行交接不能触发 vow。结契音已接入双方明确同意后的 covenant 状态变化；纪念音仍是制作储备，等待明确的纪念事件。

## 来源、质量与接入要求

全部是本项目新编音符与程序合成，未使用第三方录音、歌曲、采样包或音乐生成服务；合成拨弦、笛音、木击和环境噪声不冒充真实民乐演奏或现场采样。固定制作种子不读取游戏 RNG。音乐各有独立旋律、节奏与编配，并保留五声音阶风格。

WAV 文件已逐个重新解码：格式、时长、非静音、至少约 4 dB 峰值余量、SHA-256、音效首尾归零及循环接缝均通过。这里是 sample peak / RMS，不是 true peak / LUFS；接缝数值通过也不等于听感必然无缝。尚未做逐条人耳审听、真实手机/Windows 混音及长时间疲劳度验收，这套属于可试听的程序合成素材初版。

接入时延用现有默认静音、用户手势解锁、独立音量、后台暂停、释放声部与跨曲淡化。环境声按需加载、单层循环，避免同时叠加旧底噪。成功音只在持久化成功后按真实状态变化播放，重复查看或读档不重放奖励声。文件失败不影响领域命令与存档。不能通过音频增加剧情奖励、月份或随机消耗。
