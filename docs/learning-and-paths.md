# 功法与技艺：取消开局剑医绑定

2026-11-02，用户确认后实施。以新角色为验收对象；当前筑基可玩范围沿用既有记录，金丹突破尚未开放。

## 设计决定

建角不再选择“长春医道／青锋剑道”。剑法属于应敌与修行功法，采药、炼丹属于可以兼修的技艺，不设互斥职业。玩家在游玩中学习、装备和研修，逐渐形成自己的方向。

各境界共用成长框架、主要地域、人物与主线事件。重要挑战可根据所学功法、准备物资及装备提供不同解法和后果；不要求每个任务都分支，也不分别制作剑修筑基篇、医修筑基篇以及两套金丹人生。药谷、宗门、散修成长路线仍按阶段择一完成，不受初始身份限制。

## 当前代码对照

| 原行为 | 本次行为 |
| --- | --- |
| 建角选择药或剑，后续长期显示身份 | 建角只保留姓名、性别和资质；角色显示当前主修或尚未选定主修 |
| 救回药工按身份自动给书 | 救人后自选长春诀、听松剑经、归元息之一；领取后另行装配，可稍后再选 |
| 医道才能采药，剑道才能历练剑意 | 学会长春诀或辨草录可采药；学会听松剑经可历练剑意，允许同时掌握 |
| 炼气基础效率按身份为 10／14 | 当前世界规则统一为 10，资质、所装备功法、研修与寿元继续影响收益；长春诀的吐纳加成保留 |
| 首次护送按身份赠灵瓶／灵剑 | 首胜后由玩家择一；不会自动装备。已有所选法器则折为灵石 12 |
| 部分药理解法检查开局医道身份 | 改查已学长春诀或辨草录；其余心得、物资、准备条件保留 |
| 宗门成长实战按开局身份选择应对 | 按当前主修剑经与否决定原有应对，不复制新主线 |

入门书只能领取一次。若玩家先通过其他来源学过所选书，谢礼折为灵石 20，仅结算一次；不重复添加功法。折算灵石超出可保存上限时保留未领取资格，不先标记已领；腾出余额后可重试，法器重复谢礼同样处理。另学功法沿用坊市心得 2、灵石 20，以及既有师门和探索渠道。炼丹仍按丹方、材料及制作条件进行，不因剑经主修而被禁止。

统一效率降低了原剑道角色同等条件下的吐纳速度。没有额外增加时间门禁，也没有同步改变功法战斗参数；这次不宣称不同构筑已达到数值均衡或首玩 60–90 分钟目标。

## 实现边界与存档

- `learning.ts` 管理一次性谢礼选择、冻结检查及结算；`LearningChoices.vue` 提供现场与功法页入口。界面只发命令，保存成功后才更新可见状态。
- 权限根据已学知识判断，战斗与吐纳效果仍根据实际装配判断，兼修不等于多本主修同时生效。
- 存档 v26 在 `journey.learning` 记录书册、法器是否已结算；不依赖有限长度的命令去重列表，重新载入或旧命令淘汰后不能再领。
- 原 `path` 字段与函数参数保留给旧数据、历史核心及模拟工具，新建界面固定传兼容值，不再参与当前世界的职业权限、奖励分配和修炼速度。`chapter` 历史规则保留旧行为，当前世界在学习校验后调用其基础行动结算。
- v25 及更早的已完成节点只标记谢礼已结算，不补故事、书或装备；已持有物资与功法保留。未知或较新存档继续拒绝覆盖。新角色奖励标记清空，不继承上一角色所学。

## 验证范围

回归覆盖三册书自主选择、采药与练剑兼修、学习后仍需装备、不同历史标签下同等修炼速度、首胜择器、重复命令与重复领奖、事件/战斗/终止状态冻结、确定性重放与存档迁移。既有全程模拟增加显式领取谢礼步骤。

全工作区验证：82 个测试文件、621 项测试通过；生产构建及 `git diff --check` 通过。构建仍提示主包超过 500 kB，本轮未做打包拆分。

浏览器使用独立本地来源，从新建角色实际完成药庐教学、救回药工、自选听松剑经及装配；建角不再出现剑医选择，角色主修由实际装配决定。319px 宽视口发现选书按钮对比度不足，修正独立样式后复查；[选书界面截图](learning-review/choice.png)。更新样式后再次执行相关规则与界面测试和构建。
