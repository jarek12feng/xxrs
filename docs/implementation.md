# 首版闭环实施记录

## 交付目标

以浏览器可玩版本证明创建角色、修炼、事件、突破、死亡或飞升、遗产、下一世的完整循环。原始技术依据是用户提供的 xxrsjsfa.docx。

## 本版规则

从十六岁开始。每次 tick 推进一个游戏月；自动模式每 650 毫秒发起一次命令。已有待决事件时禁止推进。死亡检查优先于当月修炼收益与事件。每三个月获得三枚灵石，每九个月触发事件，避免连续抽到同一事件。

修为达到当前门槛后封顶，玩家主动决定突破。成功率由境界基础、感悟（最多 25 点）与功法构成；使用护脉丹增加 20 个百分点，最终不超过 97%。成功增加十八年寿元；失败保留 65% 修为、减少两年寿元上限并增加两点感悟。随机使用 xorshift32，推进后的状态随整个命令原子写入存档。

基础寿元四十八年，长春功额外十二年。轮回保留未消费遗产，花费三点选择初始感悟、财富丹药或寿元之一。本世卷宗以有界记录保存，防止无限增长。

## 存档与运行边界

IndexedDB 单个事务更新 current 和 previous 两份快照。当前快照非法时尝试恢复上一份有效快照；两份均非法时显示错误。导入只接受通过校验的 v1 状态。暂未发布旧版本，因此没有历史迁移链。

本版离线时间完全暂停。多标签页同时打开可能覆盖进度，应只在一个标签页游玩；后续增加存档锁和版本冲突处理。导入备份可回退游戏进度，本地单机不做防作弊承诺。
