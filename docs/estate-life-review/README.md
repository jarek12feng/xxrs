# 晴川药庄自主生活首批

2026-11-06。用户授权将自主安排修行生活落到已有区域。本批为筑基药庄的可选合作与求教，不扩写两套职业主线，不增加晋升门槛。现场入口为「药案与护运」。

## 已接入

- 玩家可自选潮药处理、分批护运或直接买药；制药需要已学长春诀或辨草录，护运不要求宗门、恋爱或药庄取材首通。到达药庄即可查看合作。
- 潮药保存湿气/余热：缓烘省草但耗月，分层隔湿耗草但不额外耗月，散热可恢复。允许混用，无固定答案序列。余热超限时拒绝危险操作，不造成隐藏毁药。
- 护运保存三批交接与篓架损耗：短坡每批一月、损耗2；沿渠每批两月、不加损耗；整修一月减损耗2。每批包含返庄，不改变世界地图位置。损耗超过4拒绝再走短坡，允许绕行和整修。不包含新增战斗或连续行路演出。
- 完成任一种合作可携实际记录向岑霁求教，一个月习得「分层封药」。以后隔湿不耗灵草，短坡损耗降为1。求教不是只读谈话发奖，须先亲手完成一项合作，成果用于两个实际场合。
- 完整合作报酬二选一：灵草6或灵石12，接现有库存和工坊用途。两类货源独立，完成后十二月再备一批；离庄不丢进度、不触发期限惩罚。可交还未完合作，已耗年月/物资不退、无报酬。
- 岑霁与药工回应读取真实完成事实与所学手法，不依赖截断日志或刷好感。购买不产生专业认可。沿用旧护根记录的灵石6/8购草价，不重发首通资源。

## 收支与选择

| 方式 | 总耗月 | 灵草成本 | 完成回报 |
| --- | --- | --- | --- |
| 制药，缓烘两次并散热 | 5 | 2 | 灵草6或灵石12 |
| 制药，未学封药、隔湿四次 | 3 | 6 | 同上；适合以现有药材换工钱或早日完成求教 |
| 制药，缓烘一次、隔湿两次 | 4 | 4 | 同上 |
| 已学封药，隔湿四次 | 3 | 2 | 同上 |
| 未学封药，短坡两次、沿渠一次 | 4 | 0 | 同上 |
| 未学封药，短坡两次、整修、短坡 | 4 | 0 | 同上 |
| 全程沿渠 | 6 | 0 | 同上 |
| 已学封药，全程短坡 | 3 | 0 | 同上 |

制药包含备辅药1月和封存复核2月。护运不是高收益刷钱替代原有劳作，完成本领与提供药材来源是主要用途。无零耗时领奖循环；取消不发奖。以上是规则收支，不是玩家满意度或长期经济平衡结论。

## 接口与存档

`src/estate-life/state.ts` 拥有合作、完成次数、下批备货时间、封药知识与回执。`rules.ts` 纯领域负责报价和原子资源结算；月推进由公共命令提供回调，沿用寿尽、事件、战斗、旅行等中断；最后一月被中断不发奖、不记完成。已耗材料不退，原步骤保留，可恢复后重试，重试重新计算该步月份。

`EstateLifePanel.vue` 只读展示及发 `estateLife` 命令。FoundationPanel 只增加现场入口、局部组件和选中时的准备目标。未修改 core 的纯规则边界，没有引入全局NPC模拟、声望货币或职业锁。

存档v60：v59及更早档保守初始化空合作记录；不根据旧药庄首通伪造本批制药、护运或求教经历。已有旧地折扣仍来自原事实。未来/损坏存档拒绝覆盖，新人生清空本批记录。

## 后续边界
