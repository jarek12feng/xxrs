# 洞府单场景与局部操作

2026-11-03，本地表现调整。此前洞府把背景、人物卡、完整炼气探索场景、闭关说明和十余个动作纵向堆叠，且旧 CSS 强制纵排、不限操作区高度。本批只重组表现，不改变规则或命令。

## 操作路径

- “洞府修行”进入听松山居，默认显示同一背景和人物、境界积累、当前目标，以及蒲团、案几、丹炉、灯下和山门五处入口。
- 蒲团打开打坐与闭关；当前选定时长、收益、出关年龄、余寿、剧情中断和年月不可撤回在开始前保留。成长说明、逐月计算与自动行动按需展开。
- 案几打开原有七种活动、逐月行动、自动行动、伤势处理和设施。改变活动仍受原 busy/running 锁约束；运行时不能通过蒲团入口暗中切换活动。
- 丹炉打开原炼丹、固本、筑基机缘与叩关；原消耗、约期风险、前置与命令不变。
- 灯下保留原道途介绍、谢礼/试招入口。山门精准选择已有炼气行旅/筑基行旅/外海行旅；进行中的战斗仍由已有 StoryScenes 优先级处理。
- 操作面板可收起；Escape 先关局部面板并恢复入口焦点，再按 Escape 才打开系统。自动行动的暂停始终留在场景上；待处理暂停原因不折叠。

## 实现边界

App.vue 负责局部选择与现有命令接线，immersive.css 仅为洞府增加视口布局，CultivationOutlook 的 compact 仅折叠解释。去掉洞府里嵌套的 QiJourneyPanel，真正外出统一进入 StoryScenes；未改规则、时间、资源或存档。

PC 背景与 PracticeStage 同层铺满，只允许局部面板内部滚动。窄屏保留入口及可关闭面板，不据此宣称设备验收。复用原有背景与人物姿态，没有新制作洞府交互动画或开放世界寻路。
