## 旅行演出算法

实现：`src/wayfaring/playback.ts`，两种旅行界面共用。

现实播放秒数 = min(18, 4 + 1.5 × log2(1 + 路程里数 / (20 × 速度倍率)))。

速度倍率沿用移动速度与步行速度之比：步行 1、筑基御剑 3、金丹御剑 6、行舟 7.5。路线里程来自现有路线配置，不取画面上两点的像素距离。

- 步行 15 里约 5.2 秒；25 里约 5.8 秒。
- 步行 3,600 里约 15.2 秒；同程筑基御剑约 12.9 秒、金丹御剑约 11.4 秒。
- 行舟 54,000 里约 16.7 秒；最长 18 秒。
- 续行从已存进度开始，只播放余下部分；暂停、跳过、关闭只控制表现。

这是现实演出压缩算法。游戏年月仍按原旅行引擎与剧情路段规则结算，绝不由动画帧数、结束回调或实际等待秒数推进。
