# 金丹外海与诸宗会现场优化

2026-11-03，本地实现，未提交。承接 golden-rollout.md，与炼气正在使用的场内交锋和行动反馈保持同一方向。

## 本批范围

- 外海与诸宗会使用 GoldenWorld 展示主角，古渡与来信场景保留顾沧遥、叶问苓。原半身像保留用于历史引用，新全身透明版本用于现场，避免人物截在腰间。
- 正式行旅导航不再常驻“来信与诸宗会”。古渡的道友之约／会谷来信打开对应局部操作，可从古渡石道返回原场景；观察、切换不发送规则命令。提前五十年告知、赴会条件及费用沿用规则。
- 会谷底图移除固定斗法人物；主角和当前对手作为独立人物进入战场。纪闻霜、程砚舟有独立全身素材，胜绩推进后相应人物候场。背景观众仍为静态环境，不宣称可以逐个交流。
- 外海遗迹和诸宗会/归潮交锋复用 CombatField、CombatBar：战斗隐藏探索热点、右侧大操作框和重复目标，只保留场中敌我与底部招式、来势、实际预估、撤退。守珠傀儡与石卫复用石雕护法素材；照神阵枢使用独立几何阵纹，不把人族对手换成怪物。
- 非战斗操作在局部短面板展开。闭关详细估算置于“安排闭关”内，执行前仍可见完整成本；不隐藏风险和不可逆后果。胜利、取宝、温养、转修及中后期突破后收起面板，展示短结果与相关人物姿态/器物。定神珠采用简化珠体与护体光，书册复用既有美术。
- 男性主角在会谷选中人物/石台时，复用既有八帧步态沿审阅过的空场地短距离走近；可略过，不强制等待操作。同一现场收起面板保留脚点，交锋、忙碌、待处理事件、后台、Escape 和卸载停止移动。女性仍保留静态人物，不借用男性步态。

## 工程边界

新增 `src/golden-scene/presentation.ts` 是只读投影，`GoldenWorld.vue` 管理临时表现。`StoryScenes` 仍是唯一主场景入口，不上下堆叠完整面板。共用战斗组件仅补一处计时器取消包装，详见下方追加验证。

仅从父层成功更新的状态比较产生结果；组件不自发提交命令、不改资源/RNG/年月/奖励/存档。首次读档、重复同步不补播旧成功；失败撤退不显示胜利。跳过、后台与卸载清理计时器。动作资源预载只在组件挂载时进行。

## 追加：器物过程与秘境现场（2026-11-03）

- 进入未通关的退潮遗迹、归潮秘境即能看见当前石卫、守珠傀儡或照神阵枢，点击对应对象进入既有交锋。离境或开始战斗后不保留第二个守关者；已通关层不重新生成表现。
- 温养、参悟和突破使用短暂的聚息、凝定、收势三段反馈（共约 2 秒）。器物按当前真实所有权显示在主角身侧，关闭操作面板不再使取得/温养的物品立即消失。外府首胜不提前显示尚未选取解封的法宝和功法；先分取一件后只显示该件。
- 打坐姿态独立预载，同步解码；未加载或加载失败保留站姿。器物跟随主角实际脚点，避免会谷走近后效果仍留在原位置。此处仍是静态姿态、器物位移和光效，没有新增完整持印、翻书逐帧动画。
- 减少动态效果时保留静态器物和结果说明，不播放分段变化。跳过、换对象、后台或卸载清理临时反馈；仅在父层传入新结算状态后开始，不自行执行任何领域命令。
- 修正分宝提示，把“收好所得，交接潮图”改成取得对应器物，避免将尚未执行的交接写成已完成。
- 浏览器连续快速出招实测发现共用 CombatField 把原生 clearTimeout 作为 options 方法调用，触发 Illegal invocation 并阻断场景刷新。仅将 cancel 改为箭头包装，保留浏览器调用语义；复验快速五次出招、胜利返回、分宝和温养正常。

## 追加：整备、入境与撤回（2026-11-03）

- 避潮行装按真实 prepared/supplies 状态显示为主角身侧的小型包袱；本轮为简化 CSS 器物，不是新增写实美术。成功整备后收起操作框，短提示可动身；读档不重播准备。
- 进入退潮外府/内府、归潮两层后，按实际层级提示眼前守关者。男性复用八帧步态，从前景石道入口短距离走到落脚点；选择守关者与退路时，可沿前景固定走廊走近。走动可略过，操作不必等动画，不触发额外月份。归潮背景的断桥、远处石阶不作为可自由通行区域。
- 主动退出交锋和直接离境均有撤回提示；新伤或大比重试期限增加时显示养伤提醒，大比失利注明半年再试。没有取宝或胜绩增加时不播放成功器物反馈。达到伤势上限时不以姿态推断新伤，既有详情仍以规则记录为准。
- 修正关闭局部面板会取消刚开始的入境步态的问题；入境期间只显示一条可跳过提示。选择其他对象、忙碌、交锋、待处理事件、后台或卸载仍可停止走动。
