# 炼气走近、出口与关键动作

2026-11-03。本批在现有规则上实施，未改规则、数值、存档或世界时间。

## 已接入

### 药谷 / 内府与听松山下

- 点击晋升灵材、山道、摊位、人物热点后，主角先沿画面下部的保守通行带走近，抵达才打开局部操作。连续选择以最后一次为准。
- 男性炼气复用 `hero-qi-walk-v2.png`：1536×1024、4×2 格、每格 384×512，8 帧，每帧约 100ms，左右转身。该素材来源与透明背景检查见 `art/walking-prompts.md`。
- 入境 / 非交锋中撤回先向出口移动，抵达后才发送一次既有领域命令。可略过，Escape / 后台 / 卸载取消且不提交延后命令。规则命令仍自行校验、持久化后再更新画面；保存不成功不会提前换场。
- 无适用步态、图片加载失败、女性角色、减少动态效果直接到达；不会拿静态立绘平移冒充步态。走近不扣年月、不改资源或随机种子。
- 取材成功后的短过程：收拢护材 → 封入药囊 → 收妥。男性炼气复用已制动作图的三种相应姿态，其他角色保留静态姿态与可读反馈。它发生在真实战斗取材成功且已保存之后，不另加采集奖励或再次确认。
- 炼化成功后的短过程：化开原材料 → 灵息归流 → 经脉/气海结果。取材 / 炼化均约 2.1 秒，可跳过；使用突破前对应材料，不把刚用掉的凝露草错误显示成下一阶段晶髓。
- 新读档不重播成功；后台、事件锁定和卸载清理短过程。选择现场对象可以打断当前过程，再走近该对象。

## 共享接口

`useSceneApproach({ animated:()=>boolean, initial?:Point })` 返回：

- `position / moving / frame / facing` refs：表现层百分比脚点与序列帧。
- `walkTo(point,onArrival?)`：替换未完成路径；调用方提供人工约束的地面脚点，不直接用天空热点。
- `skip()`：到终点并执行当前到达回调一次。
- `cancel()`：取消且不执行回调；`reset(point)` 取消并恢复入口脚点。

`WalkingActor.vue` 接收 `character / label / position / moving / frame / facing / pose? / sheet?`，用 `ready(bool)` 报告素材是否可用。默认仅炼气男性 4×2 图；筑基调用方必须传自己的正确素材并自行控制 `animated`，不能用炼气衣冠替代。模块负责清理 RAF、媒体查询和可见性监听；没有领域状态、存储、计月或奖励接口。

- `npm run typecheck` 通过。全量测试与生产构建由主代理整合执行。
- 本代理浏览器工具返回 `browsers=[]`；尝试创建 IAB 标签返回 `Browser is not available: iab`。因此本批**尚未自行完成 PC 截图与步态实机检查**，交由主代理在可用浏览器验收，不以 DOM 测试替代。
- 目前使用有限的前景脚点，未做全图地形碰撞；动作仍是短姿态序列与环境效果，没有全角色高帧率动画。Windows、Steam、所有分辨率及真人从新角色完整流程均未在本批验收。

炼气首战结束且已保存 `node 1 → 2` 时新增短胜利提示，告诉玩家前方灵流逆涌、整顿后再进；不根据 `duel=null` 推测最后一击伤害。初始加载与失败撤回不误播胜利。战斗撤退按钮同时读取 `qiError` 的禁用状态，不能在事件阻断时看似仍可撤退。

共享行走模块另兼容没有 `addEventListener/removeEventListener` 的旧 `matchMedia` 实现；相关专门回归覆盖挂载、减少动态与卸载，没有修改测试 mock 规避异常。

同场脚点回归：Qi 原先按包含 `gates/essence` 的场景键重置位置，会在城内炼化保存后瞬移回入口；现仅在“进入 / 离开秘境”的实际场地变化时重置，灵流节点与同场炼化保持脚点。Mist / Road 只在前后 `stage` 确实变化时重置，不因每次状态快照替换回到入口。
