# 筑基行走与修图交接：本地实施记录

2026-11-03。仅表现与交互编排，不改领域规则、随机、数值、存档或时间。男性筑基主角有专属步态；女性角色和资源加载失败时直接抵达，不让静态立绘滑行。

## 实际接入

- `FoundationWorld.vue` 接 `useSceneApproach` / `WalkingActor`。后两者由炼气行走任务单独维护，筑基不复制计时器或改变接口。
- 点击人物、器物或道路热点，先走到人工指定的前景脚点，再打开对应操作。这里是有限的前景交互走廊，不是整张图片可寻路。
- 行囊仍在身边；远行需先在道路面板查看真实费用/时间并选择目的地，再走到出口，抵达后只发一次既有 travel 命令。药庄右侧是水渠，出口在左侧道路；禁止拿空中热点坐标当脚点。
- “直接抵达”执行一次抵达回调；“停步”、Escape、后台、卸载、替换角色状态及忙碌状态取消未完成移动和延后旅行。减少动态效果与无匹配/失败的步态资源直接抵达。动作显示从保存后的新状态派生，移动不改游戏状态。
- 行前居修图交接：先靠近苏婉宁，玩家选择公开干道/绕行方案后由既有命令结算；收到成功状态才依次显示撤下旧刻样、重订路图、收好副图。已有地图器物改变展开/收起姿态，苏婉宁切换既有工作/旅行姿态，完成或跳过后回到已保存的最终现场。该段无新绘手臂/口型帧，不称完整人物动作动画。
- 筑基交锋接入独立任务提供的 `CombatField` 和 `CombatBar`，敌我在现场，招式与来势在下沿。原右侧战斗大面板移除；伤敌、承伤、耗草、回血、致命风险及招式衔接保留在按钮详情，补充规则与回合明细可展开。命令仍是原 move/withdraw，交锋动画只读已保存快照。护圃、护山、试法与归流阵不再沿用旧配置中的石偶替身图：缺专属阵法素材时显示真实阵名与数值，未补造妖兽或人族对手。

## 可复现入口与验证

`tools/foundation-sites-preview.html` 提供药庄、雪线试炼前/完成现场，以及“苏婉宁修图交接”。全部由 `journeyPlayer` 的公开命令生成，不读写玩家存档，也不直接注入领域结果。

定向 20 项通过：`foundation-movement-ui`、`foundation-performance-scene`、`foundation-scene-objects-ui`、`foundation-sites-checkpoint`。新增检查：匹配步态加载后先走再开、纯观察不改状态、出口抵达才发送一次旅行、Escape/外部状态替换清除延后命令，以及公开命令修图成功后才显示交接。类型检查通过。测试不证明真人难度/体验，也不等同于 Windows 或 Steam 验收。

浏览器核对由根任务使用现有 IAB 完成：子任务没有可用 browser surface，遵照分工不再尝试原生 Chrome。最终截图和待修项在此追加；在追加前不宣称 PC 全面验收。

## 剩余边界

女性步态、独立纵向/背面步态、物理避障、全部场景专属出口、苏婉宁真实行走帧及所有任务逐帧动作均未完成。当前关键任务是修图交接，不覆盖筑基每条支线的完整演出。Windows、系统缩放、多分辨率与陌生玩家连续体验仍待验收。

## 继续复核：状态取消与素材边界

八格原图再次逐格检查：人物 alpha ≥128 的脚底均在 y=494–496，实际260px高时约1px的帧间变化；格线 alpha 最大1–4/255。没有发现需要重生成的裁切或不透明框，未生成新图。

独立战斗复核发现 UI 原先只在 busy 时阻止直接提交。已修正为 `act` 入口和旅行抵达回调都复核 `journeyActionError`；有待处理事件、死亡等领域锁定不再发出无效命令，撤退按钮同步禁用。招式消耗灵草与实际回血独立展示，避免“消耗但回血为0”时漏报成本。新增测试验证忙碌中断出口、女性不播男性步态、锁定战斗禁用且不发命令；当前 movement UI 6项通过，类型检查通过。浏览器验收仍以根任务截图为准。

### 实机发现并修复同场瞬移

根任务 IAB 确认男性筑基八帧走近并抵达后打开面板；实际点击“另探替代路”后，截图 `foundation-map-sequence-pc.png` 暴露男主回到入口的问题。原因是监听器每次状态替换都返回新的 `[location, mode]` 数组，误触发脚点 reset。现已改为分别监听两个标量，只在实际地点/模式变化时复位；同场成功、跳过演出和替换等价状态保留靠近位置。新增测试以真实 `mapPlan` 命令验证38%脚点保留，再以真实 travel 验证换场回到入口。

同时移除 HUD 中按句号粗截的重复对白（会截成“我没写名字”半句）；完整原文保存在“此地见闻 → 刚才经过”，不改剧情。修复后待根任务更新截图确认。

药庄战斗截图 `foundation-combat-bar-pc.png` 确认固定招式栏可读，同时发现探索热点仍露出。已修复交锋时不传探索热点；`FoundationWorld` 保持挂载，但战斗期间隐藏探索人物，只在确实进行护圃/护山/试法/归流阵试炼时显示局部阵纹与真实阵名，复用既有简洁同心阵纹表达，不替换成石偶或人像。撤退后恢复探索人物和热点并移除战斗阵纹。新增公开命令测试覆盖开始/撤退前后的显示切换。局部阵纹修正后的最终截图待根任务复核；阵纹不是完整阵法攻击动画。
