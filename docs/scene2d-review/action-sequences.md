# 开篇配药与营救动作序列

2026-11-03，本地接入，承接 walking-slice.md。

## 玩家可见变化

- 配药成功后，在温蘅药炉旁依次呈现取药、温药、封装及递出药包的姿态，约2.1秒。
- 营救成功后，呈现稳住阵门、接应药工、搀扶离开及站稳姿态，约2.3秒；结束后药工留在归路安全处。
- 短字幕只标出当前动作。演出期间收起操作面板；“跳过演出”、Escape、选择其他人物或移动都能中断演出，立即恢复已保存的最终现场。
- 系绳、调息接入相同控制器，目前沿用已有姿态，没有专属多帧素材。

## 后续开发必须遵循

`action-sequence.ts` 是纯时间线；`action-player.ts` 管理 Phaser 对象；OpeningScene 只负责字幕、跳过和命令入口。仅观察父组件提交的保存成功状态变化，演出不发领域命令、不改资源、时间、奖励或随机数，不新增存档字段。载入已完成状态不重播，重复同步不重播；切场景、销毁和跳过必须取消计时器，迟到回调不能再修改画面。减少动态效果时直接显示最终现场。素材缺失保留原角色和药工。
