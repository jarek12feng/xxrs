# 凝丹至金丹后期的 PC 场景改造

2026-11-03，本地表现层改造，未提交、未发布。既有规则与开放范围分别以凝丹、外海、诸宗会实施记录为准。

## 已接入的交互

- 凝丹筹备在行前居展开：凝露药圃山路、合药炉、师门传讯/护关阵台、凝丹静室分别承载取药、炼丹、奖励与护持、选地与叩关。药圃阶段呈现柳知微与药床、守药石偶、凝露芝心和归山小径，随实际进度更换对象；金丹初成后改为云壁。
- 外海以古渡、退潮外府、内府为独立场景。堤边修士相识后显示顾沧遥与叶问苓；现有真实人物透明素材置于现场。共享潮图、交接归人物，整备及入境归石道，法宝与功法归随身物品，闭关归临海静修处，返乡归海路。
- 诸宗会按会谷、归潮秘境、古渡来信区分现场。来客交谈/备战/路线、具名对手斗法台、秘境入口、护神宝物、歇脚处、出口分别展开动作。具名人族对手保留真实姓名、宗门与意图，未用怪物立绘替代。
- 常态不展开整页操作。选对象只改变组件选中状态；长经历和上一行动全文进入可打开的见闻，动作按钮与效果、真实成本分行显示。
- 所有战斗回合在进入或重载交锋时直接显示来势、气势、招式及撤回，无需先点击对象。凝丹叩关前仍显示丹药/护持消耗、六个月、预计年龄与余寿、失败伤势。

## 工程边界

使用共享 NarrativeStage，PC 视野尺寸和键盘/关闭行为由共享组件维护。三域动作分组在 `src/scene2d/golden-objects.ts`，以动作 kind 穷举定义；新增动作必须明确归属。按钮继续调用既有 quote 与命令，不改 RNG、资源、时间、存档或规则。

顶层场景互斥由 StoryScenes/App 统一接入，本文件三域组件不自己创建全局路由。特别是外海古渡与诸宗会来信不能上下叠成两张全屏场景。

## 验证

- 三条原 UI 成长路线现通过实际对象入口再点击行动：分药—取药—合药—选地护持—凝丹—云壁；外海相识—共享—外府实战—取印—交接—温养—闭关；诸宗会两胜—两层秘境—温养—参悟。
- 新增 5 项组件检查：三个域各自的对象观察不发命令且年月/种子/资源不变；凝丹损失前置可见和 busy 禁用；恢复外海战斗无需选中对象、点击只发命令而不预先改变回合。
- 本子任务运行四个测试文件共 8 项通过。全量测试、生产构建和最终浏览器实查由主任务合并验收后记录；不据这 8 项检查声称完整新角色真人体验。

## 仍需区分的表现边界

这是已有剧情的场景交互组织，尚非完整的逐镜头演出。后期背景沿用现有素材；凝丹筹备借用月台，药圃借用既有药园，暂非独立定制布景。外海两位已有角色有现场立绘；柳知微、诸宗会其余具名人物、守阵过程尚无新增行走/交手动画。不能把场景热点、静态立绘和面板切换称为完整战斗或营救演出。Windows、Steam 安装运行和陌生玩家体验尚未由本子任务验证。
