# 场景镜头与行动反馈补充

2026-11-03，本地实现；承接 all-story-rollout.md。

- NarrativeStage 的 PC 对象选择采用有界轻推镜头、选中标记短回应、其余对象淡化；关闭恢复视野，切换背景短交叉淡入。动画不阻塞动作，也不推进年月。窄屏不推镜头。
- 对象支持方向键移动焦点，Enter 原生激活；方向键本身只观察，不提交游戏命令。换对象重建操作面板以清除上一对象的滚动位置。窗口 resize 观察器和页面可见性监听在卸载时释放。
- 开篇药庐成功准备后按方法显示药炉蒸汽/炉光、归绳或铃光。山祠营救成功后阵环短暂散去，读取已营救状态不重播。只接收成功持久化后的方法/准备/营救状态；保存失败回归验证不提前送出营救状态。
- EventScene 的桌面对话和行动选择分栏，正文和选项各自滚动，长文展开不挤走选项。换事件复位阅读，已处理选项的焦点回标题。详见 event-dialogue-polish.md。
- prefers-reduced-motion 下关闭镜头过渡、对象回应、对话淡入和阵环散去，准备状态使用静态表示。后台暂停开场渲染循环和共享舞台动画。

全量 npm test -- --maxWorkers=4：105 文件、732 项通过。另补保存失败/成功渲染状态断言后，scene2d-ui 单测通过。构建和 diff 检查通过（仍有既有包体大小提示）。

1280×720 浏览器检查公开命令生成的药炉准备、回访对象镜头、陆迟家书事件；检查页不读写玩家存档。证据 object-focus-pc.png、event-dialogue-pc.png。检查入口 tools/scene-effects-preview.html 和 tools/story-scenes-preview.html。

这些仍是镜头与现场效果，不是人物完整行走/交谈动作、碰撞寻路或全剧情专属演出完成。没有完成所有分辨率、Windows 实机、Steam 发布和真人沉浸感验收。
