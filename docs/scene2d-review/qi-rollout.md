# 炼气、青嶂与雾海场景迁移

2026-11-03。本轮为现有剧情的 PC 表现层重构；不新增剧情、月份成本、奖励或存档字段。

## 已接入

- 青嶂行路：药庐回访、坊市、青嶂关、行营、云外长路、云栈旅亭均使用全幅现场。人物交谈与交货、山口调查与三种解法、行装整备、道路出口分属不同热点。篇章结语在旅亭的归路入口查看，不再替换整个现场。
- 雾海来信：来信、行营、药圃、废驿、回声阵、档案、归家与旧山祠均以人物、现场器物、补给和道路区分操作。同行选择、分路调查、护归准备及重访能力保留。场景长背景进入“此地见闻”；人物回应在选中后出现。
- 炼气道途：山下现场分为晋升秘境、成长路线、坊市补给与故人。两处秘境保留入境方式、险地选择、炼化、撤退和三种真实战斗动作。读档恢复到战斗时无需再次寻找入口。
- 青嶂护送：在药队入口处理委托与阵眼；交锋使用原有专用战斗布局，并传送到页面根部，避免在带背景模糊的现场操作层中被裁切。行程、功法说明与旧回执折叠，整备建议由“检查行装与补给”打开。
- 使用既有主角待机立绘在场景中定位；人物肖像在交谈层展示。没有将肖像冒充新增全身素材。

## 保持的边界

热点只修改组件局部选中状态，不发命令，不消耗时间、种子、资源。真实动作仍走原有 act / dispatch / 保存流程，显示结果由父级持久化后的游戏状态决定。切地点收起旧对象，战斗不能通过关闭热点绕过。

已知成本与不可逆结果保留在对应动作中。雾海约定即使已选定，也持续显示耗费和失败后果，避免“已作出这一约定”的禁用说明覆盖原有风险。青嶂数字键预览仅在打开山口对象后生效，仍不能快捷提交不可逆解法。

## 验证与缺口

本分支本轮 `vue-tsc --noEmit`、7 个测试文件 / 48 项测试及 `git diff --check` 通过；全量构建与全量测试由主任务汇总。

针对性自动检查覆盖：场景入口不修改领域状态、父级未更新不提前显示成功、青嶂解法代价与不可逆告知、雾海约定成本及失败结果、载入炼气战斗后动作与撤退可达、busy 禁用、全部雾海地点及原路线回归。相关测试为 qi-scene-rollout、qi-preparation-ui、road-desktop、road-epilogue、pass-solutions、scenes、expedition-ui。

本轮没有制作新的 NPC 全身动作、逐地点自由行走、救援或破阵完整演出。背景和待机角色只是现场布局与现有美术复用，不能称为完整沉浸演出。尚需主任务统一做 PC 实际窗口截图与键鼠检查；这份记录不声称已通过 1080p/720p/1440p、Windows 或 Steam 验收，也不将自动测试等同于陌生玩家体验。
