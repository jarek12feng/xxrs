# 雾海来信的现场变化

2026-11-03。本批只改表现层：`MistPanel.vue` 接入 `scene2d/MistWorld.vue`，由 `scene2d/mist-performance.ts` 投影现有存档事实。没有改变成功率、资源、月份、种子、剧情和存档结构。

## 已接入

- 药圃：复用原画中的梯田与药草；`garden` 完成后在台地边缘增加小尺度、低饱和的水光与细叶线条，首次完成有短引水效果。没有另叠一块大面积卡通药圃。
- 废驿：未辨明的灵脉分段；`station` 完成后阵纹连通。
- 回声阵：`passed` 完成后阵门竖纹散去，保留地面阵纹。失败只给撤回与记下间歇的反馈，不显示开门。
- 行营护归：已有 `ward` 时可见护归阵纹。
- 探灵灯：档案室能看见尚未带回的灯；`lamp` 完成后在行营、坊市和山祠显示携回的亮灯。
- 重访山祠：`revisited` 后刻痕亮起、避难室归灯显现，原有完成背景继续保留。该节点不是再次营救人物，不增加不存在的被救者，也不把陆迟父亲的失联写成归来。
- 陆迟：仅来信、本人同行及规则支持的归来茶摊现场显示既有透明人物；已回故乡的茶摊不显示他。没有适用透明形象的其他人物沿用局部交谈面板。

这些是器物状态变化与短反馈，**不是完整人物逐帧动作、连续行走或开放地图**。药圃、阵纹和墙体采用表现层 SVG，人物与灯复用既有游戏素材，未生成新图片。

## 播放约束

只比较父级传入的已保存状态。初始挂载不播，完成后重访不播，命令未保存成功则没有对应完成状态与演出。短反馈约 1.8 秒，可按钮或 Escape 跳过；点击其他现场热点也会立即结束反馈并打开该处操作；跳过不撤销结果、不发送领域命令。进入后台、切换到另一现场、卸载、改为减少动态效果均终止反馈并清理计时器；前台恢复不补播。减少动态效果直接保留最终现场。
