# 通用剧情对话的 PC 布局完善

2026-11-03，本地表现层变更。范围仅 `EventScene.vue`；沿用调用方原有标题、人物、正文、选项及命令，不更改剧情事实、费用、奖励或存档。

- 桌面底部对话区域横向分为人物／经过和决定两栏。正文与选项各自滚动，展开全文不将选项推到正文后方；所有费用、禁用原因和后果仍来自原选项并直接展示。
- 人物肖像与姓名成组；无人物事件使用“眼前所见”，不补造说话人。长文默认前两句，保留引号和原文，展开按钮提供 `aria-controls`。正文可以用键盘滚动。
- 事件更新时收起长文、复位局部滚动，并播放 180 毫秒的轻淡入；系统要求减少动态效果时关闭动画。没有打字等待、动画完成确认或延时解锁。
- 旧选择获得焦点时，新的事件将焦点移回标题，避免键盘留在下一事件选项上。焦点位于组件外时不抢夺。
- 窄屏继续上下分区，作为次级兼容；本批并非人物口型、完整交谈动作或 Windows 实机验收。

验证：`tests/event-scene-ui.test.ts` 7 项通过，覆盖展开不提交、不隐藏选择成本后果，同标题内容改变复位，短文完整，换事件焦点，外部焦点不抢夺，引号与可访问展开关联。`npm run typecheck` 通过。布局的自动化 DOM 检查不能代替真实分辨率截图及玩家体验验收。
