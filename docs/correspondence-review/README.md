## 实际浏览器检查

通过独立页面 `preview.html` / `preview.ts`（不读写 IndexedDB/localStorage 游戏档）操作：

- 展开照玄邀约，未读数1→0；原剧情仍未答应。
- 点击暂谢绝，公共状态变为 declined；再点击愿意同行，变为 promised，年月仍为第185月。
- 自动新增一封“照玄旧约已记下”，未读数变为1；关注原信后显示已关注。
- 用户要求加强读/未读区分后重新验证：原邀约显示已读、新回音显示未读；已读筛选仅保留原邀约。
- 1280×720 检查初版两栏布局；随后浏览器实际侧栏视口为319×669，检查了最终文字徽标、状态筛选与列表窄屏堆叠。截图：`invitation-accepted.png`、`read-unread.png`。

这是隔离组件与检查点浏览器证据，不是主游戏完整新档连续试玩、所有来信全分支、Windows/Steam或真人体验验收。完整正常新档中的信息节奏、长期阅读负担、全部场景的传讯入口仍待后续连续试玩。
