# 金丹潮纹剑与旧宝续炼

2026-11-05。本批接入可选攻击法宝链，不增加晋升门槛，不代表所有法宝培养或全丹药系统完成。

## 实现

外海古渡人物处可翻阅旧器谱，提前得知离照侧路的潮纹剑胚、守匣傀儡、准备方式及御器取舍。离照分潮石道打通后回港，从药囊处进入器室支线。有效神识28自行定潮或灵草6备药，两路均花12灵石、3月；战胜守匣傀儡才获得唯一器胚。最多18合，失败伤势+1，主动撤回不加伤，准备不退，可恢复后重试。

器胚以有效神识24、24灵石、6月温养，不自动出战。潮纹剑占容量10，基础伤害+3；前招守势或辨影后，在正确反击窗口额外伤害+10、承伤+2，连续反击不触发。试罡石台耗1月、不发额外资源；必须在战中真正触发破罡并获胜才记录完成。器室护罡可由辨影寻找间隙，未取得新剑也有解法。

镇潮印须已温养、亲历外海内府；定神珠须已温养、亲历归潮深层。各花24灵石、4灵草、6月续炼，分别在正确守势、正确辨影时额外减伤3。均须出战。三宝容量合计24，高于现行最大22，不能全部出战；可以收集全部，再按战况搭配。

`artifact-growth` 封装状态、报价、预览与命令；战斗复用公共执行器，器物效果归 equipment，剧情面板只调用命令。存档v45先验证v44，再补空成长域，不补发剑胚或培养奖励，拒绝未知版本。

## 实际界面证据

使用独立端口5392，从 `tools/artifact-growth-checkpoint.ts` 通过公开命令生成的金丹后期检查点导入。不是正常新档连续游玩，不覆盖5391的原连续档。

- 起始第2562月、灵石176、灵草41、有效神识36；离照外层已通，已读器谱。
- 选择备药：花12灵石、6灵草、3月。守势、反击、辨影循环，第7合获剑胚；第1合后刷新，正确恢复第2合气势与敌方余量。
- 温养剑胚及续炼印、珠各6月；完成后灵石92、灵草25。
- 行囊原为灵瓶+印+珠，占16/16。新剑禁用并明确容量不足。收回灵瓶与镇潮印后，剑+珠正好16/16，可出战。
- 试罡第1合守势；第2合反击预览69，实际敌气势191→122，承伤10；第3合定神珠辨影减伤预览5，实际气势73→68。第5合获胜，完成首次破罡。末次月份2584。再次刷新、继续游戏、进入器谱后，破罡完成与培养状态保留；见 [读档后界面](reloaded.png)。

## 自动验证与边界

单元与公开命令集成覆盖两种准备、失败重试、主动撤退、时间中断不吞材料、重复奖励拒绝、确定性、当前状态预览一致、战中互斥、容量、未装备不生效、试剑未破罡不算完成，以及保存迁移。最终 `npm test -- --maxWorkers=2`：191文件、1310项全部通过；`npm run build`（含vue-tsc）与 `git diff --check` 通过。首次默认并行测试有2项旧60路线回放超过5秒时限、其余1308项通过；未更改超时或断言，降低并行数后全通过。构建保留大包体积提示。工作区含此前改动，这些是整合结果，不全算本批新增。

真实UI覆盖备药路线；自行定潮、印的战斗减伤、失败重试主要由自动测试覆盖。旧器谱的提前听闻有公开命令证据，尚无从外海开始自然发现至此的同一新档UI证据。尚未证明陌生玩家期待感、平衡、所有功法组合或Windows/Steam验收。破罡解除减伤当前落实在器室与试罡的护罡机制；其他共用战斗读取剑的蓄势伤害效果，不宣称每个敌人都有护罡。
