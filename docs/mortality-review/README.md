# 挑战、成就与陨落收束

2026-11-05。用户授权整体优化检查发现的问题。本轮已实施，范围为现有高风险内容的真实陨落、寿尽提示、人生总结和结束表现；不是全关卡重平衡或正常新档连续验收。

## 风险与选择

| 内容 | 原行为 | 本轮行为 |
| --- | --- | --- |
| 寿尽 | 按月先于收益结束人生 | 保留规则，新增死因记录；只余一月时不再建议来不及的探险 |
| 外海外府、离照外层、试雷 | 失败伤退 | 保留学习与恢复空间 |
| 外海内府 | 气势耗尽也安全回渡 | 气势耗尽陨落；十六合超时且气势尚存可伤退 |
| 离照内层、伏潮湾夺药交锋 | 气势耗尽、积毒100仍可回港 | 气势耗尽或积毒100陨落；十八合超时且仍能自持可伤退 |
| 正式凝婴天劫 | 气势耗尽自动散功回静室 | 气势耗尽陨落，包括同时击散雷势；十二合超时且尚有气势可散功伤退 |

进入与出招前公开风险，预览复用公共 `resolveTurn` 的同回合结算，计入真实药草恢复和反击，不另掷随机死亡概率。离照额外计入本招毒量。普通招式、准备、法宝、功法和收益保持原值；主动撤离的成本沿用现有规则。失败的死亡分支先于发奖和晋升，不能同归于尽后得到材料或增加寿元。

这使准备、读势和及时放弃机缘有实际分量。没有把每次日常学习、切磋变成生死赌局，也没有扩大为全世界随机死亡。未改变炼气/筑基突破概率、寿元基准、普通经济和修行时长。

## 总结、画面和音乐

- 修复金丹/元婴显示“尚未筑基”；补外海宝物、诸宗会胜绩、离照取药与试炉、化婴丹、凝婴、结契礼和首次护渡的真实记录。

- 未竟之愿来自当前境界、实际开始的取药/凝婴准备及已知人物去向。旧未知死因不强写为寿尽。

- 死亡配乐优先于旧地点音乐，重新载入死亡存档仍选对应曲目。继续遵循声音偏好、交互解锁、后台暂停与卸载清理；终章内直接提供开关及实际播放状态。

## 状态与边界

`src/mortality` 负责死因、只读结束投影与纯预警；章节只在命令拥有的草稿上结束人生。版本57新增 `death: null | { cause, month, age, realm }`；校验要求死亡记录与当前结束时间和境界一致，寿尽死因要求确实达到寿限。公共 dispatcher 在死亡后拒绝继续修炼、恢复和冒险命令。

v56及更早版本保留事实并补 `death:null`，不推定历史战死、不重发机缘、不重写原结局。年龄确实达到寿限的旧死亡可只读显示寿尽；其余仍显示旧卷原文。未知未来版本继续拒绝覆盖。
