# 炼丹炼器优化实施与验收

日期：2026-11-02。当前为本地实现，未提交或推送，未制作新发行包。工作区包含其他会话的成长与人物表现改动；下列范围只描述制作系统工作。

完整规则、价格、状态归属、模块接口与恢复边界见 [设计说明](../workshop-design.md)。

## 本轮前后对照

| 原有表现 | 本轮实现 |
| --- | --- |
| 普通炼药、炼器、筑基丹各处结算 | 独立 workshop 模块统一报价、校验、订单和结算；旧命令适配至同一路径 |
| 自制基础药/法器不耗月，成品采购耗一月 | 自制/委托耗一月，成品即时；筑基丹仍三月 |
| 回春散成品已有，清心丹缺少并列获取方式 | 两种基础药均可自制、买成品、委托；共同入口直接比较 |
| 只有直接耗草、辨阵、强闯战间险地 | 增加护脉丹方案，恢复 26 对照灵草 18；没有丹药仍可通行 |
| 法器仅升阶，缺少定向选择 | 灵剑/灵瓶各两种有代价的器纹，筑基后可付费重铸或恢复原纹 |
| 炼丹中断与队列次数容易脱节 | 先推进筹备月份，事件/死亡先于扣费；出丹后才扣队列次数 |
| 入口分散 | “丹药与法器准备”统一入口，储物袋仍保留服药和快捷制作 |

没有新增境界、自由交易、随机品质、强制刷矿与熟练度；现有灵草、功法、战利品报酬及三条成长路线保持各自职责。

## 证据

- `tests/workshop.test.ts`：三种方式收支与时间、旧新命令一致、重复命令、无资源/剧情/交锋/死亡锁、中断零扣料、四种器纹实际战斗修正、重铸、真实公开命令走到秘境险地后服丹、无丹替代路线、存档往返与非法数据、自动炼丹中断保留次数。
- `tests/workshop-ui.test.ts`：按钮使用同一报价、库存与禁用条件即时刷新、真实命令购丹/购器/装配、剧情期间禁用写操作。
- [audit.json](audit.json)：固定种子 2718，用正式命令生成炼气/筑基/险地检查点，比较 21 组物品与获取方式及四种通行方案。检查点额外劳作与采药用于备齐比较预算，因此记录月份不是自然玩家筑基速度。
- `tools/workshop-preview.html`：独立开发验收入口，仅内存执行命令，不读写用户正式存档；实际验收来源为 `127.0.0.1:5231`。
- 390px 浏览器实际点击炼护脉丹：第 125→126 月，灵石 203→197，灵草 24→21，护脉丹 0→1；页面宽度与滚动宽度均 390px，图片全部正常加载。见 [丹药窄屏](medicine-390.png)。
- 390px 浏览器实际点击灵瓶镇守纹：第 177→178 月，灵石 178→170，玄铁料 3→2；当前器纹更新，相同器纹禁用，恢复原纹可选。见 [刻纹窄屏](temper-390.png)。
- 两张图标由独立素材会话交付并接入，运行时 WebP 合计约 35 KB；原图和 48/64/128px 深浅底色 QA 在 [素材记录](../workshop-art/README.md)。

最终检查：`npm test` **71 个文件、557 项测试通过**（包含并行人物素材测试）；新增制作专项共 18 项。`npm run build` 与 `git diff --check` 通过。构建主 JS 约 619.34 KB（gzip 232.98 KB），仍有 Vite 大于 500 KB 的包体提示，本轮不宣称打包性能优化完成。

完整回归期间同步更新了过时的男性炼气人物图片路径断言，以匹配并行接入的真实素材；360 次整局重放的正确性测试在并行构建下曾超过默认 5 秒，将该测试单独设为 15 秒超时，未减少场景或放宽状态断言。收尾独立执行全套测试约 7.37 秒。

额外实际浏览器验证：秘境险地剩余气势 46，草药方案预览 64、护脉丹预览 66（受上限截断）；点击服丹后以 66/66 气势进入青鳞蟒战，伤势仍为 0。见 [服丹进入下一战](passage-390.png)。浏览器错误日志为空。

## 未验收与明确边界

- 这些是开发自动回归、公开命令样本与浏览器局部验收，不是陌生玩家 60–90 分钟首玩或真实手机触控验收。
- 器纹验证了条件、代价和预览/结算共用路径；长期等预算构筑强弱、购药频率和寿元压力尚待真人观察。
- 未新增裴铸专属制造任务、器谱掉落或用现有阵枢购买器纹。玄铁料目前来自稳定坊市渠道。
- 未覆盖旧角色补剧情与补奖励；保留结构迁移及未来格式不覆盖保护。

## 复现

```sh
npx vitest run tests/workshop.test.ts tests/workshop-ui.test.ts
npx esbuild tools/workshop-audit.ts --bundle --platform=node --format=esm --outfile=/tmp/xxrs-workshop-audit.mjs
node /tmp/xxrs-workshop-audit.mjs
npm run dev -- --port 5231 --strictPort
npm test
npm run build
git diff --check
```

浏览器访问 `/tools/workshop-preview.html`，切换“炼气炉房”“筑基器坊”“秘境灵流”。检查点都从新角色执行命令生成，不使用注入存档绕过成长门槛。
