# 炼气至筑基成长闭环（v0.14 / 存档 v13）

本轮以原设计的功法、装备、丹药构筑为主角成长轴。陆迟寻父是可选道友线；三年旧约仍属于早期人物事件，不能据此宣称所有剧情已完全可跳过。金丹及更高境界尚未开放。

## 成长和奖励

功法入门→熟练→通达，每阶灵石 12、灵草 2，需心得 2，第二阶需筑基。研修不推进月份，每册最多两次；只对装配功法生效。辨草录每阶另加采药 1。修为收益只在炼气阶段累计。

回春散用草 2、石 4，降低伤势最多 2；清心丹用草 3、石 6，神识 +1、上限 12。两者需心得 1 炼制，共用三个月服药间隔；无对应伤势或神识已满时拒绝无效服药。基础炼药不推进月份；原筑基丹仍沿用三月炼制及突破消耗规则，不共用此冷却。

灵器维持一个装备槽、两个品阶。山外判定中基础属性由根骨 + 神识×2 调为 floor(根骨/2) + 神识；普通灵器基础 +10，精炼 +32，克制另 +8。充分准备仍可必过，单靠一般属性加同行不再轻易封顶。

## 规则与持久化

`growth.ts` 是纯规则模块，定义研修、药品、成本、冷却、校验和命令。UI 通过 `dispatch` 修改状态，随机仍由既有种子驱动。`world.ts` 保持编排职责，在正常月推进保留成长状态，轮回重置。

存档 v12→v13 新增 `growth`，旧档从入门、空药袋、无服药历史开始，不补发首胜或营救奖励。旧版迁移链依次经过 v12 后进入 v13；首次保存保留 `original-v12`，未来或损坏存档拒绝识别。迁移不更改原始输入、种子和已完成剧情。
