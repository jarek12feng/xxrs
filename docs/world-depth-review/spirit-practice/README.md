## 交互与规则

原神识主题为固定选择“守一念→留一线听辨”，错误只增加次数。现在石案保存本念、已辨回声与识压，玩家按当前状态组合操作，成功条件为：本念稳定、两股回声辨清、识压至多一层。

| 操作 | 实际变化 |
| --- | --- |
| 守住本念 | 稳定中心，识压降一层，保留回声 |
| 逐股听辨 | 本念稳定且识压未满时，辨明一股；横潮实测每次另添一层识压 |
| 运分念诀 | 要求已研修分念诀，同时辨明两股，识压升一层；不能自动稳住中心 |
| 收息缓压 | 散去识压，保留本念与回声 |
| 灵草护神 | 消耗灵草2，稳住中心并散去识压，保留回声；不是必需物资 |
| 收念重来 | 清除回声、稳住中心并散压，可以换法 |
| 放开试阵 | 检验当前状态；失手增加识压并散去一股已辨线索，余下进度保留 |

初试通过后，传讲人换入横潮：识压从满值开始，逐股听辨还会增加识压。必须再实测通过才记入神识问法；不会仅凭初试自动领奖。古渡同行已留下对应实测者，继续保留免初试的收益，直接从横潮开始。

开场问法原耗月及已有批注减免保留；石案内局部操作不推进月份。没有真实识海创伤、随机失败、额外境界门槛或重复奖励。分念路线、逐股路线可以中途切换，灵草用尽仍有无物资解法。成本与状态变化来自同一纯规则报价。

界面仍在原问法场景：本念圆环、两股回声和识压随保存状态变化；提示为现场条件与已发生结果，不再以传讲人直接说出下一按钮为主。试阵状态不是人物逐帧动作。初测热点遮挡回声标记已修正，去掉重复的零费用行与重复反馈。
