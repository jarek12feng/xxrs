# 离照试炉：炉况与换法首批

2026-11-05。本批只改现有旧丹室试炉，不新增秘境、晋升门槛、丹药或稀缺材料奖励。问法、元婴护持和古渡同行深化不属本批。

## 规则及成本

备料仍为普通灵草2、1月，封存辅药不动用。原先普通排潮1月、收药1月；新版缓炼2月、收药1月，总计由3月变为4月。分念辨性1月、收药1月，含备料共3月。没有法宝或分念诀仍可用缓炼完成，不要求额外劳作或重战。

炉况保存为潮息、药性分离、行炉负担，各为0–2；初始为2/0/0。收药检查分药达到2，且潮息与负担之和不超过2，不检查动作序列。观察免费，操作前显示确切结果与成本。行炉负担只属于本炉，不修改人物神识、伤势或寿元上限。

| 操作 | 月数 | 普通灵草 | 炉况效果 |
| --- | --- | --- | --- |
| 分槽缓炼 | 2 | 0 | 潮息归零、分药至2、负担减1 |
| 分念辨性 | 1 | 0 | 须已研修分念诀；潮息减1、分药至2、负担加1 |
| 收念守温 | 1 | 0 | 负担归零，药性和潮息保留；无负担时拒绝空耗 |
| 灵草滤潮 | 1 | 4 | 潮息归零、负担减1，不代替分药 |
| 御镇潮印 | 1 | 0 | 须温养且装配；潮息归零，不替代分药，不消除负担 |
| 合槽收药 | 1 | 0 | 满足炉况即完成；否则负担加1，保留分药，预先显示将失稳 |
| 弃炉 | 0 | 0 | 只弃普通试液，之后重新付费备料 |

各变化在0–2范围内。滤潮与御印在潮息已退时拒绝重复消耗。完成后所有试炉动作关闭，不重复授予药理。反复观察不结算，真实耗月仍走现有逐月中断规则。

例如误收药后再分念，炉况为1/2/2，暂不能凝定。可选择收念、缓炼、滤草或御印处理，已分药性均保留。普通缓炼始终提供恢复通路；可先回港、读档再继续。法宝是处理局部炉况的手段，旧的一步直接完成捷径已撤销。

## 接口与迁移

- `src/lizhao/assay.ts` 包含纯炉况转换、报价、预览、校验与旧炉况升级。预览和结算共用同一转换，不使用随机、Vue或浏览器API。
- `rules.ts` 管理地点、时间中断、扣料与一次性药理成果；`view.ts` 引用报价生成行动预览。
- `AssayPanel.vue` 只读表现潮沫、分层药液、负担边框与文字读数，保留现有器物局部操作面板。
- 本批字段从v51开始要求。旧idle保留空炉，cloudy保留待处理试液，clear保留可收药清液，stable与已验证药理保留，不补奖励。损坏新字段、未来版本拒绝。
- 并行旧友行旅已将当前版本推进至v52，本批迁移保留在v50→v51边界，由其继续接续；不回退其他模块版本或清空已有日程。
