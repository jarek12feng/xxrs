# 金丹中期：会期选择与赴会衔接

2026-11-05，本地实现，未提交。承接筑基用途首段。本批处理已有诸宗会前的候约，不增加剧情门槛、奖励、存档字段或新会期。

## 变化

核对原规则：登台需要金丹中期，修为599是后期突破的积累条件，并非赴会条件。旧提示“继续闭关”容易混淆两者；原候会每次最多120月，长空档需要反复操作。

- 洞府/外海闭关安排及会谷场景的歇脚处说明当前中期能力用途、两胜入境与第三场可选；修炼至599作为自主增强实力的选择。
- `wait` 增加可选参数 `until: 'meeting'`，按已知且未到的会期一次报价，最多600月。原短期候会与败后六月调息保持原行为。未知、已到会期及当前会场不能使用这一模式；余寿不足拒绝。
- 候会不增加修为、不恢复伤势、不消耗灵石灵草，不自动报名；事先展示年月、预计年龄与余寿，以及已有约定提醒。按既有逐月时钟结算，待处理事件/寿尽/会期来信照常中断，已度过年月保留。
- 到期后，古渡直接提供赴会两月报价；居所先航行六月回古渡，会馆先沿原两月航路回古渡，然后才能赴会。到会场后仍由玩家相识、备战、报名。
- 准备项继续使用既有 `PreparationNotes`，不把全部宝物温养或换装变成赴会前置，也不保证当前构筑必胜。
- 等候年月记录使用“留居候约”，不再误称开炉筹备。

职责：`growth-continuity/meeting-objective.ts` 只读计划，`MeetingObjective.vue` 呈现并发出命令，conclave负责候约报价/结算；普通修炼仍由原进度模块处理。没有改变修炼速度、599上限或五十年会期。
