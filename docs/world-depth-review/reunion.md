# 第二批：金丹重逢与同行

2026-11-05。实施范围是苏婉宁金丹后的古渡重逢、侧堤共同历练、成果商议与分别短笺；不新增恋爱门槛、突破门槛、女性主角对应金丹剧情或新的秘境系统。

## 可玩流程

1. 原有独立修行年月达到凝丹节点后，收阅并核验可靠报喜信。只凭玩家金丹境界不能解锁此约。
2. 传讯收到“古渡侧堤之约”，读信不定约，回信只定约。也可到古渡侧堤入口托驿使回信。玩家仍按原有海路旅行，不传送、不定倒计时。
3. 古渡相见。她想复测药船侧堤，玩家借潮势检验新能力。没有结契、告白或好感条件。
4. 选择稳流、辨影或破桩分工。苏婉宁以独立凝丹后的分神/护堤能力承担另一侧，各自留下退路。
5. 先布归绳，再实测。普通方法布锚2月；出战且可用的镇潮印/定神珠/潮纹剑分别帮助稳流/辨影/破桩，缩短为1月；已掌握的澄息法/分念诀也分别可替代前两种法宝。实测另1月。先贸然实测只耗1月、退回石台，未受伤、未丢物资，仍可纠正。
6. 选择公开安全落点（一次灵草4）或暂留完整底图、先告知险点（一次灵石8）。双方都保留实测批注，不把同意公开写成唯一正确选项。
7. 互留信路，各赴前程。场内苏婉宁撤下，留下批注。传讯收到分别时留下的短笺，承接实际公开/暂留选择；这是离别留言，不虚构同月已经完成远途旅行。

实测后，稳流/辨影/破桩批注分别可使护持/护神/运法问法省去1月核验，仍须亲习。已问过者不再奖励或重置；不和既有拓本折扣叠加。

## 边界与封装

- `src/golden-reunion/state.ts`：持久状态与阶段/年月验证；嵌入 `goldenStory.reunion`。
- `src/golden-reunion/index.ts`：可靠消息资格、准备报价、分工效果、命令草稿更新、后续短笺。场景只读报价，仍由 `goldenStory` 公共命令办理时间、互斥、资源与保存。
- `ReunionScene.vue` 与 `OuterSeaPanel.vue`：古渡入口及单一主场景；复用已有侧堤背景与人物素材，归绳为状态示意，未生成新原画或完整逐帧演出。
- `correspondence`：邀约、回信、往来归组、未完约定及选择对应短笺。已结束后不继续催约。
- v49 承接 v48。只补未参与重逢状态，不伪造相见、合作或报酬；保留已收信件、试炉、拍卖等独立领域。
- 可以回古渡、回山或继续别事，再回来续做；没有额外全局探索锁。不因离线惩罚，不强行等待 NPC。超过既有金丹寿元可核验范围时停止新会面，不将旧消息当作永远在场。

## 验证

新增规则测试覆盖三分工、两种分图、误判恢复、无指定宝物替代、核验与邀约分离、确定性/重复命令、问法兑现、资源上限、时间中断与v48迁移；组件测试覆盖主场景唯一、刷新续做和分别后人物撤下。全量回归结果见本节末。

实际浏览器在独立5394端口导入公开命令检查点：第2508月相约、重逢、辨影分工→定神珠使布锚只用1月→刷新并继续→实测1月→暂留底图得灵石8→分别→传讯核对短笺，结束第2510月。原5391正常试玩存档未动。发现人物气泡遮挡后，将合作选择改为侧面图台操作面板；1280×720实测人物可见、选项可达。证据：[重逢分工](reunion-meet.png)、[分别离场](reunion-depart.png)、[选择对应短笺](reunion-letter.png)。

这不是正常新档全程人工试玩，未验证所有装备组合的真人体验，也没有Windows/Steam或现实游玩时长验收。检查点工具 `tools/golden-reunion-checkpoint.ts` 沿现有公开命令到金丹后期、核验报喜；只用于隔离验证，不是正常新档人工连续试玩。

最终当前共享工作区 `npm test -- --maxWorkers=1`：201文件、1367项通过；问法接口收拢后的补充回归3文件23项通过。`npm run build`（含vue-tsc）与 `git diff --check`通过，构建仍有既存大包体积提示。首轮并行全量曾出现长流程5秒超时和商盟地图节点断言失败，未将其计作通过；两项单独复测及后续上述完整回归均通过，未为本批修改商盟规则或放宽超时断言。
