# 元婴首次护渡：两处险流与舟队推进

2026-11-05。本批深化既有元婴首次能力兑现。基础元婴可独立完成；镇潮印改变可同时照看的范围与舟队停靠过程。没有新增元婴境界、自由航行、晋升门槛或奖励材料。

## 玩家可以做什么

勘察后，主潮、侧岸回流、测绘舟同时出现在古渡现场。主潮阻断航道；侧岸回流阻止登岸；中段回水湾可安全停舟。三个现场对象分别提供护流、护岸与行舟操作，不是原来的单一顺序按钮。

| 方法 | 实际过程 | 含勘察耗月 |
| --- | --- | --- |
| 基础集中护持 | 护主潮→舟队到回水湾→转护侧岸→舟队登岸 | 3月 |
| 基础铺开护持 | 两处同时受护，舟队分批缓行；到回水湾后可继续或换法 | 5月 |
| 镇潮印辅助 | 印固定主潮，自身护持侧岸；两处布置可任意先后，舟队连续通过两段 | 3月 |

原版勘察、展开护持、渡过各1月，共3月。新版勘察仍1月；改变护持、布印、收势均0月，集中行舟每段1月，铺开护持每段2月，镇潮印配合护岸连续引航2月。除沿用时间成本外不扣灵草/灵石，不重新发奖，不需要新材料。

镇潮印必须已经温养并装配，只有拥有无效。布印后卸下或失去可用性，主潮的法宝护持即时失效，不能沿旧报价绕过；仍可改用自身护持。分念诀和潮纹剑的专门护渡解法尚未接入。

## 场面与结果

- 主潮与侧岸各有独立流线和护持范围，法宝镇流显示镇潮印。
- 两艘舟从此岸移至回水湾，再移至彼岸；镇潮印组合可连护两段直接抵岸。
- 此岸和回水湾均可收势等候。关闭现场面板、重返或读档不推进航程、不丢失已经越过的险段。
- 完成后收回护持，彼岸保留路标、展开的航图和测绘队员表现，既有`ability=done`事实承接后续内容边界。
- 渲染仅使用已保存结果。船位CSS过渡不结算月份或成果；减少动态效果时取消过渡，文字与操作仍可用。

本批是现有场景叠加与短过渡，复用既有主角/木舟/镇潮印素材，石坪采用既有环境纹理，远处测绘队员为小尺寸示意。不是逐帧登岸、真实水体物理、完整NPC行走或新地点长期玩法。

## 规则与保存接口

- `src/nascent-soul/crossing.ts`：护持覆盖、舟位、只读投影、纯报价与状态转换、校验和迁移。无需通用战斗或Vue依赖。
- `rules.ts`：元婴、出关、场所和互斥检查；按报价逐月推进，成功后提交舟位与完成事实。
- `view.ts`：现场对象的命令选择；`NascentPanel.vue`负责选择对象；`NascentAfterWorld.vue`只投影结果。
- 持久字段为`nascentSoul.crossing`，含focus、seal、position。v54从当前v53承接；不覆盖离照v51、旧友行旅v52/v53或既有传讯事实。
- 旧none/surveyed保留此岸，旧sheltered保留铺开的护持但不编造已经行舟，旧done保留抵岸成果；无新奖励或自动重做。
- 未知版本、损坏枚举与未完成却抵岸等矛盾状态拒绝；完成后新护渡命令不再结算。
- 两月连续引航若中断，保留已耗月，整次航段未完成则不提前移动舟队或设标。原有原子行动边界不变；不是按每月保存一段连续行舟。
