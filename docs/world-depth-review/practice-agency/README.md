- 分药：主盏、旁盏、侧孔、净药瓶；暂存旁盏与分念照看有不同场内状态。混流可免费合盏重来，2株灵草仅用于保留分离成果的恢复，无混流时禁止付费。
- 护阵：药架位置、通道浮木、护阵覆盖和回流去向可见；就地护药与移往高台均有效。分念可同时照看药架和通道。失误不毁物资，晾干后保留布置。

交互均走现有公共命令；局部操作不扣年月、灵石或随机种子。入席仍沿用原问法报价。两轮通过后才记领悟，阶段转换与结算在同一命令内完成。没有新增长线奖励或晋升门槛。
