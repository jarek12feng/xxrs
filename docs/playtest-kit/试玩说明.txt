修仙人生 · Windows 试玩说明
版本：playtest-20261029-A / 应用 0.14.0 / 存档 v14

1. 怎么启动
适用 Windows 10/11、64 位 x64 电脑。
解压收到的完整试玩资料包，双击其中的 Setup.exe 安装，再从桌面“修仙人生试玩版”快捷方式启动。
游戏可离线运行，不需要安装 Node.js，也不需要注册账号。
本包未签名，可能显示未知发布者。如安装被系统阻止，请截图反馈，不必关闭安全防护。

2. 怎么试玩
请从新角色开始，自由选择道途，像平时一样玩约 30 分钟。不需要查攻略，也没有必须完成的进度。
从能操作建角页面开始计时，包含阅读、思考和等待。卡住、无聊或想退出都可以直接记录；随时可以结束。
30 分钟后可结束，也可自愿继续。请记录继续了多久、做了什么。
如果以前玩过本游戏，请先在“菜单 → 备份与迁移”导出旧进度，避免影响个人存档，并在反馈中说明。

3. 存档与声音
有效行动会自动保存，等待保存完成再退出；游戏不提供跨设备云存档。
网页版与桌面版存档独立。重要进度可从“备份与迁移”导出 JSON。
声音可从游戏菜单开启。本包不含开发环境中的五首试听配乐。

4. 怎么反馈
玩完填写同目录“反馈表.txt”，发回给邀请你试玩的人。
遇到问题请附截图、出错前的操作、游戏年月和错误文字；若愿意，可附游戏导出的存档。
无需提交个人资料或电脑账号信息。录屏完全自愿，请不要录入其他私人内容。

这是受控内测包，尚未完成 Windows 实机安装、更新和所有设备验收；不是正式发行版。
