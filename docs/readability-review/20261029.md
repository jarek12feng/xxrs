# 文字可读性检查 · 2026-10-29

用户本轮授权检查并修复文字与背景接近的问题。本次只变更表现层色彩与阅读底板；无剧情文本、规则、数值或存档格式变更。修订标识 readability-20261029-D，原 A 版试玩包与冻结清单不覆盖。

## 查明的问题

- 洞府下一目标：浅色正文叠在旧的浅色提示底板，计算颜色对比约 1.11:1。
- 擂台战报：浅色段落叠在纸色底板，约 1.37:1。
- 旅程记录折叠标题：沿用深绿文字，但父面板已经改深色，约 1.96:1。
- 洞府成长标题、探索进度：约 3.33:1、1.93:1。
- 当前页标签：白字搭金色底，约 3.60:1。
- 禁用按钮：原有 0.4–0.55 整块透明度连同材料要求一起变淡。
- 场景、地图标签：文字直接叠图或靠渐变/阴影，可读性随图片明暗变化。不能用忽略图片的纯 CSS 对比结果判定图片文字合格。

## 修复

`src/readability.css` 在主题样式之后加载，限定深色场景/面板范围：

- 正文、人物对话、HUD、修行标题背后的阅读底板更加稳定；地图题字有独立底色。
- 下一目标、战报和相关浅底遗留卡片统一深底浅字。
- 成长数字、摘要、条件说明使用对应面板的浅色文字。
- 当前页金底配深字；悬停与键盘焦点保持文字和底色匹配。
- 禁用按钮不再整体降透明度，采用灰色底、浅字、虚线边框与原 disabled 行为。
- 不使用全局反色，保留纸色页面的既有语义。

## 验证范围与限制

实际浏览器检查当前 319px 窄屏：归灯场景、洞府、储物袋、功法、地图、师门、炼器购药、人物关系、人物属性、擂台完成页、见闻；未推进游戏月份。修复后再次检查洞府、地图、见闻和擂台战报，所检 DOM 文本节点计算色对未发现低于 4.5:1 的项。检查包含 disabled 条件文字及键盘焦点截图。

计算检测按祖先背景透明合成，不解析背景图像、渐变和所有遮挡；因此图片文字另做视觉检查，不能称为整款游戏无障碍认证。未重走每个剧情分支、死亡结局及正在进行的战斗，也未完成真实 Windows 显示器与桌面宽屏复核。修改主要落在这些场景共用的阅读组件样式。
