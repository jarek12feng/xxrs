## 已接入

- 无名渡击退石偶后出现侧室石匣。查看铭文，选择有效神识12或玄铁料1定阵，三段内解禁取栖尘戒；失败普通伤势+1、可静养重试，撤回不添伤。只有成功取得戒，观察不发奖。沉井主法、分念诀与必要历练不改。
- 储物袋大件载荷1；坊市32灵石/1月扩容到2；遗戒外层4；分念诀、有效神识18、24灵石/3月修复到6。普通补给不引入全背包格数限制；当前大件仅沉纹器髓，每块占2。
- 侧室两块器髓只收取一次，不刷新。无戒可用扩容袋分次运送，或每块12灵石分匣封装。满载拒绝、不消失；封装不是通用货运系统。
- 二阶主器重铸：器髓1、玄铁料1、灵石24、3月。原精炼和器纹保留；灵剑反击+3、正确辨影+1伤害；灵瓶守势−2、正确辨影−1承伤。未装备不生效，沿用共用战斗预览与结算。
- 栖尘戒内层隔存：自制或委托回春散、清心丹、养神丹、护脉丹每炉节省灵草1；购买、突破丹和炼器不变。配方、报价、备料缺口和扣料共用，修复后有持续用途。
- 背包展示真实容器、载荷、材料和重铸效果；底部入口/弹窗标题随获得遗戒由储物袋变为储物戒。取得和升级记录进入已有履历日志。
- 新 item-growth 纯规则域负责机缘和成长；equipment 只读取重铸结构，workshop 引用只读隔存计算，不在 Vue 中结算规则。
- 存档v44：v43先验证再补空域，保留原入道/剧情；更旧版本沿已有迁移链补空。不补戒指或材料，不修改原对象，未知版本拒绝。

## 实际浏览器局部证据

使用独立来源 `http://127.0.0.1:5286`，通过真实“系统菜单→备份与迁移→导入备份”加载 `tools/item-growth-checkpoint.ts` 所生成的检查点，不读取其他端口玩家存档。检查点由现有公开命令路线构造，仍属于隔离场景验收，不是全程从新建角色的真人连续试玩。

1. 无名渡现场点侧室石匣→查看铭文→神识定阵→辨读外环。刷新并继续游戏，恢复到第2/3段、稳定度6、解禁2/6。
2. 托住阵脚→探入取戒，实际获得栖尘戒，入口变为“储物戒”。收取一块器髓，背包载荷2/4、器髓1、现场余材1。
3. 第二个检查点由公开命令完成取戒、取材、沉井试运/离渡、归居、精炼与购铁。正常导入后，点击重铸归元灵瓶：灵石104→80，玄铁1→0，器髓1→0，载荷2/4→0/4，年月+3。已装备灵瓶显示重铸特效和新素材；刷新后成果保留。
4. 检查1920×1080和1280×720下的背包、侧室人物与局部操作。浏览器捕获的error日志为空。未检查2560×1440、系统显示缩放、Windows、Steam与手柄。

现场发现并修复两项UI问题：读档后取戒会退回外层，改为保留侧室；导入另一地点的存档会留下旧侧室面板，改为按实际地点关闭。探阵中不显示无效离场热点，必须通过明确撤回命令退出。
