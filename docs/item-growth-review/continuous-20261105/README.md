## 已发现并修正

- 旧药窟配药只说2草，过阵后才明确调息另需2草，造成无伤成功后返程补给。现出发支路、旧阵准备均提前提示至少留2草、药理方案合计4草，战中回气另计。原成本、规则和存档不变。
- 泉谷行前建议的“选择一项主要投入即可尝试”容易使人高估一阶灵瓶的连续作战保障，改为说明应敌与战间恢复需搭配，明确功法研修用途，不要求买齐装备。
- 重铸贡献原来被并入“器物修正”，战斗中难以区分新器性与旧辅器。现在从既有贡献来源生成“归元灵瓶重铸：承伤 -2”等明细，并说明已计入总数、受承伤下限与击倒影响；未改结算。正常战斗读档续接后实际验证预览与回合结果均可见。
