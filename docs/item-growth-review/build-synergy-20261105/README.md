- 原灵瓶重铸、器纹和主法规则继续配合：稳守减伤、灵剑反击、镜的换招辨影各有用途。本轮没有新增道具或更改器纹数值，未宣称三套同成本平衡或最优构筑。
- 旧式概率擂台没有上一招接口，不触发本轮衔接；金丹不触发。文案限定“筑基行旅”，不冒充全部战斗覆盖。
