# 准备取舍与向前兑现成长

2026-11-02。用户授权在现有关卡实现不同代价的解法、装备/丹药/研修取舍及晋升成就感，并特别要求少回头。本轮打磨炼气药谷/内府及筑基雪线/古道，不增加系统、必经回访或金丹内容。以下为本地实现，未提交、推送或重新发行安装包。

## 规则对照

| 位置 | 原有行为 | 当前行为 |
| --- | --- | --- |
| 炼气妖兽战 | 守势主要依赖对应来招，长春另有耗草回气 | 所有主修守势均伤害 −3、承伤 −4，用输出换生存；傀儡已有独立守势规则，不重复叠加 |
| 护泉青蟒 | 药理入场耗草、气势上限 +12，敌人按固定序列行动 | 保留费用和气势；药理路线上一合守势会诱出下一合反击窗口，该合所有动作承伤 −4。可抢攻或利用减压稳住，不额外耗药引；长春回气仍按原规则耗草 |
| 两战间逆流 | 草药、护脉丹、辨阵或受伤强穿 | 新增已装配灵瓶的无耗材通行；熟练主修增强辨阵；各选项显示实际进入下一战的气势，不能叠领 |
| 淬脉成果 | 根基 +3、解除瓶颈 | 保留原成果；下一程凝元内府可直接行气穿过逆流，不要求回药谷、交药或找 NPC 领能力 |
| 雪线整备 | 自备药物或付服务费 | 新增已装配二阶灵器隔寒、通达主修行功御寒；后续仍须选路、实战取材与炼化 |
| 筑基后期 | 灵元凝练主要解除瓶颈 | 凝练且修行 ≥400 时，古道外缘与接应交锋前两合承伤 −3；直接用于后续主线，无回访/领奖前置 |

诱引只作用于秘境护泉青蟒，不作用于准备路线青蟒或内府傀儡。UI 按秘境分别说明；破绽提示、预览与结算使用同一判断。诱引结束恢复原回合序列，没有隐藏随机变招。
