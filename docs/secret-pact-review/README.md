## 已接入

- 无名渡提前相约，筑基中期后沿古道取材路线深入照玄遗府。首次内府探险与外缘成长实战相衔接，已通外缘不重复打；其他两条成长路线、苏婉宁主线不增加前置。
- 贺崇、叶照各有目的；入府方式影响争宝首合的实际承伤。分宝支持交换、让宝、继续议价、主动夺宝、离府。
- 冲突分清谁先毁约，使用具名人族贺崇的真实回合战斗。胜后得法；败退、撤退不丢既有晋升主材，后续可追索或传信止争。
- 照玄护脉法对守势接识阵增加 2 点伤害；守约分宝有一次回春散补给，主动毁约不会同时获得守约认可。资源、履历、尾声与任用资格对应真实结果。
- 可靠秘境亲历可以替代额外药运晋职证明，仍需筑基中期、取材炼元及门内身份条件。任职可选，无新官阶体系。
- 圆满晋升提示改为已经通过归流后的归山与未尽行旅，消除提示顺序错误。

## 争宝挑战修订（2026-11-02）

取消付少量药资稳拿玉简；新角色必须争夺获胜才得护脉法。贺崇气势 160→200、攻势 23→28；护脉法守后识阵由伤害 +2 改为伤害 +6、承伤 −3。入府前可查看对手与己方攻守、研修/灵器/伤势准备提示。让宝、离府、败退恢复与继续成长仍保留。

不增加存档字段或随机掉宝。三主修通过公开命令提升主辅修到通达、积累至 350 后可胜；这是固定检查点的可达性证据，不是首玩胜率。新增失手无宝、养伤整备再战、后续战斗兑现与界面情报回归。尚需真人验证宝物吸引力与准备负担。
